## 横断テーマから生まれる物語の種

一人の先生の専門領域だけに閉じない、シリーズ共通の着想を管理する。教訓を先に置かず、子どもの生活場面と「どうして？」から物語にする。

|---|---|---|---|---|---|---|
| T-01 | 参加の仕方はいろいろあってよい | **『いっしょにやるって、どこにいること？』** | 輪の中で同じ動きをしない子が、少し離れて見る、音だけ返す、道具を渡す、途中で休んで戻る。大人が決めた一つの参加像では見えなかった「一緒」が見つかる | うさぎ＋りす＋ことり＋ぞう | U-03、U-06、R-07、K-02に断片はあるが、参加そのものを主題にした作品はまだない | **新規候補** |
| T-02 | できないことを前提にしない | **『まだやってないのに、できないってわかるの？』** | 遊具の前で止まった子を、大人が先に抱き上げようとする。子どもは足場、持ち手、時間を自分で確かめ、必要な助けだけを選ぶ | うさぎ＋りす | 完成作『うさぎせんせい、「かんたん」ってだれがきめたの？』と `every-step` が中心テーマを扱う | 既存作で扱う |

横断テーマを作品化するときの注意:

- 「参加しなくてもよい」で閉じず、本人が参加したいときに選べる方法と環境を増やす。
- 「できるはず」と励ます話にせず、最初から能力を決めつけずに本人の反応を確かめる。
- 車椅子、補聴器、眼鏡、装具、AACなどを「壊れた身体を直す物」や特別な魔法として描かない。本人の身体と意思を中心に、アクセス、選択、参加の方法を増やす道具として描く。
- 機器を一括りにせず、本人によって必要性、使い方、合う条件、使いたくない時間が異なることを尊重する。
- 呼吸、身体のリズム、表情、姿勢、声の調子を「心が通じた証拠」と決めつけない。大人側の変化、子ども側の反応、その前後を子どものペースで観察する。
- 同じリズムになることだけを成功にせず、顔をそむける、身体を離す、動きを止めることも、距離や刺激を調整するための大切な応答として扱う。
- 身体への好奇心は、大人が子どもを観察するだけでなく、子ども自身が「ぼくの身体はどうなっている？」と世界を見る形にする。
- T-06では、聞こえる子を意地悪な役にしない。「同じにすることが公平」という身近な感覚から問いを始め、難聴児本人が配慮を説明する責任を負わない構成にする。補聴器を使えば常に同じように聞こえるとも描かない。
- T-07では、同級生を診断者や小さな支援者にしない。本人と日常を共有してきた友達が具体的な手がかりを持っていることを示し、最終判断と安全確保の責任は大人が担う。「癇癪を起こす子」ではなく、前後の条件と身体反応を描く。
- T-08では、母親の過重な負担や自己犠牲を「頑張る美談」にしない。父親、家族、専門職、地域も支える側へ入り、母親には助ける、助けられる、断る、休む選択がある。コミュニティへの貢献量を親の価値の条件にしない。
- T-09では、身体的拘束を日常的な指導方法として正当化しない。差し迫った危険への対応と、管理しやすさのための制限を混同せず、当事者の経験と権利、安全の専門的確認を経てから作品化する。特定の先生や学校だけを悪者にせず、矛盾が起きる構造と修復を描く。

### T-04 企画メモ『いっしょのリズムは、どこにある？』

#### 物語の核

> 身体は、周りの感覚と人との関わりの中で、自分に合うリズムを探している。

「落ち着けない子」を直す話ではない。音、光、動き、言葉が重なったときに身体がどう反応するかを子どもの内側から描き、感覚を減らす、加える、変える、休むという選択を試す。最後は親子が同じ状態になることではなく、互いの異なるリズムの間に小さな出会いが生まれる。

#### キャラクターの役割

| キャラクター | この物語での役割 |
|---|---|
| りす先生 | 主役。身体の探偵として、感覚を一律に増やさず「減らす・加える・変える・休む」を一つずつ試す |
| ことり先生 | 呼吸、表情、声の調子、姿勢、顔をそむけるなど、言葉にならない応答を受け取る |
| くま先生 | 呼吸、顔色、痛み、体調、疲れ、安全を確認し、感覚の問題だけに決めつけない |
| 保護者 | 子どもを深呼吸させるのではなく、まず自分の声、速さ、距離、動きを緩める |

#### 12場面の物語線

| 場面 | 出来事 | 表現の中心 |
|---|---|---|
| 1 | 楽しい部屋で、音、光、人の動きが重なる | 背景の刺激が少しずつ増える |
| 2 | 子どもの息、肩、指、まばたきが速くなる | 行動名ではなく身体の内側を描く |
| 3 | 大人の「落ち着いて」が、もう一つの速い音として届く | 大人を悪者にせず、一生懸命さも見せる |
| 4 | 子どもが「ぼくの身体だけ、走っているの？」と問う | 物語を動かす子どもの問い |
| 5 | りす先生が身体の探偵として現れる | 答えより観察から始める |
| 6 | まず音、光、言葉、人との距離を減らす | 感覚は足すだけではない |
| 7 | 押す、包む、揺れる、離れるなどを一つずつ試す | 一度に複数を試さない |
| 8 | 子どもが身体、表情、AACなどで「もう少し」「おしまい」を選ぶ | 本人の意思と停止の選択 |
| 9 | くま先生が呼吸、顔色、体調、安全を確かめる | 感覚だけに原因を限定しない |
| 10 | 保護者が話す速さと身体の動きを緩め、隣で待つ | 調整を子どもだけに求めない |
| 11 | 呼吸は同じにならないが、肩が緩む、視線が動くなど小さな応答が現れる | 同期を成功条件にしない |
| 12 | 子どもが自分の選んだ方法で、遊びへ戻る、見る、または休む | 参加方法を本人へ返す |

#### 感覚の選択肢

| 調整 | 物語に置ける例 |
|---|---|
| 減らす | 音を小さくする、光を落とす、言葉を減らす、人との距離を広げる |
| 加える | クッションや毛布で身体の境界を感じる、押す・引くなどの活動を本人が選ぶ |
| 変える | 揺れの速さ、姿勢、場所、道具を変える |
| 休む | 何も加えず、安心できる場所で待つ |
| 終える | 顔をそむける、身体を離す、AACで示すなどの「おしまい」を尊重する |

#### 科学・安全上の境界

- 本文で「迷走神経」という用語は使わない。呼吸、心拍、覚醒に関わる自律神経の背景知識として、必要なら巻末で簡潔に触れる。
- 特定の呼吸、揺れ、圧刺激によって「迷走神経が整う」「必ず落ち着く」と説明しない。
- ポリヴェーガル理論を、この物語の唯一の科学的根拠にしない。
- 「感覚ダイエット」を誰にでも同じ活動を与える処方として描かない。本人の生活上の目標、選択、反応を見て、必要に応じて作業療法士などと検討する。
- 感覚は増やせばよいとは限らない。減らす、加える、変える、休むを比較し、合わない刺激は止める。
- 親子の身体的な同期を「心が通じた証拠」や成功条件にしない。異なるリズムのまま関わることも含める。
- 呼吸の異常、顔色の変化、意識の変化、痛みなどがある場合は、感覚調整の物語で完結させず医療相談へつなぐ。

### C｜母親歴ではなく、経験した節目で読む（7案）

母親になった年数と、悩みの深さ・支援の熟練度は一致しない。順番に克服する物語ではなく、同じ気持ちへ戻ることも描く。母親の経験を中心にしつつ、父親・家族・支援者へ負担を渡せる余地を残す。

| ID・仮題 | 節目／心に残る一場面 | 感情に響く点と、持ち帰る一つ | 既存案との統合 | 響/用/楽/試 | 順 |
|---|---|---|---|---|---|
| C01 検索を閉じられない夜 | 初めて発達が気になり、検索語ばかり増える | 焦りを否定せず、相談で聞きたいことを一つメモ。検索をやめられたことを正解にしない | 新規。原点メモの孤立・情報探索を抽象化 | 5/4/2/5 | 次 |

| C04 先生に、言ってもいいかな | 園で気になることがあるが、感謝と遠慮で言い出せない | 「家では○○です。園ではどうですか」と事実から話す一文 | T-07・P-04＋原点メモの統合 | 5/5/2/4 | 次 |

原点メモは内部の企画材料として参照し、公開用の実話原稿として転載しない。初稿は架空・複合場面として明示する。実在の家族の発言・写真・固有の経緯を使う場合は、本人たちの意向を確認してから扱う。感情の強さを、悲しさの強さだけで測らない。おかしさ、安堵、誇らしさ、親子で笑えた瞬間も評価する。

### 何を見て、次を決めるか

初稿を3〜5人程度の協力者に見てもらうのは、言い回しの誤解を探すための探索であり、効果の検証ではない。最初に「役立ちましたか」ではなく、次を聞く。

1. どの場面が自分の経験に近かった？ 違うと感じたところは？
2. 何の話だと思った？ 誰の気持ちが残った？
3. 一つ持ち帰るなら何？ 実際にやるには何が難しい？
4. 責められた・急かされた・決めつけられた感じはあった？

公開テストでは、同じ形式・近い配信条件で、保存率・共有率などを閲覧数と併記する。絶対値や少数の反応だけで優劣を決めず、具体的な「試した」「うちでは違った」の内容と合わせて判断する。診断名や子どもの個人情報をコメント欄へ書くよう促さない。

| 記録項目 | 残すこと |
|---|---|
| 内容 | 試作ID、対象場面、媒体、冒頭文、今回変えた一点 |
| 感情 | 残った言葉・共感した場面・違和感（匿名の要約） |
| 実用 | 何を試したいか、試せない理由、試した結果 |
| 数値 | 閲覧数、保存数／率、共有数／率。媒体で取得できるもののみ |
| 判断 | 続ける／入口を直す／情報を絞る／確認する／保留 |

「響くが試せない」ならヒントを小さくする。「役立つが読み始められない」なら冒頭を具体場面へ。「責められる・診断に見える」なら反応数に関係なく表現を見直す。投稿への反応を、発達支援の有効性の証拠にはしない。

## ママの心が大きく動くとき｜年齢・節目から絵本を考える

更新: 2026-10-23。状態: **対話用の候補／実話として未確認**。ユーザーが挙げた10の場面を軸に、喜び・安堵・怒り・迷いの場面を加えた。以下の内心と台詞は執筆のたたき台であり、実在の母親や子どもの発言ではない。

子どもの年齢は「この物語を置くなら」という設定目安。診断、合併症の判明、開示、支援との出会いはどの年齢でも起こり得る。学校・卒業時期も個々の進路で異なる。母親歴・診断からの年月・きょうだいの年齢を、子どもの年齢とは別に記録する。

### このシリーズで描くこと

- 感情は「悲しみ→受容→前向き」の順に進めない。子どもを大切に思うことと、怖い・つらい・逃げたいと感じることは同時にあり得る。
- 「受容できない母」を問題にせず、何を失うように感じたか、何が分からず怖かったか、誰にも言えなかったことを具体的に描く。
- 困難の原因を子どもの存在に置かず、健康への心配、環境との不一致、説明や調整の負担、支えの不足を分ける。
- ママの物語でも、子どもを親を成長させる道具にしない。本人の好き・嫌・選びたいことを残す。年長の子の開示・進路は本人の意向も物語の中心に入れる。
- 重い経験ほど感動的、と評価しない。「笑えた」「仕事ができた」「断れた」「誰かが覚えていてくれた」も大きな転機。

#### 第1編｜まだ知らない、きみと明日

中心は「説明を聞いた夜から、次の朝まで」。出生前の期待を短い回想として重ねる。合併症や退院は別の時間として明示し、一晩に起きたことにしない。

| ページ | 言葉・気持ちの流れ | イラストの核 |
|---|---|---|
| 1–2 | 「この服を着て、どこへ行こう。」→初めて会う。楽しみにした時間も、今の子も大切 | 広げた小さな服から、抱く腕へ |
| 3–4 | 説明を聞く。「抱いているきみは同じ。なのに、明日が見えなくなった。」 | 説明の紙と、そばにある子どもの手 |
| 5–6 | 夜、検索が止まらない。家族が「代わろうか」と抱っこを引き受ける | 光る画面、交代する腕。説得して端末を取り上げない |
| 7–8 | 後日、聞けなかったことを一つ尋ねる。分かることと、まだ分からないことが分かれる | 質問一つのメモ。専門家が隣で紙を整理 |
| 9–10 | しばらくして新しい心配。「また、怖くなった。」今度は次に聞く相手へ連絡する | 新しい受診日、置かれた食事、同じ服をたたむ手 |
| 11–12 | 家のいつもの音。「明日の全部は、まだ知らない。今日は、きみとここにいる。」 | いつものコップ、子どもが触れる布。晴れやかな決意は求めない |

感情：期待 → 出会い → 足元が揺らぐ → 焦り → 誰かがそばにいる → 再び怖い → 今日の小さな安堵。家族の実際の交代と、聞き直せる専門家を主な支えにする。

#### 第2編｜きみのことを、話すとき

中心は「園の先生との面談」。周囲への開示、比べてしまう気持ち、きょうだいの問いを面談前後につなぐ。本人について伝える範囲を、使える表現で確かめる場面を置く。

| ページ | 言葉・気持ちの流れ | イラストの核 |
|---|---|---|
| 1–2 | 伝える文を書いて消す。「どこから話そう。」家族と、まず誰に何を伝えるかを選ぶ | 長い下書きが短い一文になる |
| 3–4 | 善意の返事にも、うまく笑えない。行事の写真を見て、比べてしまう | バッグを下ろす手、写真を伏せる手 |
| 5–6 | きょうだいの「どうして？」を聞く。自分が用意した説明と、聞きたいことは違った | 寝る前の小さな問い。きょうだいを説明役にしない |
| 7–8 | 面談へ。「できないことばかり、書いていた。」子どもの好きなことと、助かる関わりも添える | 本人が選ぶ道具と、一枚のメモ。共有する内容を確認 |
| 9–10 | 先生が本人へ「これ、好きだったね」。母が説明し始める前に、二人のやりとりが始まる | 道具を差し出す手、受け取る／選び直す子ども |
| 11–12 | 「全部を、今日話さなくてもいい。」帰りに、できたことではなく楽しかったことを家族へ送る | 短いメッセージ。母だけが連絡係にならない |

感情：緊張 → 傷つき・比較 → 問いへの驚き → 言葉を選ぶ → 分かってもらえた安堵。主な支えは相手が本人との関係を育てること。開示すれば必ず理解される結末にはしない。

#### 第3編｜この先にも、きみの場所を

中心は「新しい居場所の見学」。就学期と卒業期を同一人物の数日に詰めず、時間の経過を明示する。16ページ程度を想定し、進路制度の説明ではなく、同じ問いを持ち直す構造にする。

| ページ | 言葉・気持ちの流れ | イラストの核 |
|---|---|---|
| 1–2 | 「きみは、ここへ行ってみたい。」本人の関心から出発 | 行きたい場所を指す／写真を選ぶ手 |
| 3–4 | 見学で「難しいかもしれません」。帰り道、資料ばかり見てしまう | 入口に立つ二人、閉じた資料 |
| 5–6 | 相談相手が「どんな一日を過ごしたい？」と尋ねる。本人の希望を聞き直す | 名称の比較から、一日の絵へ |
| 7–8 | 短い時間、休む場所、移動方法。家族と施設側も条件を一つずつ確かめる | 本人・家族・担当者が同じ地図を見る |
| 9–10 | 試してみる。楽しい瞬間も、帰りたい瞬間もある。選んだ場所でも相談してよい | 参加と休憩。無理して最後までいる成功にしない |
| 11–12 | 「何年かたって」。卒業が近づき、また地図を広げる | 成長した本人、新しい地図。明確な時間表示 |
| 13–14 | 今度は本人も、学校の人も、その先の人も一緒に考える。親一人の問い合わせにしない | 本人を中心に、関係を引き継ぐ |
| 15–16 | まだ決まらない場所もある。「きみがどう過ごしたいか。そこから、また話そう。」 | 次の見学の印。扉は開け切らず余韻を残す |

感情：期待 → 拒まれた痛み → 行き詰まり → 条件が見える → 試す喜びと難しさ → 将来への不安 → 一緒に考えられる感覚。居場所不足を親の工夫だけで解決しない。親自身の将来への心配（M19）は終盤の短い内心に留め、きょうだいへの将来の託し方の話へ広げない。

#### 4編共通の制作ルール

- 母の「わたし」を語りの軸にし、他者の気持ちは台詞と仕草で見せる。
- 1編につき中心の出来事を一つ。関連する経験は回想・短い反復・時間の経過としてつなぐ。
- 第1編は「今日」、第2編は「関係」、第3編は「場所」、第4編は「時間」を持ち帰る。結末の役割を重複させない。
- Mimo・Luke・Genの絵本と同じ人物の造形・柔らかな輪郭・白い不透明の面。動物を解決役として追加しない。
- 短い文と絵を交互に置き、沈黙のコマも使う。杏色は温かさ、ベージュは休息、観察や背景のある場面は座布団なしを基本にする。
- 全素材を入れたかより、気持ちと行動がつながるかで編集する。未使用の素材IDは下の一覧に残し、独立制作へ自動で増やさない。

### 視点と読者を先に決める

- **ママのための絵物語**：母の一人称。診断時の衝撃や仕事との両立などを描ける。子どもに親を慰める役を担わせない。
- **親子・きょうだいで読む絵本**：子どもが知りたいことから始める。母の内心を全て説明せず、本人たちの問い・好き・選択を描く。
- **家族・支援者に渡す短編**：誰かを責めるためでなく、見えていなかった負担や、助かった一言を共有する。
- 同じ題材でも読者が違えば別の語りにする。自己紹介Webtoonの「バディ一人称」をこのシリーズへ機械的に当てはめない。

### 一緒に思い出すためのメモ

各候補について、答えられる範囲で以下を埋める。全項目を埋める必要はなく、まだ言葉にしたくない箇所は空欄でよい。

1. 子どもは何歳頃？ きょうだいは何歳？ 診断からどれくらい経っていた？
2. どこで、誰と、何が起きた？ 出来事の前は何を期待していた？
3. その場で口にした言葉と、言えなかった言葉は？
4. 怒り・悲しみ・喜び・安堵のうち、何と何が同時にあった？
5. 誰の一言、どんな行動が残っている？ 何があれば少し違った？
6. そのとき子どもが実際にしていたことは？ 親の推測と分けて書ける？
7. 一枚だけ絵にするなら、手・物・場所のどこを描く？
8. 今も解決していない部分は？ 読後に「分かってもらえた」と感じてほしいのは誰？

実話をもとに公開する場合は、子ども・きょうだい・関係者の意向と識別される情報を確認する。診断や進路の具体的な制度説明は、台本化する時点の地域・時期に合わせて別途調べる。

### 各場面を支える4つの力｜M01〜M26

以下は絵本を設計するための支援場面の案で、実際に起きた出来事や、誰にでも有効な解決策ではない。本人・家族の希望を確かめて具体化する。

「自分での悟り」は、**そのとき少し気づけたこと／自分に許せたこと**として扱う。気づけなくてもよく、受容や前向きさを物語の合格条件にしない。周囲・専門家・家族の行動によって、初めて気持ちの余裕が生まれる順番も描く。

| 支え | 主な役割 | 絵で見せること |
|---|---|---|
| 自分の気づき | 自責や「こうあるべき」が少し緩む。望みや限界に気づく | 書き直す、手を止める、話す、今日は決めない |
| 周囲の手助け | 孤立や参加の障壁を減らす。友人・同じ経験の親・職場・地域など | 隣に座る、誘い方を変える、具体的な用事を引き受ける |
| 専門家の助言・行動 | 分かることと分からないこと、選択肢、相談先を整理し、調整を一緒に進める | 紙に整理する、本人の反応を見る、関係者をつなぐ |
| 家族の手助け | 生活と判断の責任を分け、親子・きょうだいそれぞれの時間を守る | 予約・付き添い・説明を担当し、休む時間をつくる |

家族は配偶者・祖父母などに固定しない。身近な大人がいない場合、同じ役割を相談先や利用可能な支援へつなぐ設定にする。きょうだいを当然のケア担当にせず、家族への開示や分担も本人の望みと安全を確かめる。

### 絵本へ落とすときの選び方

一冊に4種類すべての支えを詰め込まない。**主な支え一つ＋短い補助一つ**を選び、変化を小さな行動で描く。「専門家が教える→母が悟る」だけの型を繰り返さない。

| 候補 | 主な支え | 物語で見せる転機 | 残してよい未解決の気持ち |
|---|---|---|---|
| M06『送信する前に』 | 自分の気づき＋家族 | 全員宛ての長文を、伝えたい一人への短い文にする。家族が送るかどうかの判断を急かさない | 返事が怖い。まだ伝えない相手もいる |
| M20『予定表に、わたしがいない』 | 家族＋職場 | 母が書き足すばかりの予定表に、別の人が自分の担当を書く | 忙しさは消えない。それでも一人で調整しなくてよくなる |
| M12『覚えていてくれたんだ』 | 周囲・支援者の行動 | 母が説明しようとしたとき、相手が本人の好きな道具を用意していた | 任せる緊張はあるが、少し手を緩められる |
| M13『きみの学校を、さがす日』 | 専門家の整理＋家族 | 資料の学校名を比べる手が止まり、「きみの一日」を本人と描き始める | まだ決められない。次に聞くことは見つかった |
| M15『楽しみにしていた日なのに』 | 主催者・同行者 | 母の説得ではなく、周りが休む場所や参加の仕方を変える | 以前の悔しさまで消えたわけではない |
| M02『その日のことばは、まだ』 | 家族の生活支援＋専門家の聞き直せる説明 | 答えを出さない母のそばに、食事が置かれ、次に話せる日が紙に残る | まだ受け止められない。それでも今日を一人で過ごさなくてよい |

制作時には「誰が正しい助言をしたか」より、**その後、誰の手がどう動き、何を一人で抱えなくてよくなったか**を確認する。気持ちが晴れる結末だけでなく、言葉にできた・決めずにいられた・誰かが隣にいた、という終わり方も残す。

#### 2本それぞれの全体の流れ（編集上の読み取り）

- **A：暮らしの中で、支えの意味が変わっていく。** 不安と孤立 → 人との接点 → 場所や方法を探し回る → 生活の負担に気づく → 本人に合う暮らしを考える。大きな悟り一つで変化した話にしない。
- **B：誰かが決めた未来から、その子と探す未来へ。** 制限から始まる説明 → 用意された環境への疑問 → 情報で解決しようとする → 個別に見る視点 → 関係や環境をつくる行動。起業の経緯を4編に全部入れるより、シリーズの編集軸として使う。

#### 4編へ組み直す案（ここからは創作上の構成）

**1｜先が見えないまま、今日を過ごす**

出会う前の期待 → そばにいられない出産後 → 未来を聞いても答えがつかめない → 他の親の喜びが遠く感じる → 夫も揺れる → 説明を聞き直す・食事を分ける → 今日の子のしぐさを一つ見る。

結末は受容や決意ではなく、その日を一緒に過ごせたこと。Mimoは最後の小さな観察にのみ登場。つらい診断の場面で明るい解説役にはしない。

**2｜見られるのが怖いところから、見てもらえる関係へ**

伝えるのを避ける → 運動会で比較する → 園の一人の姿を見て胸が詰まる → 母の推測と実際の様子を分けて尋ねる → 先生も関わり方を変える → 子の好きが人との接点になる → 話せる相手が少し増える。

既存の運動会・きょうだいの台詞は創作として維持し、記事の出来事と混同しない。Mimoは隣で遊び、先生が観察を持ち寄る。母が開示を決意したから全て変わった、とはしない。

**3｜受け入れ先を探すことから、過ごし方を一緒につくることへ**

行きたい場所 → 見学 → 入れた後にも難しさ → また入口に立つ → 子が何を楽しむかを確かめる → 受け入れる側が時間・距離・休憩を変える → 合う部分と合わない部分を話せる → 将来の場所にも同じ問いを持っていく。

既存の「一度断られ、相談したら進む」を、調整と揺り戻しのある流れへ。LukeとGenだけでなく、園・施設の人が変える行動を描く。遠くの園や自然活動を唯一の正解にはしない。

**4｜良い支援を増やすことから、続けられる生活を選ぶことへ**

良いと言われる予定を入れる → 送迎にも時間がかかる → 着いたときには親子が疲れている → 自分の仕事やきょうだいの時間がこぼれる → 家族にも疲れが伝わらずすれ違う → 移動・準備・連絡を可視化する → 支援側も量と通い方を相談する → 分担と、自分の予定を一つ残す。

『予定表に、わたしがいない』の題名は維持。「パパが引き受ける」だけでなく、支援の組み方自体も変わる。Lukeは提案をしまう側にもなる。本文を増やすより、既存の抽象的な予定説明を送迎の一場面へ置換する。
