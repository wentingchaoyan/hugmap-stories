# 手先の発達 stage ごとのコンテンツ構成案

作成日: 2026-08-29  
対象: 保護者向け「感覚・手・道具」stage 詳細

## 1. 構成方針

手先の発達は、指の器用さだけで説明しない。**見る・感じる・姿勢を保つ・届く・力を調整する・両手を分担する・道具を選ぶ**の組み合わせとして見せる。

- **S / 1場面・3レンズ**: 一つの感覚または手の動きを深く見る
- **M / 3場面ストーリー**: 持つ・運ぶ・離すなど操作の連鎖を見る
- **L / 3場面＋道具・姿勢バリエーション**: 制作や生活参加まで広げる

3レンズは、①興味と感覚、②姿勢と手の動き、③物・道具・環境、とする。

## 2. productionとの対応

2026-08-29時点のproduction「手先の発達」の有効な `category_stage` は7件。

- 目と手の協調性、握る・つまむ、運ぶ・離す、積み木・パズル、道具操作、描く・書く、ハサミ

イラスト棚は10 stageで、「動くものを目で追う」「声や音に気づく」「触り方や感じ方を自分で選ぶ」「両手を一緒に使う」を含み、productionの道具操作・ハサミを生活場面に合わせて再編集している。感覚stageを正式に手先カテゴリへ含めるかは、OT領域として意図を明文化する必要がある。

## 3. 全ページ共通要素

- 子どもが触りたい／避けたいもの
- 見え方、音、触覚、固有感覚
- 骨盤・体幹・肩・肘・手首の支持
- 握る、運ぶ、回す、離すのどこで難しくなるか
- 片手・両手・利き手に固定しない別ルート
- 道具の太さ、重さ、摩擦、固定方法
- 「完成」ではなく本人の選択と参加
- 誤飲、刃物、熱、痛みなど安全条件

## 4. 10 stageの推奨構成

### 1. 動くものを目で追う

**推奨: S / 1場面・3レンズ**

- 興味: 何なら気づきやすいか
- 身体: 頭を大きく動かさず追う／頭ごと向くなど現れ方
- 環境: 距離、速度、背景、照明、コントラスト
- 別ルート: 音や触覚と組み合わせる、物を近づける
- しなくてよいこと: 目の前で速く何度も往復させる

現状0枚。左右への追視だけでなく、背景を整理した近距離場面を1〜2枚作る。

### 2. 声や音に気づく

**推奨: S / 1場面・3レンズ**

- 興味: 好きな声や予測できる生活音
- 身体: 止まる、表情が変わる、身体を向けるなどの応答
- 環境: 雑音、距離、補聴機器、視覚・触覚の手がかり
- 別ルート: 光、振動、身ぶりを組み合わせる
- しなくてよいこと: 背後から繰り返し驚かせて反応を試す

現状0枚。手先stageとの関係が薄く見えるため、「音へ手を伸ばす／鳴らして確かめる」場面へ接続する。

### 3. 触り方や感じ方を自分で選ぶ

**推奨: L / 3場面＋感覚強度バリエーション**

場面: 見る → 道具越しに触る → 自分から直接触る／触らないを選ぶ

- 「触れた」を最終到達点にしない
- 素材、温度、匂い、音、汚れ、予測可能性を分ける
- 別ルート: 袋越し、筆、スプーン、手袋、短時間
- ヒント: 見るだけも参加。退く・拭く・終える方法を先に用意する
- しなくてよいこと: 嫌がる素材へ慣れさせるため手を入れる

### 4. 見ながら手を伸ばす

**推奨: M / 3場面ストーリー**

場面: 物へ気づく → 届く姿勢を作る → 触る・取る

- 手だけでなく、頭・体幹・肩・距離の調整を見る
- 別ルート: 物を近づける、前腕支持、トレー、スイッチ、視線選択
- ヒント: 物を遠ざけて訓練せず、少しの動きで成功できる位置から始める
- しなくてよいこと: 欲しい物を届かない所へ置き続ける

現状0枚。姿勢支援あり／なしの比較ではなく、支援により手が自由になる場面を作る。

### 5. にぎる・指でつまむ

**推奨: M / 3場面ストーリー**

場面: 手のひらで持つ → 指を分けて扱う → 用途に合う持ち方を選ぶ

- ピンサーグリップを唯一の完成形にしない
- 大きさ、重さ、表面、持ち手の形を変える
- 別ルート: 両手、手の側面、適応グリップ、面ファスナー
- ヒント: 小さくする前に、本人が操作しやすい物で目的を達成する
- 安全: 小物は誤飲リスクを明示する

### 6. 運ぶ・離す・容器に入れる

**推奨: M / 3場面ストーリー**

場面: 持つ → 目的地へ運ぶ → 狙った場所で離す

- 落とす遊びも因果関係を確かめる活動として扱う
- 容器の大きさ、縁、音、滑り止めで成功条件を変える
- 別ルート: 容器を固定する、前腕を支える、傾けて入れる
- ヒント: 「離して」より、縁へ触れる・音が鳴るなど終点を分かりやすくする
- しなくてよいこと: 手を開かせるために強く叩く・マッサージする

### 7. 両手を一緒に使う

**推奨: L / 3場面＋役割分担バリエーション**

場面: 両手で一つを持つ → 片手で支え片手で動かす → 左右を交代・選択する

- 左右対称だけでなく、支持手と操作手の分担を見る
- 片麻痺などでは、弱い側の使用を強制せず、参加目標と専門的支援を分ける
- 別ルート: 物を固定する、クランプ、滑り止め、片手用道具
- ヒント: 両手使用そのものより、本人の目的が達成できる方法を探す
- しなくてよいこと: 利き手を決める／使いにくい手だけでやらせる

productionに独立stageがないため追加設計が必要。

### 8. 積む・はめる・形を作る

**推奨: L / 3場面＋遊び方バリエーション**

場面: 動かして変化を知る → 積む・並べる・はめる → 自分の形やルールを作る

- 完成見本への一致だけでなく、崩す、並べる、回すも遊びとして扱う
- 認知的な形合わせと、手の操作を分けて説明する
- 別ルート: 大きい取っ手、磁石、縁付き盤、部品数を減らす
- ヒント: どこで止まるかを「見る／持つ／向ける／離す」に分ける
- しなくてよいこと: 大人が手を重ねて完成させる

### 9. 描く・線や形をまねる

**推奨: L / 3場面＋表現手段バリエーション**

場面: 跡がつく → 線や色を選ぶ → 形・文字・意味へ広げる

- 握り方の正しさより、疲労なく意図した跡を残せるかを見る
- 姿勢、紙の固定、傾斜台、道具の太さ、筆圧を分ける
- 別ルート: スタンプ、指、太いクレヨン、タブレット、キーボード、視線入力
- ヒント: 「何を描いた？」より、選んだ色や動きへコメントする
- しなくてよいこと: 三点持ちになるまで表現活動を待たせる

### 10. 切る・貼る・紙で作る

**推奨: L / 3場面＋道具バリエーション**

場面: 素材を変える → 一回切る／はがす → 選んだ場所へつなげる

- ハサミ操作を、開閉・紙の支持・進行方向に分ける
- 別ルート: バネ付きハサミ、卓上ハサミ、ちぎる、型抜き、テープ、接着面を固定
- ヒント: 完成品より、本人が選んだ位置や素材を残す
- しなくてよいこと: 手を重ねて連続切りを完成させる
- 安全: 刃物、誤飲、接着剤の扱いを別枠で示す

## 5. 障害特性を考慮した読み替え

| 観点 | 難しさとして現れやすいこと | 表示する別ルート |
|---|---|---|
| 低緊張・姿勢の不安定さ | 肩や手首の安定、持続、疲労 | 適合座位、前腕支持、傾斜台、短時間、太い道具 |
| 片麻痺・両手機能の差 | 支持手、手を開く、到達、両手分担 | 物の固定、片手用道具、環境配置、専門家と設定した能動課題 |
| 視覚の難しさ | 到達、形合わせ、線、背景から対象を探す | コントラスト、触覚輪郭、実物、大きい部品、音による結果 |
| 触覚過敏・感覚探索 | 素材回避、力加減、汚れ、強い刺激を求める | 道具越し、予告、選択、終了手段、素材・強度の調整 |
| 運動企画・協調の難しさ | 手順、方向、複数動作、模倣 | 一工程ずつ、始点と終点を見せる、固定具、反復可能な生活課題 |
| 知的・言語理解の難しさ | 道具の目的、複数指示、見本理解 | 実演、写真手順、物を一つずつ提示、選択肢を減らす |

「手先が不器用」という一語でまとめず、入力（見える・感じる）、姿勢、運動出力、道具、課題理解、意欲のどこが障壁かをページ内で分ける。

## 6. データと制作の優先順位

1. 感覚3 stageを手先カテゴリの正式stageにするか決める。
2. 「両手を一緒に使う」を独立stageとしてproductionへ正規化するか決める。
3. S/M/L試作は、触り方を選ぶ／運ぶ・離す／切る・貼る、の3本から始める。
4. 最優先イラストは0枚の「動くものを目で追う」「声や音に気づく」「見ながら手を伸ばす」。
5. 既存画像にも、適合座位、滑り止め、太い道具、片手操作など環境調整が自然に映る場面を追加する。

## 7. ガードレール

- ピンサーグリップ、三点持ち、利き手を唯一の完成形にしない。
- 感覚回避をわがまま、反復操作を遊び方の誤りとして扱わない。
- 手を重ねて動かす介助を一般的ヒントにしない。
- 道具や固定具による成功を「自力ではない」と低く扱わない。
- 痛み、急な機能低下、強い左右差、日常参加の大きな制限は家庭練習だけで解決させない。

## 8. 主な根拠

- AACPDM, Central Hypotonia Care Pathway: 安定した適合座位は、リーチ・把持・操作と遊びの学習機会を増やす。活動は子ども主導・能動的であることを重視する。
- AACPDM, Early Detection of Cerebral Palsy Care Pathway: 手の機能を含む介入は、意味のある課題と環境の中で目標志向に行う。
- WHO, Assistive Technology: 支援製品は自立と参加を高め、本人の機能を維持・向上するためのもの。
