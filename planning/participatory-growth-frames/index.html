HUGMAP PARTICIPATORY GROWTH FRAMES

子どもの姿が入って、
はじめて物語になる。

淡い人型は、お子さんの写真が入る位置とポーズを示す枠です。子どもの身体や仕草をキャラクターが受け取り、二人の間に視線、動き、形が生まれることで完成します。

CHEER｜そばで応援途中、休む、また試す時間を残す MILESTONE｜育ちの瞬間今見えている姿勢や動作を残す TOGETHER｜関係の中で育つ求める、応える、待つ往復を残す
ゲン｜動く・休む ミモ｜伝える・つながる ルーク｜触る・作る 関係の中で育つ

遊びの家族と、保護者への質問

似たカードを一つの遊びの流れとして見て、写真に写らない意図や繰り返し方は、保護者の観察から受け取ります。

画像は「写真で見える姿勢」の代表です。選択肢は達成判定ではなく、今日どんな楽しみ方だったかを複数選べる問いとして使います。

発達は一本の階段ではないため、15の入口を5つの並行する軸に分けています。軸同士には前後関係をつけず、各軸の中だけを、おおよそ「入口から複雑な遊びへ」と並べます。近い遊びを選び、代表フレームで写真を撮ったあと、一問だけ答えることで、その子らしい方法を記録できます。

01｜からだと姿勢

身体の形が変わる

仰向け → 手足が中央へ → 寝返り → うつ伏せ → 座る

今日は、どんな身体の使い方をしていましたか？

手足を見つけた横を向いた寝返った頭を上げた座って支えた
02｜移動する

行きたい方へ進む

ハイハイ → くぐる → 歩く → 階段 → 走る → 跳ぶ

今日は、どうやって移動していましたか？

手と膝で進んだ狭い所をくぐった歩いた段差を進んだ走った跳んだ
03｜公園と順番

見る、待つ、やってみる

立ち止まる → 観察する → 並んで待つ → 滑る・揺れる

遊具へ近づいたとき、どんな様子でしたか？

まず見ていたまだ進まなかった前の子を待った番に気づいた自分から始めた
04｜ボール

離す、送る、受ける

見る → 離す → 転がす → 蹴る → 投げる → 受ける

今日は、ボールをどう楽しんでいましたか？

動きを見た手を離した転がした蹴った投げた受けようとした交互に続けた
05｜見る・伝える

興味の先を分け合う

目で追う → 見続ける → 指差す → 見せる → 一緒に見る

興味のあるものを、どう伝えていましたか？

見つめた目で追った指差した持ってきた見せた一緒に見た
06｜まねる・生み出す

こんどは、わたしが見本

表情・声 → 身体 → 道具 → 他児 → 後から再現 → 自分の形

どんな「まね」が起きていましたか？

表情声や音身体の動き道具の使い方他の子の遊び後から再現自分の動きを加えた
07｜隠す・見つける

見えなくても、つづいている

隠れた物を探す → 自分が隠れる → 相手を探す → 交代する

今日は、どちらを楽しんでいましたか？

隠れた物を探した自分が隠れた見つかるのを待った相手を探した役を交代した
08｜ごっこ

ふりから物語へ

飲食のふり → 相手へする → 見立てる → 手順 → 役割 → 注文・交換 → 物語

遊びの中で、どんな物語がありましたか？

飲食のふり人形へした別の物に見立てた手順を続けた役になった注文を聞いた売り買いした生活動作をまねた役を分けた物語を続けた
09｜感覚遊び

触り方を自分で選ぶ

触れる → 握る → 落とす → 押す → 移す → 繰り返す・やめる

どんな触り方をしていましたか？

触れた握った落とした押した丸めた移した繰り返したやめることを選んだ
10｜探求・原因と結果

こうしたら、どうなる？

動かす → 変化を見る → 繰り返す → 方法を変える → 予想する

動かしたあと、どんな様子でしたか？

変化を見たもう一度した違う方法を試した結果を待った次を予想していた
11｜組み合わせ・構成

部分をつないで、何かになる

運ぶ・置く → 積む・並べる → 同じ物を合わせる → 部分と空白を見比べる → 向きを変える → 全体・見立て・共同

今日は、物をどう組み合わせていましたか？

運んだ一個置いた積んだ並べた同じものを合わせた空いた場所を見たピースを回した試し直した何かに見立てた一緒に作った
12｜描く・作る

跡から、形と物語へ

点 → 往復 → 線 → 円や形 → 色を広げる → 描いた物を語る

紙の上で、何を楽しんでいましたか？

点をつけた手を往復した線を描いた形をまねた色を広げた物らしい形名前をつけた
13｜状況・ことば

わかったことを、相手へ届ける

身近なことばに気づく → いつもの流れを予測する → 示す・選ぶ → 相手の応答を見る → 出来事を伝える

ことばや場面から、どんなことを受け取り、どう伝えていましたか？

名前を聞いて見た指した方を見た次の流れを予測した物を持って伝えた二つから選んだ身振りや声で返した相手の応答を見た起きたことを伝えた
14｜日常生活

自分でする、助けを求める

食べる・飲む → 着る → 片づける → 手伝いを求める

今日は、どこを自分でしていましたか？

口へ運んだコップを持った袖へ手を通した物を戻した手伝いを求めた途中まで自分でした
15｜関係・ルール

近くで遊ぶ、関わる、一緒に作る

自分の遊び → 少し離れて見る → 同じ場所で別々に遊ぶ → 見せる・渡す → 待つ・順番 → 助ける → 共通の目的で作る

ほかの子が近くにいるとき、どんな遊び方をしていましたか？

自分の遊びを続けた少し離れて見た同じ場所で別々に遊んだ相手の動きをまねた物を見せた・渡した待った・順番を守った同じ材料を使った一つの物を一緒に作った出入りを自分で選んだ

ここでは、写真姿勢をキャラクターから選べます。
同じ遊びの細かな段階は「発達軸から見る」タブの質問で記録し、身体の形や撮影場面が明確に異なるときだけ、別のフレームを選びます。

ゲン｜うさぎ先生

姿勢、足元、バランス、疲れ方を見て、その子の速さと参加方法へ合わせます。

子どもが前。ゲンは横か一歩後ろ。立つ、歩く、休むを優劣にせず、同じ時間を一緒に過ごします。
LOW VIEW

ひくいところで、こんにちは

子どもがうつ伏せになると、ゲンも同じ高さへ。二人の視線が小さなボールで出会います。

軽く見る発達うつ伏せで前腕を支えにする／頭を上げる／目の前の物を見る

写真の姿勢：うつ伏せ・頭を上げた横向きまたは正面

TOGETHERCRAWL & CHASE

まって、ゲン

子どもが手と膝で前へ進むと、ゲンも少し先を低い姿勢で進み、振り返ります。追いつくことより、同じ方向へ動く遊びを残します。

二人の間で起きていること両手と両膝で身体を支える／手足を交互に出して進む／動く相手へ自分から近づく

写真の姿勢：手と膝を床につき、片膝を前へ出してゲンを見る。大人は撮影側

MILESTONETHROUGH & OUT

むこうまで、くぐった

子どもの頭と両手がトンネルの向こう側へ現れます。ゲンは出口を塞がず、身体が全部出てくる場所を横で空けています。

この姿勢・動作で見えること手と膝で狭い場所を進む／入口と出口をつなげる／身体の位置を確かめながら外へ出る

写真の姿勢：トンネルから出る途中。両手を出口の外へ置き、片膝はまだ中に残す。大人は撮影側

REACH

ここまで、とどいた

伸ばした手の先へ、ゲンが短いリボンを返します。子どもの腕とゲンの腕が一本の線になります。

軽く見る発達座った姿勢を保つ／斜めへ手を伸ばす／目と手を一緒に使う

写真の姿勢：座位・片手を斜め上へ伸ばす

TOGETHERROLL & RETURN

ころころ、そっちへ

子どもが床へ手を伸ばしてボールを放すと、ゲンは道を塞がず、低い姿勢で受け取る形をつくります。次に返せる余白も残します。

二人の間で起きていること座って手を前へ伸ばす／物を意図して放す／相手と順番に送り返す

写真の姿勢：床に座り、片手をボールの後ろへ伸ばす。大人は撮影側

BALANCE & IMITATE

おなじ傾き

子どもが片足を上げて両腕を広げると、ゲンも隣でその形をよく見て、同じ膝と腕の形を小さく返します。

軽く見る発達片足へ体重を移す／腕でバランスをとる／相手の身体の動きを見てまねる

写真の姿勢：両腕を横へ広げ、片膝を曲げて片足で立つ。大人は撮影側

BALL

そっちへ、どうぞ

子どもの足とゲンの足の間にボールを置き、送る・受け取るの往復をつくります。

軽く見る発達片足で立つ／足を前へ出す／ボールへ足を合わせる

写真の姿勢：横向き・片足をボールへ向ける

REST

並んで空を見る

何かを頑張る時間ではなく、同じ場所で一緒に休む時間を残します。

軽く見る発達仰向けで身体を休める／視線を上へ向ける／安心して静かに過ごす

写真の姿勢：仰向け。手足の位置は自由

MILESTONEBODY DISCOVERY

あし、みつけた

子どもが仰向けで両足を手に取ると、隣のゲンも膝を胸へ寄せ、自分の足をつかんで同じ形を返します。

この姿勢・動作で見えること股関節と膝を曲げる／手で自分の足をつかむ／身体の中央で手足を出会わせる

写真の姿勢：仰向けで両膝を胸へ寄せ、左右の手でそれぞれの足を持つ。大人は撮影側

MILESTONEROLL & IMITATE

ころん、をいっしょに

子どもが膝と腕を向こう側へ運び、身体を横へ向け始めると、ゲンも隣で同じ丸い形を返します。

この姿勢・動作で見えること脚を身体の反対側へ動かす／肩と腰の向きを変える／仰向けから横向きへ移る

写真の姿勢：仰向けから横向きになる途中。片膝と片腕を身体の反対側へ。大人は撮影側

MILESTONESTAND & TWIST

つかまったまま、くるり

子どもが片手を台へ残したまま胸と顔を横へ向けると、ゲンも隣で同じひねりを返します。

この姿勢・動作で見えること片手で身体を支える／両足で立位を保つ／腰と肩を違う向きへ動かす

写真の姿勢：低い台へ片手を置き、足と腰を残したまま胸・顔・反対の腕を横へ。大人は撮影側

MILESTONEPUSH & WALK

押す道の、少し前

子どもが両手で車の取っ手を押して一歩進むと、ゲンは触れずに少し先から同じ道を示します。

この姿勢・動作で見えること両手で支持物を押す／身体を少し前へ傾ける／足を交互に出して進む

写真の姿勢：安定した四輪手押し車の取っ手を両手で持ち、片足を前へ。大人はすぐ支えられる撮影位置

MILESTONEPEDAL & STEER

こぐ足の、そのあとを

子どもがハンドルを握り、片足でペダルを押すと、ゲンは後ろから同じ行き先へ走ります。

この姿勢・動作で見えること両手で進行方向を調整する／左右の足でペダルを踏む／座った姿勢で前へ進む

写真の姿勢：三輪車へ座り、両手をハンドルへ。片膝を上げ、反対の足でペダルを押す。安全な場所で大人が撮影

MILESTONEBOUNCE

しずんで、ぽん

子どもがトランポリンを両足で沈ませて浮くと、ゲンも安全な外側で小さく同じ形を返します。

この姿勢・動作で見えること両膝を一緒に曲げ伸ばす／両足で面を押す／上下の動きに合わせて姿勢を保つ

写真の姿勢：低いトランポリンの中央で両足をそろえ、膝を曲げ、腕を横へ。大人は手の届く位置

REST

寄りかかって、ひと休み

子どもが少し後ろへ寄りかかると、ゲンも同じ角度で隣へ座ります。

軽く見る発達座る／手で身体を支える／自分に合う姿勢で休む

写真の姿勢：床座り・両手を後ろへ

CURIOSITY

同じ小さなものを見る

虫や葉っぱ、おもちゃなど、子どもの興味の先へゲンも並びます。

軽く見る発達興味のある物を見続ける／同じ対象へ注意を向ける／楽な姿勢を選ぶ

写真の姿勢：うつ伏せ・頬や顎を手に置く

FOLLOW

歩く子どもの、二歩あと

子どもが行き先を決め、ゲンは同じ方向へ後ろからついていきます。

軽く見る発達前へ歩く／左右へ体重を移す／自分のペースで移動する

写真の姿勢：歩く後ろ姿。日常の写真をそのまま使える

MILESTONESQUAT & PICK UP

しゃがんだ先に、みつけた

子どもが両足を床につけたまま腰を下げ、小さな物へ手を伸ばします。ゲンも隣で同じ高さへしゃがみ、物を取らずに子どもの発見を見ます。

この姿勢・動作で見えること両足で体重を支える／膝と股関節を曲げて腰を下げる／床の物へ手を伸ばす／拾って立位へ戻る

写真の姿勢：両足を少し開いて深くしゃがみ、片手を床の物へ。反対の腕でバランスを取る。大人は撮影側

TOGETHERLEAD BY HAND

こっち、いっしょに

子どもがゲンの手を取り、自分の行きたい方へ一歩先に進みます。ゲンは引き戻さず、子どもの示した方向へ一緒についていきます。

二人の間で起きていること相手の手を取って意図を伝える／行き先を示す／相手がついてくることを確かめる

写真の姿勢：一歩前へ進み、片手を後ろへ伸ばしてゲンの手を引く。反対の手で行き先を示す。大人は撮影側

MILESTONERUN TOGETHER

走る子どもの、そのあとを

子どもが先に駆け出すと、ゲンも少し後ろから同じ行き先へ。追い越さず、子どもの速さを楽しみながら追いかけます。

この姿勢・動作で見えること腕と足を交互に動かす／地面を蹴って進む／走りながら姿勢を保つ

写真の姿勢：走る後ろ姿。肘を曲げ、片膝または後ろ足が上がった瞬間

MILESTONETWO-FOOT JUMP

ぴょん、の少しあと

子どもの両足が地面を離れたあと、ゲンも小さくぴょん。先に跳ぶ子どもの動きを、少し遅れて返します。

この姿勢・動作で見えること両膝を曲げる／両足で地面を蹴る／空中と着地で姿勢を調整する

写真の姿勢：両足が同時に床を離れ、腕を上げた瞬間

MILESTONEDRESSING

おてて、でてきた

子どもが自分で袖へ腕を通し、反対側から手が現れます。ゲンは手を貸さず、出てきた手と同じ高さで見守ります。

この姿勢・動作で見えること袖口へ腕を向ける／反対の手で衣服を支える／手が出るまで腕を伸ばす

写真の姿勢：座って片腕を横へ伸ばし、もう一方の手で服の前を持つ。大人は撮影側

FOLLOW

階段の、一段あと

子どもが先に一段上り、ゲンは触れずに一段後ろから同じ速度で進みます。

軽く見る発達段差へ足を上げる／片足で身体を支える／手すりを使って進む

写真の姿勢：安全な階段を上る後ろ姿

MILESTONESTEP DOWN

おりる足を、一段下で

子どもが手すりを持ち、足元を見て一段下へ足を運びます。ゲンは進路を塞がない下側で止まり、手を出さず次の足場を見ています。

この姿勢・動作で見えること片足へ体重を残す／もう一方の足を下の段へ運ぶ／手すりと足元を使って姿勢を調整する

写真の姿勢：手すりを片手で持ち、片足を一段下へ伸ばしている途中。大人は撮影側

MILESTONESLIDE

すべる先で、待ってる

子どもが滑り台へ座り、自分の身体で下へ進みます。ゲンは着地点を塞がず横へしゃがみ、手を出さずに動きの先を見ています。

この姿勢・動作で見えること座った姿勢を保つ／重力に合わせて身体を動かす／脚を前へ向けて着地を準備する

写真の姿勢：滑り台の途中で座り、上体を起こして両脚を前へ。大人は撮影側

MILESTONESWING

ゆれる形を、となりで

子どもがブランコで脚を伸ばし、身体を傾けます。ゲンは軌道の外から同じ傾きを返し、押したり止めたりせず動きを見ます。

この姿勢・動作で見えること座面で姿勢を保つ／揺れに合わせて身体を傾ける／脚を曲げ伸ばしする

写真の姿勢：ブランコに座り、上体を少し後ろへ、両脚を前へ伸ばす。大人は撮影側

MILESTONEHANG

にぎった手で、ぶらーん

子どもが低い鉄棒を両手で握り、足を床から離します。ゲンも隣で同じ棒へぶら下がり、支えたり回転を見せたりせず、子どもの身体の形を返します。

この姿勢・動作で見えること両手で棒を握る／腕へ体重を預ける／足を床から離す／膝を曲げて姿勢を保つ

写真の姿勢：低い鉄棒を肩幅で両手握り。肘を伸ばし、両足を少し浮かせ、膝を軽く曲げる。大人は必ず手の届く位置で見守る

CHEERPAUSE

一歩手前で、いっしょに見る

子どもが遊具の前で止まると、ゲンも一歩後ろで止まります。進むことを勧めず、見ている時間を一緒に過ごします。

この場面で守っていること近づく前に観察する／自分のタイミングを選ぶ／まだ進まない選択をする

写真の姿勢：低い遊具や段差の前で立ち止まる後ろ姿

MILESTONEPULL TO STAND

立てた手は、まだここに

子どもが低い台へ手を置き、膝を伸ばそうとします。ゲンは反対側で同じ高さに立ちますが、身体や台には触れません。

この姿勢・動作で見えること支持面へ手を置く／足へ体重を移す／膝と股関節を伸ばす

写真の姿勢：低く安定した台につかまり、立ち上がる途中または立位

TOGETHERHIDE & SEEK

みつけて、ここだよ

子どもが壁の向こうへ身体を隠し、ゲンはまだ違う方を探しています。見つけるまでの期待を二人でつくります。

二人の間で起きていること身体を隠す／相手が探すことを予想する／見つかるまで待つ

写真の姿勢：壁やカーテンから顔・片手・片足だけを出す。大人は撮影側
