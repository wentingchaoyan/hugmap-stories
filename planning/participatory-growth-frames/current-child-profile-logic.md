# 「今のこの子」プロフィール更新ロジック

## 目的

「今のこの子」は発達段階の判定ではなく、本人が現在使っている方法、好きなこと、安心しやすい環境、家族が大切にしたいことを共有するための可変プロフィールである。

診断名や年齢だけから本人像を生成しない。日常記録から候補を提案する場合も、自動反映せず、必ず保護者の確認を通す。

## 情報の3層

### 1. 基本・支援情報 `stable_profile`

変更頻度が低い情報。初回オンボーディングまたは必要時に編集する。

- 生年月日。年齢は自動計算する
- 診断・相談状況。任意、複数選択、自由記述、未診断に対応する
- 医療的ケア、安全上必要な情報
- 補助具、AAC、コミュニケーション機器
- 通園・通学先、支援機関
- 家族、共有メンバー

診断・障害種別をコンテンツ推薦の唯一の条件にしない。年齢は安全性、生活場面、制度情報の絞り込みに使うが、発達内容を年齢で非表示にしない。

### 2. 本人の今 `current_profile`

数週間から数か月で変化する情報。Homeの「今の○○」と学びの推薦に使う。

- `interests`: 好き、夢中、繰り返していること
- `communication_methods`: 視線、表情、声、身ぶり、物、写真、ことば、AAC、距離や行動
- `comforts`: 安心しやすい人、場所、物、感覚、予告
- `difficult_contexts`: 困りやすい場面、刺激、時間帯、変化
- `movement_and_participation`: 本人が使う姿勢、移動、休憩、参加方法
- `current_contexts`: 食事、着替え、外出、園、学校、遊び、睡眠など

各項目は次の状態を持つ。

```text
active       今もそう
changed      少し変わった
inactive     今は違う
candidate    アプリが提案中。未確認
```

### 3. 大切にしたいこと `family_priorities`

本人、家族、必要に応じて支援者が現在注目するテーマ。Homeには最大3件を表示する。

- 好きなことを広げる
- 自分の方法で伝える
- 自分で選ぶ時間を増やす
- 安心できる環境をつくる
- 心地よく体を動かす
- 人とのやりとりを楽しむ
- 家族や支援者が本人を理解する
- 今は記録だけ続ける

## 初回オンボーディング

質問の骨格は固定し、具体例と候補を本人の生活に合わせて変える。

1. 最近、何に夢中ですか
2. どんな方法で気持ちを伝えていますか
3. どんなときに安心していますか
4. 今、気になっている場面はありますか
5. 今、一緒に大切にしたいことは何ですか
6. 必要な基本・支援情報を登録しますか
7. 生成された「今の○○」を確認、修正する

自由記述と「今は特にない」「入力しない」を常に用意する。

## 定期チェックイン

### 軽い確認

- 目安: 2〜4週間ごと
- 表示: Home上の1問
- 例: 「小さいものを見つける」は今も好きですか
- 回答: 今もそう / 少し変わった / 今は違う

### まとまった見直し

- 目安: 3か月ごと
- 所要時間: 2〜3分
- 前回内容を保持し、差分だけ確認する
- 全項目への再回答を要求しない

### 出来事による見直し

次の場合は関連する項目だけを確認する。

- 入園、進級、転園、引っ越し
- 新しい支援や補助具の開始
- 診断、支援計画、医療情報の更新
- 保護者が「最近変わった」と記録した
- 同じテーマの記録が一定期間に複数集まった

## 行動からの候補生成

候補は次の情報から作る。

```text
家庭の写真・音声・文章記録
+ 園や支援者から共有された記録
+ family_priorities
+ 最近閲覧・保存した学び
```

候補生成の例:

```text
条件:
  30日以内に「新しい場所で離れて見る」に関する記録が3件以上

提案:
  最近「まず離れて見る」が増えています。
  自分のタイミングを選んでいる姿かもしれません。

操作:
  今に追加する / あとで見る / 今は違う
```

件数だけで断定しない。異なる場面や記録者からの情報が重なる場合に候補の確度を上げる。

## 確認と反映

- `candidate` は保護者の承認までHomeや共有プロフィールに表示しない
- AI生成文は文単位で「そのまま / 書き直す / 今は違う」を選べるようにする
- 生成根拠を「最近の4件の記録と、家族が選んだテーマから」のように表示する
- 診断名、障害種別、医療情報から性格や能力を推測しない
- 家族が否定した候補は、同じ根拠だけで短期間に再提案しない

## Home表示文の生成

入力:

```text
承認済みの current_profile
+ 最大3件の family_priorities
+ 最近の代表的な記録
```

出力は2〜3文とタグ3件までにする。

例:

> Tamakiは、小さいものを見つけて誰かに見せることを楽しんでいます。ことばだけでなく、物を持ってくることや距離で気持ちを伝えています。今は「自分で選ぶこと」と「伝わる経験」を一緒に見ています。

避ける表現:

- 年齢相応、遅れている、未達成
- この障害だからこの行動をする
- 次にできるべきこと
- 本人や家族が確認していない断定

## UI構造

「今を見直す」画面は次の3タブで構成する。

1. **今のこの子**: 前回内容との差分確認、記録からの候補
2. **大切にしたい**: 現在のテーマを最大3件選択
3. **基本・支援**: 低頻度で変わるプロフィールと支援情報

保存時には変更内容を要約し、共有プロフィールへ反映される項目を明示する。
