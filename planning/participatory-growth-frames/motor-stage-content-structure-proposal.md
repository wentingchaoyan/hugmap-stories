# 運動発達 stage ごとのコンテンツ構成案

作成日: 2026-08-29  
対象: 保護者向け「からだを動かす」stage 詳細

## 1. 構成方針

運動発達は、動作の完成形より、**自分から始める・支えを使う・休む・行き先を選ぶ・生活へ参加する**過程を見せる。

- **S / 1場面・3レンズ**: 一つの姿勢や動きの中を詳しく見る
- **M / 3場面ストーリー**: 体重移動や支えの変化を追う
- **L / 3場面＋環境バリエーション**: 移動や全身遊びを家庭・園・屋外へ広げる

3レンズは原則として、①子どもの目的、②身体と支持面、③環境・道具・相手の支え、とする。

## 2. productionとの対応

2026-08-29時点のproduction「運動発達」の有効な `category_stage` は6件。

- あおむけ、うつ伏せ、座る、立つ、歩く、走る・ジャンプ

イラスト棚の8 stageは、床での移動を独立させ、後半を「高さを変えて進む」「ボール・乗り物・遊具で遊ぶ」に再編集している。正式運用前に、新stageとして正規化するか、既存stageの詳細セクションとして保持するかを決める。

## 3. 全ページ共通要素

- 今日見つけたい動き1つ
- 子どもの目的・興味
- 支えている身体部位と支持面
- 始め方、続け方、やめ方
- 疲労、痛み、不快、怖さのサイン
- 支えや道具を使う別ルート
- 「しなくてよいこと」1点
- 転倒、呼吸、痛み、左右差、後退など必要時だけ相談導線

## 4. 8 stageの推奨構成

### 1. あおむけで体を動かす

**推奨: S / 1場面・3レンズ**

- 目的: 顔や手足、近くの物へ気づく
- 身体: 手足が中央へ近づく、片側へ重さが移る、休める
- 環境: 届く位置、見やすい方向、衣服や床の摩擦
- ヒント: 動かす量より、自分から始まった小さな動きを待つ
- 別ルート: 重力下で手足を上げにくい場合は横向き、タオル支持、軽い物を使う
- しなくてよいこと: 手足を反復して動かし、完成動作を作る

### 2. うつ伏せで顔や体を上げる

**推奨: M / 3場面ストーリー**

場面: 楽な短時間で支える → 顔を上げて対象へ向く → 手や体重を動かす

- 胸の下のタオル、保護者の胸、横向きからの移行など複数の入り方を示す
- 頭を上げた高さより、呼吸、表情、回復できる姿勢を見る
- ヒント: 起きていて機嫌のよい時に、短く終える
- 別ルート: うつ伏せを強く嫌がる場合は傾斜面や抱っこで前面支持を経験する
- しなくてよいこと: 泣いている時間を「筋力がつく時間」として続ける

### 3. 座って遊ぶ

**推奨: M / 3場面ストーリー**

場面: 支えのある座位 → 手を一つ離す → 斜めへ手を伸ばして戻る

- 一人座りの秒数より、手が遊びに使えるかを中心にする
- 足底、骨盤、机の高さ、座面の滑りを見せる
- 別ルート: コーナーチェア、側方支持、車いす・適合座位も同じstageの参加方法
- ヒント: 支えをなくすより、必要な場所へ必要な量だけ置く
- しなくてよいこと: 倒れそうになるたび、身体全体を固く保持する

### 4. 床で向きを変え、移動する

**推奨: L / 3場面＋移動方法バリエーション**

場面: 向きを変える → 目的物へ近づく → 人や遊びの間を移動する

- ずりばい、四つ這い、寝返り移動、座位移動などを並列に扱う
- 速さやフォームより、行き先を選び到達できることを見る
- 道具ルート: 移動補助具、早期パワーモビリティ、床面調整
- ヒント: 行きたい物を決めるのは子ども。大人は経路を安全にする
- しなくてよいこと: ハイハイを必須の通過点として反復させる

productionには独立stageがないため追加設計が必要。

### 5. 立って体を支える

**推奨: M / 3場面ストーリー**

場面: 安定した面へ手を置く → 足へ重さを移す → 向きを変える／座り直す

- 立てたことと同じ程度に、安全に下りられることを扱う
- 足、膝、骨盤、手の支持の組み合わせを見る
- 別ルート: 立位台、装具、手すり、介助で立位参加を作る
- ヒント: 引き上げず、子どもが押して立てる高さを用意する
- しなくてよいこと: かかとや膝の形を家庭で力づくで修正する

### 6. 歩いて移動する

**推奨: L / 3場面＋生活参加バリエーション**

場面: 支えの間を移る → 止まる・曲がる → 行き先で活動する

- 歩容の見た目より、目的地、疲労、転倒後の回復、生活上の効率を見る
- 場面タブ: 家／園／屋外
- 別ルート: 手すり、歩行器、装具、車いすとの併用。歩くことと車いすを上下に置かない
- ヒント: 距離を伸ばす前に、止まれる速さと休憩場所を作る
- しなくてよいこと: 補助具を「自力歩行までの一時的失敗」と表現する

### 7. 高さを変えて進む

**推奨: L / 3場面＋安全条件**

場面: しゃがんで戻る → 低い段差へ上がる → 手すりで下りる

- 上る・下りるを別の難しさとして示す
- 足場の見え方、手すり、速度、片足支持、恐怖を分ける
- 別ルート: 座って段差を越える、スロープ、昇降機、介助を利用する
- ヒント: 「できる高さ」より「自分で止まって確かめられる高さ」
- しなくてよいこと: 怖さを慣れの不足として押し切る

productionでは「走る・ジャンプ」の一部。独立stageにするなら正規化が必要。

### 8. ボール・乗り物・遊具で遊ぶ

**推奨: L / 3場面＋遊び選択**

場面: 送る・止める → 乗り物で方向を変える → 揺れや高さを選ぶ

- 走る、跳ぶ、片足立ちを合否にせず、速さ・重力・道具への調整として扱う
- 「もう一回」「おしまい」を運動の自己決定として必ず含める
- 別ルート: 大きいボール、座位投球、適応型三輪車、支持付き遊具
- ヒント: 成功する距離・大きさ・速さから始め、子どもが止められるようにする
- しなくてよいこと: 高さ、回数、速度を上げることを上達の中心にする

## 5. 障害特性を考慮した読み替え

| 観点 | 難しさとして現れやすいこと | 表示する別ルート |
|---|---|---|
| 低緊張・関節の不安定性 | 姿勢保持、抗重力運動、疲れ、手を遊びへ使いにくい | 適合座位、短い活動、装具、支持面、休憩 |
| 脳性麻痺・筋緊張の偏り | 選択的運動、左右差、姿勢変換、拘縮・痛み | 目標志向の能動活動、補助具、ポジショニング、専門家との継続評価 |
| 筋疾患・持久力の制限 | 距離、反復、床からの立ち上がり、回復 | ペーシング、早めの移動補助、活動保存、休息 |
| 視覚・前庭感覚の難しさ | 足場、高さ、動く面、方向転換 | コントラスト、触覚的境界、手すり、予告、ゆっくりした入力 |
| 発達性協調運動の難しさ | 複数動作、ボール、階段、遊具 | 課題を一要素ずつ、環境調整、成功しやすい道具、追加の処理時間 |

補助具は「できないことの印」ではなく、探索、選択、友だちとの参加を早く増やす道具として描く。WHOも支援機器の目的を機能・自立・参加の維持向上としている。

## 6. データと制作の優先順位

1. productionにない「床での移動」を独立stageにするか決める。
2. 「高さを変えて進む」「ボール・乗り物・遊具」の2stageと既存「走る・ジャンプ」の関係を整理する。
3. S/M/L試作は、あおむけ／座る／歩くの3本から始める。
4. 既存31枚は十分多い。新規生成より、各stage内で「自力のみ」に偏らず支え・装具・移動補助を含む場面へ差し替えることを優先する。

## 7. ガードレール

- milestoneの月齢をページの主役にしない。
- 正常／異常なフォームという二分法を避ける。
- 痛み、呼吸、疲労、後退、急な左右差は「練習のヒント」で済ませず相談導線へ分ける。
- 家庭向けコンテンツで装具調整、関節操作、歩容矯正を指示しない。
- 受動的に動かされる場面より、子どもが目的を持って能動的に動く場面を優先する。

## 8. 主な根拠

- AACPDM, Central Hypotonia Care Pathway: 活動は目標志向・機能・参加中心で、子どもが能動的に開始し、適合座位や移動機器を早期から活用する。
- AACPDM, Early Detection of Cerebral Palsy Care Pathway: 早期介入は課題特異的・能動的・豊かな環境で行い、自然な生活場面の機能目標を重視する。
- WHO, Assistive Technology: 支援機器は機能、自立、尊厳、社会参加を維持・向上するためのもの。
