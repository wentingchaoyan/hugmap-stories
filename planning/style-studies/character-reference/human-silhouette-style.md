# 人物シルエットの線・色 制作基準 v1.1

対象：子どもと大人の人物シルエット。動物キャラクターには適用しない。

| 要素 | 指定 |
|---|---|
| 子どもの線 | #F59B82、不透明度100% |
| 大人の線 | #F7C6B3、不透明度100% |
| 人物内側 | #FFFFFF、不透明度100% |
| 背景 | #FFFCF7 |
| 接地影 | #EEDCC6、不透明度35% |
| 外線 | 子ども4px／大人3px |
| 内線 | 子ども3px／大人2.5px（袖・裾・指など必要な線のみ） |
| 線端・角 | round |
| 線幅の揺れ | 基準幅の±10%以内を目安 |

1536×1024pxの場面原稿が基準。子ども・赤ちゃんは4/3px、大人は3/2.5px。各役割内では身体の大きさによって線幅を変えない。人物ごとに全高600pxへ正規化する以前の案を置き換える。

768×512pxへの書き出しでは、子どもの外線2px・内線1.5px、大人の外線1.5px・内線1.25px。さらに小さな表示では不要な内線を省略し、輪郭や動作の意味を保つ。

大きな曲線を滑らかにつなぎ、線の縁にごく軽い粒子感を許容。輪郭の途切れ・二重線・光彩・濃いにじみは使わない。影は輪郭線へ混ぜず別レイヤーで管理。

色はsRGB。生成画像の既存素材は数値一致未検証。HTMLの見本は指定値で描画しているが、表示倍率によって画面上の太さは変わる。今後の原稿・修正・書き出しにこの仕様を使用する。
