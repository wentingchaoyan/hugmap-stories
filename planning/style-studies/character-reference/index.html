既存資料から抽出

  • 背景：白〜ごく淡い暖色の紙調、弱いにじみ。描き込まれた室内や風景は省略。
  • 足元：薄い線や影で接地を示す。
  • 主役：子ども・保護者は淡い橙の輪郭。Mimoは小さく脇に配置。
  • 道具：絵カードなど、その場面の行動に必要なものを中心に置く。
  • 補助記号：点・短い線でやりとりや反応を示す。色や数は場面によって異なる。

制作・再利用ルールと出典詳細

固定と可変の境界

固定する動かせる別途決める
採用した骨格比率、顔の基準位置、部位数、結び側、ロゴ原稿、色の役割、人物像の核ポーズ、視線、まばたき、規定内の感情、場面の持ち物、相手との距離、画面内の全体縮尺耳・冠羽・翼・尾の可動範囲、開口上限、衣替え、遠近による見え方、小サイズで省略する線

関節を動かしたり遠近が付いたりすれば、見かけの全高は変わります。立位のピクセル高を全ポーズへ強制せず、同じ骨格・部位比率を保ちます。形を決めたあとに色と線を合わせます。

参照の優先順位

今回ユーザーが指定した原図を最優先にします。以前の文章、試作、実用場面が原図と違うときは原図へ戻します。添付1の服・小物と添付2の寸法は用途別に参照し、両者の小物状態を合成しません。未掲載の演技だけを追加設計します。

再利用用セットの完成形

各キャラにつき、①採用正面＋寸法 ②三面図＋45度 ③顔と表情 ④ポーズと接触 ⑤服・小物・配色 ⑥NG例と小サイズ見本をそろえます。見せるための一枚ボードに加え、制作に渡す個別画像と固定設定を固定ファイル名で保管し、変更履歴はGitで管理します。

生成時の固定文：［キャラID・Gitコミット］の採用正面／三面図を使用。［固定比率・顔・部位・服・小物・線・色］を維持。今回変えるのは［動詞・視線・道具・相手との距離・構図］のみ。［禁止差分］を追加しない。未承認の過去案を混ぜない。

USAGE GUIDE

利用ガイド

造形と世界観を共通にし、何を主役にするかで配色と背景の量を変える。

用途主役・配色背景の使い方
① 発達の姿を探す子どもの動作とやり取り。動物は白い身体＋識別小物の色。白〜生成り。行動に必要な対象物と、机の端・薄い地面など最小限の場所。
② 紹介・相談チャット相談相手のキャラクター。身体も含むカラー表現。紹介・会話開始では部屋全体。一覧は本人中心。会話本文の背面は無地に近づける。
③ 漫画を交えた解説理解してほしい出来事。行動を示すコマは①、案内役を紹介するコマは②。導入で場所を示す → 背景を省いて動作・手元を見せる → 短く補足する。

配色データ

小物の色と質感

道具は背景と共通の淡い木の色・黄色・生成りを使い、細い茶系の輪郭と控えめな陰影で描く。強い光沢・黒い太線・細かな木目は抑える。スカーフ・蝶ネクタイ・胸のマークは上記のブランド色で固定する。眼鏡はキャラクターの輪郭に合わせる。

同じ道具の形と基本色は用途間で共通。発達カードでは細部と影を省き、背景では場所になじませる。木の道具箱・丸い台・無地の黄色いボール・木枠の時計を共通の形とする。

参照する基準

造形・衣装の形は三面図、寸法は寸法図、線はanimal-line-style.json／human-silhouette-style.json、識別小物と胸マークの色はbrand-colors.json、身体の白／カラーと背景量はusage-guidelines.htmlを基準にする。原図の黒い線・胸記号や旧資料の色指定より現在の線・配色仕様を優先する。

アプリの主背景 #FFFFFF と、人物イラストの背景 #FFFCF7 は用途別の指定。カラー版の身体色・LUMIの追加ポーズ／表情は未確定で、掲載例から数値仕様を推定しない。

共通に固定すること

頭・耳・顔・身体の比率、服と小物の形は三面図を基準にする。白い身体の表現とカラー表現は用途別の配色として扱い、未完成／完成の差にしない。色を変える際に造形を変えない。

カラー版の身体色はキャラクターごとに配色表で管理する。現在の白いモデルから任意の色へ塗り替えず、カラーの使用例をそのまま造形の基準にはしない。

①のカードで優先すること

  • 最初に伝えるのは「子どもが何をしているか」。手・指・姿勢・相手との距離を実際のカードサイズで確認する。
  • 動物は子どもの動作へ顔と身振りを向ける。白い身体でも、濃い顔や鮮やかな小物が目立つことに注意する。
  • 強い色は識別小物と、その場面で注目する対象へ絞る。背景は子どもの輪郭より控えめにする。
  • 背景を入れる判断は「行動の理解に必要か」。毎回キャラクターの部屋を示す必要はない。
  • 「まだ見つけていない姿」を紹介するときも、子どもの絵を灰色や失敗表現にしない。状態は文章やUIで示す。

背景を持ち込む量

基本：対象物だけ

ベル・布・ボール・カードなど、その行動に必要なもの。

必要時：場所の一部

机の端、座布団、低い台、薄い地面。対象物に加える場所の要素は、まず1つから。

紹介・導入：部屋全体

工房、音楽室、運動広場、研究室。小さな行動カードには原則使わない。

漫画の基本構成

1コマ目：場所と関わる相手を示す。2コマ目：背景を省き、子どもの動作や手元を大きく示す。3コマ目：相手の応答・条件の違いを見せ、文章で補足する。行動の意味が1枚で伝わる場合は、コマを増やさない。

発達イラストの精査・修正状況を見る

掲載前の確認

  • 縮小しても、子どもの行動が背景や動物より先に読み取れるか。
  • 背景を外しても意味が同じなら、その背景は省けるか。
  • 紹介と行動説明で配色を変えても、同じキャラクターだと分かるか。
  • チャットは本文を読み続けやすく、漫画は1コマごとの要点が明確か。
