# 動物の線仕様

三面図を造形の基準とし、ポーズ・表情へ展開する。
- 輪郭・表情線：#A77C65。目・鼻の塗りと眼鏡：#6B5143。不透明度100%、丸い線端と角。
- 外輪郭4px、内部3px、細部2.5px。眼鏡の線幅は外輪郭と同じ、色は #6B5143。
- 基準画面1536×1024。全高Mimo340／Luke440／Gen488pxを同じ場面へ配置するときの共通線幅。
- 全体の拡縮時は線も同倍率。座位の高さや表情の拡大図で線幅を再定義しない。
- PNGの厳密な色・線幅一致は未検証。数値は制作目標。

詳細：[設定データ](animal-line-style.json)

適用対象はMimo・Luke・Gen。LUMIは今回の改定対象外。線は滑らかな曲線とし、強い筆圧変化や毛羽立ちを加えない。背景を弱めるために動物を半透明にしない。既存PNGの再着色は未実施。
