# りす先生 造形固定ガイド

りす先生の表情・ポーズ差分を作るとき、STEP 01で選んだ第3案を造形の正本として使う。

## 固定するもの

- 頭は真円ではなく、頭頂が緩やかで、左右の頬が少し張り、顎へ向かって狭くなる。
- 耳は小さく低い。耳先に短い2〜3本の毛束を残す。
- 目は小さな縦長の点。左右の間隔を変えない。
- 鼻は小さな横長の楕円。鼻下の線を長くしない。
- 通常の口は短いW形。丸いクマ型のマズルを作らない。
- 頭、胴体、手、足、尻尾の比率を維持する。
- 尻尾を隠しても、同じりす先生に見える。

## 変更できるもの

- 視線、目の開閉、眉、口角
- 首と身体の傾き
- 手足の動きと重心
- 道具、場面ごとの持ち物
- 耳と尻尾の小さな反応。ただし外形と大きさは変えない

## 確認方法

1. 表情と道具を取り除く。
2. マスター輪郭へ半透明で重ねる。
3. 頭、頬、顎、耳が大きく外れていないか確認する。
4. 無表情へ戻したとき、マスターと別のキャラクターに見える案は採用しない。
