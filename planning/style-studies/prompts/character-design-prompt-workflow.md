# HugMap キャラクターデザイン Prompt 制作フロー

作成日: 2026-08-04  
対象: HugMap Stories のキャラクターデザイン制作  
目的: 画像生成を使ったキャラクター制作を、探索から実際の利用場面まで一貫して進める

## 1. 制作工程

キャラクターは、次の6段階で制作する。

1. **草图／ラフスケッチ**
2. **正面图（线稿）／正面線画**
3. **色彩稿／カラーデザイン**
4. **三视图（不带 Pose）／ポーズなし三面図**
5. **代表 Pose 图和情绪图／代表ポーズ・感情表**
6. **实际应用场景／実際の利用場面**

各工程では、すべてを描き直さない。前工程で決まった内容を固定し、その工程で検討する項目だけを変更する。

```text
キャラクターの不変条件
↓
今回の工程と目的
↓
参照画像ごとの役割
↓
今回決める項目
↓
まだ決めない項目
↓
出力形式
↓
維持するもの
↓
避けるもの
```

各 Prompt の最後には、原則として次の一文を入れる。

> **この工程で指定していない要素は再設計しない。前工程で確定した内容を維持する。**

---

## 2. 全工程に共通する固定ブロック

キャラクターごとに、最初に固定ブロックを作る。以降の工程では毎回同じ内容を添える。

### 固定ブロックに含めるもの

- 名前
- 物語上の役割
- 性格を表す3語
- 信じていること
- 最初に見るもの
- 基本の動き
- 強み
- 愛嬌のある弱点
- 身体的特徴
- 衣装
- 反復する視覚記号
- 線と塗りの基本
- 避ける表現

詳細なキャラクター設定は [`world-and-character-guide.md`](../../world-and-character-guide.md) を参照する。

### 種族造形の固定ルール

正面線画で基準形を選んだ後は、表情・感情・ポーズの工程でも次を再設計しない。

- 耳・翼・しっぽの大きさ、位置、輪郭、毛束
- 頭の縦横比、額、頬、顎の輪郭
- 目、鼻、口の基本位置と、通常時の口形
- 頭と身体、手足の比率

特に、りす先生は [`risu-model-lock.md`](../references/risu-model-lock.md) とマスター輪郭を毎回参照し、**小さく低い耳と耳先の短い毛束、小さな楕円鼻、短いW形の口**を固定する。感情を変える際に耳を丸い半円へ変えたり、頭を真円にしたり、鼻下の縦線を長くしたりして、クマ型の顔へ近づけない。尻尾を隠しても同じりす先生に見えることを確認する。

> **表情差は造形差ではない。感情を変えても、無表情へ戻せば正面線画と同じキャラクターになること。**

### 固定ブロック例――うさぎ先生

```text
キャラクター:
HugMap Stories のうさぎ先生。

役割:
伴走型の応援者。子どもに挑戦を強制せず、
その子に合う参加の量・速さ・方法を一緒に探す。

性格:
元気、楽しい、挑戦を好む。
小さな一歩を楽しく応援する。
ときどき張り切りすぎるが、相手の反応に気づくと、
身体を低くし、声と動きを小さくして相手に合わせる。

身体的特徴:
白いうさぎ。
頭が大きく、身体は小さく簡略化されている。
長い耳、短い手足、小さな丸いしっぽ。
点の目、小さな鼻、短い口。
顔の部品は最小限。

衣装:
シンプルなノースリーブのトップス。
複雑な装飾や柄は付けない。

造形上の特徴:
完全な左右対称にはしない。
片耳の角度、片足の位置、肩の高さなどに小さな非対称を持たせる。

基本の線:
細いペン線。
線にはわずかな揺れ、かすれ、欠け、描き直しがある。
滑らかなベクター線にはしない。

避ける表現:
ヒーローのような勝利ポーズ。
成功するまで励まし続ける表現。
大きすぎる笑顔。
過度に幼児的なマスコット表現。
子どもを引っ張ったり、挑戦を強制したりする姿。
```

## 3. 工程1――草图／ラフスケッチ

### 目的

完成度を上げる前に、キャラクターのシルエット、頭身、身体比率、第一印象を比較する。

### 共通比率と性格差のルール

キャラクターごとに体型を完全に別設計せず、シリーズ共通の骨格を先に置く。性格は「太い・細い」などの印象語へ直接置き換えず、そのキャラクターの基本動作に必要な部分だけで表現する。

```text
メイン3人の共通ベース
頭：身体 = 55：45 前後
顔の部品 = 同じ簡略化レベルと配置範囲
手足・翼 = 丸く小さく簡略化
通常表情 = 穏やかで控えめ
自然立位 = 正面、両足を接地
```

共通ベースからの変更は、原則として10〜15%以内に留める。

| キャラクター | 調整する部分 | 目安 | 性格との関係 |
|---|---|---:|---|
| ことり先生 | 頭を大きく、身体・翼・脚を小さくする | 頭：身体 = 58〜62：42〜38 | 小さなサインを受け取り、静かに待つ |
| りす先生 | 手を少し大きくし、身体と足元を安定させる | 頭：身体 = 52〜55：48〜45 | 調べ、比べ、作り、調整する |
| うさぎ先生 | 足を少し大きくし、耳と身体を縦方向へ伸ばす | 頭：身体 = 52〜55：48〜45 | 一緒に動き、小さな一歩を支える |

耳、翼、しっぽは頭身の数値に含めず、種族と基本動作を示す外側のシルエットとして別に比較する。

避けるのは、元気だから筋肉質、静かだから極端に小さい、考えるから頭だけ非常に大きい、食事担当だから太い、という性格・能力と体型の固定的な結び付けである。

5案は、共通ベースを中心とした狭い範囲の比較にする。5体が別キャラクターに見えるほど比率を変えない。

### この工程で決めること

- 頭身
- 頭、胴体、手足の比率
- 耳、翼、しっぽなどのシルエット
- 衣装の大まかな形
- 正面から見た第一印象
- 性格を感じさせる非対称性
- ほかのキャラクターとの差

### まだ決めないこと

- 正確な清書線
- 色
- 衣装の細部
- 完成した表情
- 小道具の詳細
- 背景

### Prompt テンプレート

```text
工程:
キャラクターデザインの第1段階、探索用の草図。

目的:
キャラクターの性格が、シルエットと身体比率だけで伝わる
造形方向を比較する。

参照画像:
添付画像は、種族、基本的な頭身、顔の印象を理解するための参考。
ポーズや線をそのままトレースしない。

出力:
同一キャラクターについて、正面向きのラフデザインを5案。
白い紙面に等間隔で配置する。
すべて自然な直立姿勢とし、大きなポーズは付けない。

5案で比較する項目:
- 頭と身体の比率
- 耳、翼、しっぽの大きさと角度
- 肩幅
- 手足の大きさ
- 衣装の基本形
- 左右非対称の程度

共通比率:
- シリーズ共通の頭：身体 = 55：45前後を出発点にする
- 顔の部品、簡略化レベル、自然立位は全案で統一する
- 性格に関係する部位だけを共通ベースから10〜15%以内で変える
- 耳、翼、しっぽは頭身から除外し、外側のシルエットとして比較する
- 5案が別キャラクターに見えるほど比率を変えない

描画:
薄い鉛筆による探索スケッチ。
補助線、描き直し、重なった線を残す。
線を整えすぎない。
色は使用しない。

重要:
5体は別キャラクターではなく、
同一キャラクターの造形候補として描く。
性格を体型へ直接置き換えず、
キャラクターの基本動作に必要な部位だけを調整する。

避ける:
完成線画、着色、陰影、背景、小道具、
表情差分、アクションポーズ。

この工程で指定していない要素は再設計しない。
```

### 確認基準

- シルエットだけでも誰かわかるか
- 3人を並べたときに見分けられるか
- 小道具がなくても性格を感じられるか
- かわいさだけで造形を決めていないか
- 5案の比較軸が明確か

## 4. 工程2――正面图（线稿）／正面線画

### 目的

三面図、ポーズ、表情、アニメーションの基準になる正式な正面モデルを作る。

### この工程で決めること

- 正式な頭身とプロポーション
- 目、鼻、口の位置
- 耳、翼、しっぽ、手足の標準形
- 衣装の正式な線
- 標準状態での左右非対称
- 線の太さ、揺れ、欠け方
- 身体の中心線と接地位置

### 固定するもの

- 採用した草図のシルエット
- 頭、胴体、手足の比率
- キャラクターの役割と性格

### Prompt テンプレート

```text
工程:
キャラクターデザインの第2段階、正面基準線画。

入力:
添付した草図の第__案を正式案として使用する。

目的:
今後の三面図、ポーズ、表情、アニメーションで使用する
正面基準モデルを作る。

固定するもの:
- 採用案の頭身
- 頭、胴体、耳／翼／しっぽ、手足の比率
- 顔の形
- 衣装の形
- 設定済みの小さな非対称性

姿勢:
顔、胸、腰は正面。
自然な直立姿勢。
両手または両翼は身体の横へ自然に下ろす。
足は接地させる。
アクションポーズにはしない。

表情:
通常時の穏やかな表情。
顔の部品は最小限。
笑顔を強調しない。

描画:
細い黒インクの線画。
手描きらしい小さな揺れと筆圧差を残す。
非重要部分では輪郭の10%程度を自然に欠落させる。
顔、手足、翼など意味を伝える線は読みやすく保つ。

出力:
正面図1体のみ。
白い背景、全身。
色、陰影、背景、小道具、文字は付けない。

変更禁止:
草図で確定した頭身、身体の幅、顔、衣装を再設計しない。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### 確認基準

- 顔の中心と各部品の位置が安定しているか
- 左右対称すぎず、意図しない歪みにも見えないか
- 小さく表示しても顔と身体が読めるか
- 手描き感が乱雑さになっていないか
- 足元と重心が安定しているか

---

## 5. 工程3――色彩稿／カラーデザイン

### 目的

確定した線画を変更せず、キャラクターの役割とチーム内の識別性を支える配色を決める。

### この工程で決めること

- 基本色
- 補助色
- アクセントカラー
- 線の色と濃さ
- 塗り方
- 塗り残しと線からのずれ
- 他キャラクターとの色の差
- 小さく表示した場合の視認性

### 固定するもの

- 身体比率
- シルエット
- 顔
- 衣装の形
- 正面線画

### Prompt テンプレート

```text
工程:
キャラクターデザインの第3段階、色彩設計。

入力画像:
添付画像は確定済みの正面線画。
線、身体比率、顔、衣装、輪郭を変更しない。
色彩のみを検討する。

目的:
キャラクターの性格と役割を表し、
ほかのキャラクターとも明確に識別できる配色を決める。

出力:
同じ正面線画を使用した配色案を4案。
形と線は全案で共通にする。

検討項目:
- 衣装の基本色
- 縁や小物のアクセント色
- 線の黒の濃さ
- 身体の一部に色を入れるか
- 塗り残しの割合

色の方向:
淡く限定された配色。
一案につき主要色は3色以内。
紙の白を活用する。
彩度を上げすぎない。
塗りは輪郭を完全に埋めず、
わずかなずれや塗り残しを残す。

避ける:
グラデーション、立体的な陰影、光沢、
エアブラシ、写真風の質感、色による輪郭変更。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### 確認基準

- 白黒に戻しても形が読めるか
- 他キャラクターと色が混同しないか
- アプリの小さなアイコンでも認識できるか
- 色が性別や能力を固定的に連想させないか
- 印刷と画面の両方で成立するか

## 6. 工程4――三视图（不带 Pose）／ポーズなし三面図

### 目的

正面、側面、背面で矛盾しない制作基準モデルを作る。

### この工程で決めること

- 頭と顔の奥行き
- 耳や翼の付け根
- しっぽの位置
- 手足の接続位置
- 衣装の側面と背面
- 横から見た重心
- 全方向での身長と床位置

### Prompt テンプレート

```text
工程:
キャラクターデザインの第4段階、ポーズなし三面図。

入力:
確定済みの正面線画と色彩稿。
キャラクターの形、頭身、衣装、色を変更しない。

目的:
正面、真横、背面で矛盾のない制作基準モデルを作る。

出力:
左から以下の3体を横一列に配置する。
1. 正面
2. キャラクターの右側面
3. 背面

三体は同じ縮尺。
頭頂、顎、肩、腰、膝、足元の高さを揃える。
床の基準線を一本だけ薄く入れる。

姿勢:
ニュートラルな自然立位。
顔、胴体、腰を捻らない。
手や翼は身体の横。
足は平行に接地。
表情差、感情、アクションを付けない。

確認する構造:
- 頭と鼻先／くちばしの奥行き
- 耳／翼の付け根と厚み
- 腕、翼、脚の接続
- しっぽの位置
- 衣装の側面と背面
- 非対称な特徴の方向間での整合性

描画:
確定済みの手描き線と色を維持する。
設計図のような完全なベクター線へ変えない。

避ける:
三者で異なるポーズ、異なる表情、斜め向き、
遠近法、背景、小道具、影。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### 確認基準

- 正面と側面で頭の大きさが変わっていないか
- 耳、翼、しっぽの位置に矛盾がないか
- 3体の足元と縮尺が揃っているか
- 衣装の前後がつながっているか
- 三面図がポーズ集になっていないか

## 7. 工程5-A――代表 Pose 图／代表ポーズ表

### 目的

静止したモデルではなく、相手の反応によって行動が変わる瞬間からキャラクターの性格を見せる。

### この工程で決めること

- キャラクターらしい基本動作
- 強みが役立つ瞬間
- 強みが行きすぎる瞬間
- 相手に気づき、自分の行動を変える瞬間
- 反復する姿勢や視覚記号
- 動作の大きさとリズム

### Prompt テンプレート

```text
工程:
キャラクターデザインの第5段階、代表ポーズ表。

入力:
確定済みの正面図、三面図、色彩稿。
顔、頭身、衣装、色、身体的特徴を変更しない。

目的:
キャラクターの性格を、相手への反応を含む動作で表現する。

代表ポーズ:
1. 基本の強みが現れる姿
2. 相手を活動へ誘う姿
3. 強みを使いすぎる姿
4. 相手の反応に気づく姿
5. 自分の行動を相手に合わせ直す姿

重要:
5つを独立した格好いいポーズとして描かず、
一つの人格の流れとして読めるようにする。

性格の表現:
顔の変化を大きくしすぎない。
視線、耳／翼／しっぽ、肩、肘、手、膝、足幅、
重心、身体が占める面積で違いを見せる。

出力:
同一キャラクター5体。
同一縮尺、白い背景。
各ポーズを完全に分離する。
文字や説明は入れない。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### うさぎ先生の代表ポーズ例

```text
1. 一緒にやろうと誘う
2. 張り切って大きく応援する
3. 相手の反応に気づいて止まる
4. 身体を低くして相手の速さに合わせる
5. 小さな一歩を静かに一緒に喜ぶ
```

### ことり先生の代表ポーズ例

```text
1. 小さなサインに気づく
2. 同じ形でまねして返す
3. やさしく問いかける
4. 小さく歌ってやりとりを広げる
5. 羽を閉じて少し待ちすぎる
```

### りす先生の代表ポーズ例

```text
1. 虫眼鏡で観察する
2. 二つの手がかりを比べる
3. ひらめいて道具を取り出す
4. 道具を出しすぎる
5. 一つを選び、残りを戻す
```

## 8. 工程5-B――情绪图／感情表

### 目的

喜怒哀楽の記号ではなく、日常の中で生じる小さな内面の変化を、最小限の顔と身体で表現する。

### この工程で決めること

- 日常的な感情の種類
- 感情ごとの強度
- 視線と姿勢の変化
- 顔以外で感情を伝える方法
- 悲しさや疲れを笑顔で消さない表現

### Prompt テンプレート

```text
工程:
キャラクターデザインの第5段階、感情表。

入力:
確定済みの正面基準モデル。
頭身、顔の部品、衣装、色を変更しない。

目的:
最小限の顔と身体で、キャラクターの内面的な変化を表現する。

感情:
1. 楽しみ
2. 好奇心
3. 迷い
4. 相手の変化への気づき
5. 少し心配
6. 疲れ
7. 待つ
8. 安心
9. 小さな変化を一緒に喜ぶ

表現方法:
口の形だけに頼らない。
視線、耳／翼／しっぽの角度、肩、手の位置、
膝、身体の高さで感情を分ける。
同じ笑顔を繰り返さない。

表情の強度:
日常的で控えめ。
感情の最大値を10とした場合、2〜6程度。
悲しさ、迷い、疲れを笑顔で消さない。

出力:
胸から上の感情案、または全身の感情案。
一枚の中では形式と縮尺を統一する。
白背景、文字なし。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

## 9. 工程6――实际应用场景／実際の利用場面

### 目的

完成したキャラクターが、絵本、アプリ、カード、教材などの実際の場面で、役割と距離感を守って機能するか確認する。

### この工程で決めること

- キャラクターと子どもの距離
- 視線の方向
- 身体の高さ
- 画面の中心人物
- 背景の情報量
- 用途に必要な余白
- 表示サイズ
- 安全性と専門的な境界
- キャラクターが主役になりすぎていないか

### Prompt テンプレート――絵本

```text
工程:
キャラクターデザインの第6段階、実際の物語場面。

用途:
HugMap Stories の絵本見開き。

入力:
確定済みの三面図、代表ポーズ表、感情表、色彩稿。
キャラクターデザインを変更しない。

場面:
[子どもと先生がいる具体的な日常場面を書く]

物語上の瞬間:
[成功後ではなく、何に気づく瞬間なのかを書く]

位置関係:
- 子どもまたは親子を画面の中心にする
- 先生は斜め横、同じ高さ、または少し後ろに置く
- 先生を子どもより大きく描き続けない
- 先生は子どもの正面や進路を塞がない
- 必要に応じて、先生と子どもは同じ対象を見る
- 適度な距離と余白を残す

背景:
日常の場所を、キャラクターより少ない情報量で描く。

構図:
横長の見開き。
綴じ目に顔や重要な手を置かない。
次の場面へ進む方向に余白を残す。

避ける:
先生が子どもの手を引っ張る、成功を要求する、
励まし続ける、中央で説明する、
子どもの気持ちを断定する。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### Prompt テンプレート――アプリUI

```text
用途:
保護者向けアプリの[画面名]に表示するキャラクター挿絵。

表示サイズ:
画面上で幅___px程度。

状況:
[保護者に伝えること、先生が担う役割を書く]

ポーズ:
[代表ポーズ表から使用する姿勢を書く]

構図:
全身または上半身。
UI文章やボタンを置く側に十分な余白を残す。
キャラクターの配置位置を指定する。

視認性:
小サイズでも顔、手／翼、姿勢が読める。
細かい小道具や背景は使わない。
輪郭の欠けは残すが、顔と意味を伝える手は欠けさせない。

背景:
アプリと同じ温かい白、または切り抜きやすい単純な背景。

避ける:
複雑な背景、細かすぎる小道具、強い陰影、
過剰な表情、画像内へ直接描いたUI文字。

この工程で指定していない要素は再設計しない。
前工程で確定した内容を維持する。
```

### 確認基準

- キャラクターより子どもや親子の物語が中心になっているか
- 先生が正解を渡すヒーローになっていないか
- 子どもの正面や進路を塞いでいないか
- 相手の反応によって先生の姿勢が変わっているか
- 小さな表示サイズでも意味が伝わるか
- 背景や小道具がキャラクターより目立っていないか

## 10. 参照画像の役割を分ける

複数の参照画像を渡す場合は、各画像から何を採用するかを明記する。

```text
参照画像1:
キャラクターの形、顔、頭身、衣装を固定するための基準。
構図やポーズは参照しない。

参照画像2:
線の揺れ、欠け、筆圧、紙の質感だけを参照する。
キャラクター造形は参照しない。

参照画像3:
ポーズと身体の重心だけを参照する。
顔、衣装、色は参照しない。

参照画像4:
画面内の配置、余白、UIとの関係だけを参照する。
キャラクターの形や画風は参照しない。
```

「この画像を参考に」だけでは、形、構図、色、画風、ポーズのどれを採用するかが曖昧になる。参照画像ごとの役割を必ず分離する。

## 11. 工程ごとの変更可能範囲

| 工程 | 変更してよいもの | 固定するもの |
|---|---|---|
| 1. 草図 | 頭身、シルエット、比率、基本衣装 | 役割、性格、種族 |
| 2. 正面線画 | 正式な線、顔の位置、細部の整理 | 採用した草図、比率、シルエット |
| 3. 色彩稿 | 色、塗り方、塗り残し | 形、線、比率、衣装 |
| 4. 三面図 | 側面と背面の構造 | 正面、頭身、色、衣装 |
| 5. ポーズ | 姿勢、重心、視線、動作 | キャラクターモデル、色、衣装 |
| 5. 感情 | 視線、表情、姿勢の微差 | 顔の基本構造、頭身、衣装 |
| 6. 応用場面 | 構図、距離、背景、表示サイズ | モデル、性格、色、役割 |

## 12. Prompt 品質チェックリスト

画像を生成する前に、次を確認する。

### 内容

- [ ] 今回の工程が明記されている
- [ ] 今回の目的が一文で書かれている
- [ ] キャラクターの固定ブロックが含まれている
- [ ] 今回変更してよい項目が明記されている
- [ ] 変更禁止項目が明記されている
- [ ] 参照画像ごとの役割が分かれている
- [ ] 必要な出力数と配置が指定されている
- [ ] 正面、側面、全身などの向きと範囲が指定されている
- [ ] 文字、背景、色、小道具の有無が指定されている

### キャラクター

- [ ] 性格を表情だけで説明していない
- [ ] 視線、肩、手足、翼、耳、しっぽ、重心を使っている
- [ ] 強みだけでなく、強みが行きすぎる弱点も表現している
- [ ] 相手の反応を受けて行動を変える流れがある
- [ ] 先生が正解を知るヒーローになっていない

### 画風

- [ ] 線の太さ、揺れ、欠け、筆圧が指定されている
- [ ] 手描き感と乱雑さの境界が指定されている
- [ ] 色数、彩度、塗り方が指定されている
- [ ] 避けたいベクター感、光沢、3D感などが明記されている

### ドリフト防止

- [ ] 同一キャラクターであることを明記している
- [ ] 前工程のどの案を採用したか書いている
- [ ] 形を変えず色だけ変える、など編集範囲を限定している
- [ ] 「指定していない要素は再設計しない」を入れている

## 13. 推奨する承認ポイント

各工程を一度に通過せず、次のタイミングで承認する。

```text
草図から1案を選ぶ
↓
正面線画を承認する
↓
配色を1案に決める
↓
三面図の構造を承認する
↓
代表ポーズと感情の範囲を承認する
↓
絵本・アプリなどの実際の場面で検証する
```

応用場面で問題が見つかった場合は、すべてを描き直さず、問題が属する工程まで戻る。

| 見つかった問題 | 戻る工程 |
|---|---|
| 小さくすると誰かわからない | 草図または正面線画 |
| 他キャラクターと色が似ている | 色彩稿 |
| 横を向くと構造が崩れる | 三面図 |
| 性格が伝わらない | 代表ポーズ・感情表 |
| 子どもより先生が目立つ | 実際の利用場面 |
| いつも別キャラクターに見える | 正面線画と参照画像指定 |

この工程管理により、見た目の完成度だけでなく、HugMap Stories の価値観と役割が一貫したキャラクターを制作する。
