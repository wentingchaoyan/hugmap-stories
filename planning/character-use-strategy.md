# HugMap キャラクター用途整理・試作案

作成日: 2026-08-12

## 結論

最も効果が高いのは、キャラクターを長く説明させることではなく、保護者が迷う瞬間に短く現れ、次の一歩へつなぐ使い方である。

優先順位は次の通り。

| 優先 | 用途 | 狙い | 効果 | 制作負荷 |
|---:|---|---|---|---|
| 1 | アプリ内の状況別インタラクション | 行動開始・継続・相談への橋渡し | 高 | 低〜中 |
| 2 | 発達段階の短い説明 | 「できる／できない」を日常の観察へ変える | 高 | 中 |
| 3 | FAQの入口・回答の帰属 | 自分に近い困りごとを見つけ、安心して読む | 高 | 低 |
| 4 | 道具カード・家庭で試すミニ支援 | 読んだ知識を今日の行動に変える | 高 | 中 |
| 5 | チュートリアル | 初回理解と機能発見 | 中 | 中 |
| 6 | 振り返り・小さな変化の発見 | 記録継続と自己効力感 | 中〜高 | 中 |
| 7 | 絵本・長編動画 | 世界観・共感・深い理解 | 中（接触時間は長い） | 高 |
| 8 | 通知・季節コンテンツ | 再訪 | 中 | 低〜中 |

アプリのコア体験では 1〜4 を先に作り、絵本・長編動画は同じ題材を深掘りする二次展開にするのがよい。

## 判断の根拠

- `category_stage` は53段階・6カテゴリを、保護者が日常で観察できる表現へ置き換えている。キャラは段階の「採点者」ではなく、観察ポイントの案内役に合う。
- FAQは「生活場面 → 観察できる様子 → 知りたいこと」の疑問文へ更新されている。キャラ別の専門性と自然に接続できる。
- 既存設計では、評価入力・発達一覧・専門職向けPDFにはキャラを出さない。これは維持する。
- 先生は解決するヒーローではなく、本人と家族が見方や方法を見つける余白を作る伴走者である。

## 1. アプリでのインタラクション

### Sample A — Check Inカード「きょうの様子」

**登場:** ぽけっとさん
**タイミング:** ホーム初回表示、または前回記録から7日以上
**コピー:**

> 今日はどんな一日だった？
> 写真でも、ひとことでも大丈夫。あとで一緒に整理できるよ。

**選択肢:** `写真を残す` / `ひとこと書く` / `今日は閉じる`
**ねらい:** 記録の心理的負荷を下げる。解釈や助言はしない。

### Sample B — 発達詳細から相談へ

**題材:** 「指さしや視線で伝える」
**登場:** ことり先生
**コピー:**

> 手を引くことも、大切な「伝えたい」サインだよ。
> いつ、何を伝えようとしていたか、一緒に見てみる？

**選択肢:** `よくある場面を見る` / `ことり先生に相談`
**接続FAQ:** 「欲しいものがあると、指さしではなく私の手を引いて連れていきます」

### Sample C — 状態変化の発見

**登場:** ぽけっとさん → 必要に応じて担当先生
**コピー:**

> 「座って遊ぶ」の記録が3回たまったよ。
> 支え方や遊んだ場所も違っていて、できる形が増えているみたい。

**選択肢:** `3つの記録を見る` / `うさぎ先生の見方を読む`
**ねらい:** 達成判定ではなく、条件と変化を返す。

## 2. 発達段階の説明（アプリ画面・短編動画・絵本）

一つのテーマを3媒体へ展開する。まず10〜20秒の画面説明を作り、反応のよい題材だけ絵本・長編へ広げる。

### Sample A — 「いっしょに見て楽しむ」

**category_stage:** いっしょに見る・感じる
**担当:** ことり先生
**3コマ:** 子どもが電車を見る → 一瞬だけ保護者を見る → 保護者も横から電車を見る
**ナレーション:**

> ずっと目が合わなくても、同じものを見て、声や表情を交わせたら、もう「いっしょに見る」は始まっています。

**CTA:** `うちの子のサインを記録する`

### Sample B — 「座って遊ぶ」

**category_stage:** 座る
**担当:** うさぎ先生
**3コマ:** 足が浮いて手で支える → 足台を置く → 両手で好きなおもちゃに触る
**ナレーション:**

> 座ることに力を使い切ると、遊ぶ手が空かないことがあります。足元を支えると、その子の力を遊びに使えることがあります。

**CTA:** `環境の工夫を見る`
**注意:** 「足台で座れるようになる」と因果を断定しない。

### Sample C — 「スプーンや道具を使う」

**category_stage:** 道具操作
**担当:** りす先生
**3コマ:** 柄の細いスプーンが回る → 太い柄と滑りにくい器を試す → 本人が使う／手で食べるを選ぶ
**ナレーション:**

> 手の力だけでなく、持つ太さ、器の動き、姿勢でも使いやすさは変わります。今日合う形を一つ試してみよう。

**CTA:** `試した条件を残す`

## 3. チュートリアル動画

機能名を順番に読み上げるのではなく、「困った瞬間 → キャラの役割 → できること」の15〜30秒単位にする。

### Sample A — はじめての記録（20秒）

1. 保護者: 「あとで書こうと思って忘れちゃう」
2. ぽけっとさん: 「写真だけ預けて。言葉はあとから足せるよ」
3. 写真追加 → 日付自動入力 → 保存
4. ぽけっとさん: 「残せたよ。必要なときに一緒に見返そう」

### Sample B — 発達の見方（25秒）

1. 画面に「歩いて移動する」
2. うさぎ先生: 「何歩かだけじゃなく、支え・止まり方・疲れ方も手がかりだよ」
3. `できる` の二択ではなく、観察項目と記録例を表示
4. 「評価入力には先生を出さない」ことで判定感を避ける

### Sample C — 相談の使い分け（30秒）

1. ことり先生: 「伝え方や会話なら、わたし」
2. りす先生: 「感覚や道具の工夫なら、ぼく」
3. ぽけっとさん: 「記録や整理は、わたしに預けてね」
4. 相談内容が複数分野なら「うさぎ先生も一緒に見られるよ」と紹介導線

## 4. 追加で効果が見込める用途

### 4-1. FAQの場面ナビゲーション

専門分野名より先に、生活場面を選ばせる。

- 朝の支度: ぞう先生「順番を見える形にしてみよう」
- 食卓: かば先生「食べる量だけでなく、姿勢や食感も見てみよう」
- 園から帰った後: ふくろう先生「疲れや切り替えの前後を一緒に見よう」

### 4-2. 「今日試す」道具カード

- ことり先生: `二択で聞くカード` — 「りんご？ バナナ？」。指さしや視線も返事として受け取る。
- りす先生: `おもちゃを2〜3個だけ出すカード` — 集中時間を伸ばすことより、変化を観察する。
- ぞう先生: `朝の3ステップカード` — 着替える → かばん → 靴。家庭の写真へ差し替え可能。
- かば先生: `食事姿勢チェック` — 足・腰・あご。安全情報と相談目安を併記。

### 4-3. 振り返りダイジェスト

**登場:** ぽけっとさん
**月末コピー:**

> 今月は「自分から選んだ」が4つ残っていたよ。
> 食べ物、遊び、服で、伝え方はそれぞれ違っていました。

`記録を見る` / `家族や園に共有する`
数を成績化せず、変化・条件・本人の選択を言葉にする。

### 4-4. セーフティ・相談目安

**登場:** くま先生。ただし不安を煽る表情や赤い警告キャラにはしない。
**例:**

> いつもと違う呼吸、顔色、強い痛みがあるときは、発達の工夫より先に医療機関へ相談してください。

`相談先の目安を見る`

### 4-5. 園・支援者へ渡す前のバトン

**登場:** ぽけっとさんは作成体験にだけ登場し、完成PDFからは外す。
**コピー:**

> 「苦手なこと」だけでなく、「伝わりやすい方法」と「好きなこと」も一緒に入れよう。

`3項目を確認` → ニュートラルなPDFを書き出す。

### 4-6. 季節・場面別ミニストーリー

- 運動会: うさぎ先生 — 全参加だけでなく、見る・一部参加・休むを選択肢にする。
- 入園・進級: ぞう先生＋ぽけっとさん — 写真予定表と引き継ぎメモ。
- 外食: かば先生＋りす先生 — 食感、音、椅子、終えるサインを事前に確認。

## 画面に出す／出さない基準

### 出す

- 初めてで迷うとき
- 空状態、完了、状態変化
- 専門分野を選ぶとき
- FAQから相談・記録・道具へ移るとき
- 本人や家族の選択肢を増やすとき

### 出さない

- できる／できないを入力する評価画面
- 全カテゴリ一覧のような高頻度作業面
- 診断、危険度、医療的判断そのもの
- 園・医療へ渡す完成PDF
- 毎回同じことを話す常設吹き出し

## MVP提案

1. Check Inカード3種: 初回、7日空き、記録完了
2. 発達ミニ説明3本: `いっしょに見て楽しむ`、`座って遊ぶ`、`スプーンや道具を使う`
3. FAQ場面入口3種: 朝、食卓、帰宅後
4. 「今日試す」カード4種
5. 2週間で、表示→CTA率、閉じる率、相談開始率、記録完了率を比較

キャラの有無だけでなく、`キャラ＋短い行動提案` と `文章のみ` を比較する。キャラの効果を好感度ではなく、次の行動と再訪で判断する。
