## 2. シリーズの世界観

HugMap Storiesは、子どものできなさを直す物語ではない。

子どもはすでに、見ている、感じている、試している、伝えようとしている。動物の先生たちは、その小さなサインを見つけ、保護者が子どもの育ちに気づけるようにする。

シリーズ全体を、親子が受け取る感触で表す3つのキーワードは、**気づく・つながる・育つ**。

先生たちは、困ったときだけ現れる救助隊ではない。普段から親子の少しそばにいて、保護者が「どうしてだろう？」と立ち止まったとき、その場面に必要な見つけ方を持つ先生が一歩前へ出る。

先生たちは、一つの開かれた「HugMapの家」で暮らしている。そこには、休む、感じる、動く、作る、伝える、考える、つなげるための場所がある。場所は発達の優劣を示す段階ではなく、そのとき必要な関わり方を選ぶための行き先である。

```text
動物たちは、いつも日常の近くにいる。
保護者が「どうしてだろう？」と立ち止まったとき、
その場面に必要な手がかりを持つ先生が一歩前へ出る。

"See Your Child. See Yourself. Grow Together."
親と子の双方向的な成長

"The Expert in Your Child Is You. We Help You See It."
親の専門性（子どものことを一番知っている）の再認識

"Stories Where Every Child Finds Their Way."
多様性、個別性の尊重
```
「複雑さを、わかりやすくする。」
発達支援、医学的知識、栄養・感覚・言語・運動 etc. を、親子にアクセス可能な物語に変える
専門家の知見 ≠ 講義ではなく、動物の先生たちの「見方」として伝える


## 3. シリーズが信じること

| 信じること | 物語での表し方 |
|---|---|
| 子どもはすでに世界と関わっている | 最初から絵の中に小さなサインを置く |
| 行動には本人なりの理由がある | 表面だけで決めつけず、前後や反応を見る |
| 一つの正解より、合う条件を探す | 環境、道具、距離、速さ、伝え方を変える |
| 全部頑張らなくてよい | 休む、断る、見るだけも選択として認める |
| 楽しさは学びの入口になる | 一見どうでもよいことから遊びが始まる |
| 強みは伸ばせる | できなさの克服だけをゴールにしない |
| 成長は周囲と祝える | 保護者が小さな変化に気づく場面を作る |
| 可能性は一人で支えない | 先生同士、家庭、必要な専門家へつなぐ |

## 4. シリーズ共通の約束

- 子どもを困りごとの代表として扱わない。
- 先生が子どもの気持ちを断定しない。
- 本人の反応を見て、見立てを確かめる。
- 発語、速さ、回数、完食だけを成功基準にしない。
- 悲しさや難しさを、前向きな言葉で急いで消さない。
- 一度の工夫ですべてが解決したように描かない。
- 必要な医療・発達相談・専門支援を、絵本だけで代替しない。
- 最後は先生の解説ではなく、親子の日常へ場面を返す。
- 先生やアプリがいない場面でも、保護者が次のサインを見つけられるようにする。

## 5. キャラクターを分ける軸

先生たちは専門職名だけで分けない。次の二つの問いで個性を定義する。

> この先生は、子どもの世界の何に最初に気づくか。
>
> その手がかりを、どのような方法で確かめるか。

同じ場面を見たとき、全員が違う手がかりを見つけられることを、キャラクター成立の条件とする。

### 支援キャラクターに共通する距離感

先生たちは、問題を代わりに解決するヒーローではない。障害のある子どもや家族に対して、**近づきすぎず、離れすぎず、同じ方向を一緒に見る伴走者**として描く。

- 同情より関心を向け、まず本人が見ているもの、望んでいること、困っている条件を知ろうとする。
- 励ます前に、つらさ、迷い、疲れをそのまま受け止める。
- 答えを決めつけず、観察できた事実を返し、本人や家族の選択を待つ。
- 子どもの代わりに話しすぎず、視線、声、仕草、拒否、沈黙も本人の表現として尊重する。
- 必要な情報や方法は渡すが、選択権と物語を動かす役割は本人と家族へ戻す。
- 問題に飲み込まれない落ち着きと、分かったつもりにならない好奇心を持つ。

画面では、先生を子どもや家族より大きく、中央に置き続けない。正面を塞がず、斜め横、同じ高さ、または少し後ろに位置し、必要のない場面では黙って待ち、役割を終えたら一歩下がる。表情は穏やかに保つが、いつも笑顔にして悲しみや疲れを消さない。

避けるのは、いつも正解を知る専門家、努力や奇跡ですべてを解決するヒーロー、「普通にできること」を唯一のゴールにする指導者、本人の気持ちを断定する代弁者である。先生の役割は、本人と家族が自分たちの見方や方法を見つけるための**余白**をつくることにある。

## 6. キャラクター早見表

キャラクターを列、重要な比較軸を行に置く。これをシリーズ全体のキャラクター判断の入口とする。

### メインキャラクター

#### 最優先――キャラクターの核

最初にこの表だけを読み、三人の違いが分かる状態にする。新しい設定や物語が下段の専門情報と合っていても、この核と矛盾する場合は採用しない。

| 軸 | ことり先生 | りす先生 | うさぎ先生 |
|---|---|---|---|
| **人物像** | 傾聴者 | 探偵兼発明家 | 伴走型の応援者 |
| **ひと目で感じる3語** | やさしい・おしゃべり・歌う | 好奇心・器用・ひらめき | 元気・楽しい・挑戦 |
| **信じていること** | ことばの前から伝え合いは始まり、そのやりとりの中でことばも育つ | 道具と環境を変えると、その子の「できる形」は増やせる | 参加には、その子に合う量・速さ・方法がある |
| **最初に見るもの** | 目、声、仕草、身体の向き、間 | 触る、握る、匂う、繰り返す | 姿勢、足元、バランス、疲れ方 |
| **見つけるもの** | 届こうとしているもの | 身体が探す感覚と参加方法 | 一歩の中のがんばり |
| **基本の動き** | 待つ・聞く | 調べる・作る | 一緒に動く |
| **強み** | 待つ、まねる、問いかける | 手がかりを探し、試して調整する | 小さな挑戦を楽しく応援する |
| **愛嬌のある弱点** | **のんき**（待ちすぎる） | **いたずら好き**（試しすぎる） | **張り切り屋**（応援しすぎる） |

ことり先生は**ことばになる前の表現を受け取り、やりとりと言葉の育ち**を支え、りす先生は**道具と環境の条件**を変え、うさぎ先生は**参加の量・速さ・方法**を広げる。この違いを、三人の役割が重ならないための基準とする。

#### 絵で性格を見せる最小の3場面

性格は持ち物や得意なポーズだけで説明せず、**子どもの反応を受けて先生の行動が変わること**で見せる。1枚のキャラクターシート、絵本の見開き、短いアニメーションでは、次の流れを基本とする。

| 先生 | 3場面の流れ | 性格が見える瞬間 | 弱点を愛嬌にする瞬間 | 反復する視覚記号 |
|---|---|---|---|---|
| ことり先生 | **気づく → まねる → 待つ** | 子どもの小さな声、指、視線、間を受け取り、同じ形で返す | 返事を急がず待ち、少し待ちすぎる | 往復するオレンジの点、閉じた羽 |
| りす先生 | **観察 → 出しすぎる → 選んで戻す** | 子どもの反応に合わせ、道具や環境を選び直す | ひらめいて道具を広げすぎるが、不要なものをしまえる | 紫の部品、二つの選択肢、道具箱 |
| うさぎ先生 | **張り切る → 気づく → 相手に合わせる** | 見る、少し触る、休むなど、その子の参加方法へ速度を合わせる | 大きく応援しすぎたあと、しゃがんで声量と動きを小さくする | 黄色いボール、足跡、低い姿勢 |

避ける表現:

- ことり先生を、いつも歌っているだけの先生にしない。
- りす先生を、便利な道具を渡すだけの先生にしない。
- うさぎ先生を、成功するまで励まし続ける先生にしない。
- 子どもの反応がなくても、先生だけで問題を解決しない。

#### 次に確認――物語・専門性・制作情報

下の表は、担当する物語を選び、生活場面や専門的な境界を具体化するときに使う。人物像を定義する表ではなく、上の核を実際の作品へ展開するための情報である。

| 軸 | ことり先生 | りす先生 | うさぎ先生 |
|---|---|---|---|
| **物語の入口** | 伝える・つながる | 感じる・試す・工夫する | 動く・挑戦する |
| **関心テーマ** | 聞こえ、聴覚活用、発声、発音、音韻、語彙、文法、会話、共同注意、模倣、AAC、口腔発達と言語 | 五感、感覚調整、手先、手と目の協調、道具、探究遊び | 姿勢、バランス、筋力、持続力、身体の使い方、外遊び |
| **よく出会う生活課題** | 呼びかけを逃す、言葉が増えにくい、発音が伝わりにくい、要求や拒否を伝えにくい、会話が続きにくい | 着替え、食具、鉛筆、はさみ、ボタン、トイレ、遊びへの参加、音・光・触感による疲れ | 座位や立位が不安定、転びやすい、階段や移乗が難しい、疲れやすい、遊具や外出へ参加しにくい |
| **得意なスキル** | 聞こえ方の観察、傾聴、ミラーリング、言葉の拡張、AAC、必要な聴覚・言語評価への接続 | 活動分析、動作の分解、感覚と環境の調整、自助具、遊びと日常動作への参加づくり | 姿勢・移動・歩行の観察、段階づけ、足場・支持・補助具の調整、持久力と休憩の設計 |
| **主な象徴** | 吹き出し、柔らかな線、ベル、歌 | 道具箱、布、ブラシ、トング | 黄色いボール、足跡、低い台 |
| **補う先生** | ふくろう、うさぎ | ことり、くま | くま、ことり |

メイン3人は普段から子どもの近くにいて、シリーズの入口になる。「待つ」「調べて作る」「一緒に動く」という異なる動きで物語にリズムを作る。

弱点は能力の不足ではなく、強みを使いすぎたときの偏りとして描く。まず強みが役立ち、その後に裏返しが現れる。別の先生は否定せず、異なる見方を重ねて補う。仕草、口調、具体的な台詞は [`character-expression-guide.md`](character-expression-guide.md) を参照する。

### 家族キャラクター

#### お姉ちゃん

お姉ちゃんは、動物の先生のように子どもを支援する役ではなく、同じ家で暮らし、一緒に遊び、ときには失敗する子どもの一人として描く。

| 軸 | 設定 |
|---|---|
| **家族での位置** | 主人公の姉。年齢と名前は未決定 |
| **人物像** | 世話好きで真面目。自分なりの「ちゃんとしたい」がある |
| **ひと目で感じる3語** | しっかり・おしゃれ・おせっかい |
| **好きなこと** | 服や小物を選ぶ、組み合わせを考える、人の身支度を手伝う |
| **基本の動き** | 襟や持ち物を整える、先に準備する、弟へやり方を見せる |
| **強み** | 小さな変化に気づき、必要そうなものを先に用意する |
| **強みの裏返し** | 手伝いすぎる、正しく整えようとしすぎる |
| **愛嬌のある弱点** | ファッション好きなのに、急いだ日は左右で違う靴下を履いている |
| **視覚的な記号** | 色や柄の違う左右の靴下。本人は途中まで気づかないこともある |
| **物語での役割** | 大人より子どもに近い目線で一緒に試す。弟を代弁せず、本人へ確かめることを少しずつ覚える |

お姉ちゃんの世話好きは、家族を支える義務として描かない。手伝わない日、間違える日、自分の遊びを優先する日があってよい。左右違う靴下は「だらしなさ」ではなく、真面目さとおしゃれ好きの中にある、本人らしい可笑しさとして扱う。

### 専門テーマの境界

| テーマ | 主に見る先生 | 設定上の扱い |
|---|---|---|
| 大きい音には反応するが、小さい音や語尾を聞き逃す | ことり＋くま | 「注意して聞けばよい」とせず、音の強さ、距離、雑音、左右差、頻度を観察し、必要なら小児聴覚の専門家へつなぐ |
| 音が大きいと苦しい、特定の音を避ける | りす＋くま | 聴力の問題と決めつけず、感覚負荷と身体反応、環境条件を確かめる |
| 絵なら分かる、口頭なら分かる、実物なら分かる | ぞう＋ことり＋りす | 子どもを固定的な「視覚型・聴覚型」に分類せず、課題ごとに複数の提示方法を試し、理解と参加の反応を比べる |
| 息、声、唇、舌、顎と発音のつながり | ことり＋かば＋くま | ことりは呼吸・発声・共鳴・構音と言語を、かばは吸う・噛む・飲み込む動きと呼吸の協調を、くまは身体と安全を確認する |
| 不器用、感覚の過敏・鈍さ、生活動作の難しさ | りす＋うさぎ＋ぞう | りすは活動と感覚、うさぎは姿勢と移動、ぞうは手順理解を見る。診断名ではなく、生活のどこで参加しにくいかから考える |
| 崩れる、逃げる、叩く、自分を傷つける | ふくろう＋ことり＋くま | 困った行動だけを止めず、前後、伝えたいこと、痛みや体調、安全を同時に確認する |
| むせ、咳、湿った声、食事の長時間化、成長の心配 | かば＋くま＋ことり | 好き嫌いだけで扱わず、嚥下・呼吸・栄養・消化・口腔機能を含む安全課題として専門家へつなぐ |
| 家庭ではできるが園では難しい、支援が引き継がれない | ぽけっと＋担当の先生 | 場所ごとの事実、うまくいった条件、本人と家族の希望を短く残し、支援を一貫させる |

口の運動だけを切り離して万能な訓練として扱わない。発音なら実際の音やことば、食べる動きなら実際の食形態と安全条件など、目的の活動に近い経験として描く。

## 7. 同じ場面を見たときの違い

例: 子どもが電車のおもちゃを繰り返し押している。

| 先生 | 最初に気づくこと |
|---|---|
| ことり先生 | 電車を見たあと、一瞬相手の顔を見ている |
| りす先生 | 車輪の振動、押す力、音の違いを確かめている |
| うさぎ先生 | 同じ姿勢を保ち、押す力を調整している |
| ふくろう先生 | どんな前触れや反応のあとに繰り返すか |
| くま先生 | 疲れ、痛み、普段との違いがないか |
| ぞう先生 | 遊びの順番や次の展開を見える形にできるか |
| かば先生 | 口や呼吸の動き、感覚との関係がないか |
| ぽけっとさん | いつ、どこで、何が変わったかを事実として残す |

## 8. チーム内の連携

| 最初に見つけた先生 | 別の視点が必要なとき |
|---|---|
| ことり先生 | 身体と感覚はりす先生、行動整理はふくろう先生 |
| りす先生 | 動作と姿勢はうさぎ先生、安全と体調はくま先生 |
| うさぎ先生 | 感覚はりす先生、本人の意思確認はことり先生 |
| ふくろう先生 | 気持ちの受容はことり先生、小さな実行はうさぎ先生 |
| くま先生 | 安全な挑戦はうさぎ先生、環境調整はりす先生 |
| ぞう先生 | コミュニケーションはことり先生、情報整理はふくろう先生 |
| かば先生 | 感覚と道具はりす先生、健康と安全はくま先生 |
| ぽけっとさん | 残す情報の選択はふくろう先生、今の対話はことり先生 |

先生同士は互いを否定しない。「その見方は違う」ではなく、「今度はこちらの見方も重ねてみよう」と関わる。

## 9. シリーズ共通の物語エンジン

```text
1. 子どもの日常と、心が動いた瞬間
2. 大人には困りごとに見える出来事
3. 担当の先生が、その先生固有の手がかりを見つける
4. 環境、道具、距離、伝え方のどれかを小さく変える
5. 子どもの反応から見立てを確かめる
6. 保護者が、すでにあった育ちに気づく
7. 親子の日常へ戻り、次にも使える見方を残す
```

これは筋書きを固定する型ではなく、シリーズの価値観を確認するための物語エンジンである。空間を移動する展開は [`world-space-story-map.md`](world-space-story-map.md)、視点、三幕、EAT＋Eは [`story-narrative-guide.md`](story-narrative-guide.md) を正本とする。

## 10. 各作品を作り始める条件

```text
リアルな声
↓
中心となる一つの出来事
↓
子どもがすでにしていること
↓
保護者に起きてほしい気づき
↓
最初に見る手がかり
↓
担当する先生
```

テーマやフレームから先に決めず、実際の声と具体的な場面から始める。
