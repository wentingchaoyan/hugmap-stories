## 2. シリーズの世界観

HugMap Storiesは、子どものできなさを直す物語ではない。

子どもはすでに、見ている、感じている、試している、伝えようとしている。動物の先生たちは、その小さなサインを見つけ、保護者が子どもの育ちに気づけるようにする。

先生たちは、困ったときだけ現れる救助隊ではない。普段から親子の少しそばにいて、保護者が「どうしてだろう？」と立ち止まったとき、その場面に必要な見つけ方を持つ先生が一歩前へ出る。

先生たちは、一つの開かれた「HugMapの家」で暮らしている。そこには、休む、感じる、動く、作る、伝える、考える、つなげるための場所がある。場所は発達の優劣を示す段階ではなく、そのとき必要な関わり方を選ぶための行き先である。

```text
動物たちは、いつも日常の近くにいる。
保護者が「どうしてだろう？」と立ち止まったとき、
その場面に必要な手がかりを持つ先生が一歩前へ出る。
```

## 3. シリーズが信じること

| 信じること | 物語での表し方 |
|---|---|
| 子どもはすでに世界と関わっている | 最初から絵の中に小さなサインを置く |
| 行動には本人なりの理由がある | 表面だけで決めつけず、前後や反応を見る |
| 一つの正解より、合う条件を探す | 環境、道具、距離、速さ、伝え方を変える |
| 全部頑張らなくてよい | 休む、断る、見るだけも選択として認める |
| 楽しさは学びの入口になる | 一見どうでもよいことから遊びが始まる |
| 強みは伸ばせる | できなさの克服だけをゴールにしない |
| 成長は周囲と祝える | 保護者が小さな変化に気づく場面を作る |
| 可能性は一人で支えない | 先生同士、家庭、必要な専門家へつなぐ |

## 4. シリーズ共通の約束

- 子どもを困りごとの代表として扱わない。
- 先生が子どもの気持ちを断定しない。
- 本人の反応を見て、見立てを確かめる。
- 発語、速さ、回数、完食だけを成功基準にしない。
- 悲しさや難しさを、前向きな言葉で急いで消さない。
- 一度の工夫ですべてが解決したように描かない。
- 必要な医療・発達相談・専門支援を、絵本だけで代替しない。
- 最後は先生の解説ではなく、親子の日常へ場面を返す。
- 先生やアプリがいない場面でも、保護者が次のサインを見つけられるようにする。

## 5. キャラクターを分ける軸

先生たちは専門職名だけで分けない。次の二つの問いで個性を定義する。

> この先生は、子どもの世界の何に最初に気づくか。
>
> その手がかりを、どのような方法で確かめるか。

同じ場面を見たとき、全員が違う手がかりを見つけられることを、キャラクター成立の条件とする。

## 6. キャラクター早見表

キャラクターを列、重要な比較軸を行に置く。これをシリーズ全体のキャラクター判断の入口とする。

### メインキャラクター

| 軸 | ことり先生 | りす先生 | うさぎ先生 |
|---|---|---|---|
| **人物像** | 傾聴者 | 探偵兼発明家 | 伴走型の応援者 |
| **基本の動き** | 待つ・聞く | 調べる・作る | 一緒に動く |
| **物語の入口** | 伝える・つながる | 感じる・試す・工夫する | 動く・挑戦する |
| **関心テーマ** | 発声、発音、語彙、文法、会話、共同注意、模倣、AAC | 五感、感覚調整、手先、手と目の協調、道具、探究遊び | 姿勢、バランス、筋力、持続力、身体の使い方、外遊び |
| **得意なスキル** | 傾聴、ミラーリング、言葉の拡張、質問、選択肢、歌と口遊び | 観察、比較、動作の分解、道具の工夫、刺激量と環境の調整 | 見本、小さな段階づけ、足場と支えの調整、休憩、遊びへの変換 |
| **最初に見るもの** | 目、声、仕草、身体の向き、間 | 触る、握る、匂う、繰り返す | 姿勢、足元、バランス、疲れ方 |
| **見つけるもの** | 届こうとしているもの | 身体が探す感覚と参加方法 | 一歩の中のがんばり |
| **信じていること** | ことばの前から会話は始まっている | 行動には身体が探すものがある | 速さより力を使える条件が大切 |
| **強み** | 待つ、まねる、問いかける | 手がかりを探し、試して調整する | 小さな挑戦を楽しく応援する |
| **愛嬌のある弱点** | **のんき**（待ちすぎる） | **いたずら好き**（試しすぎる） | **張り切り屋**（応援しすぎる） |
| **主な象徴** | 吹き出し、柔らかな線、ベル、歌 | 道具箱、布、ブラシ、トング | 黄色いボール、足跡、低い台 |
| **補う先生** | ふくろう、うさぎ | ことり、くま | くま、ことり |

メイン3人は普段から子どもの近くにいて、シリーズの入口になる。「待つ」「調べて作る」「一緒に動く」という異なる動きで物語にリズムを作る。

### サブキャラクター

| 軸 | ふくろう先生 | くま先生 | ぞう先生 | かば先生 | ぽけっとさん |
|---|---|---|---|---|---|
| **人物像** | 分析者・会議の進行役 | 守り手・保健室の先生 | 翻訳者・案内図を描く人 | 辛抱強い料理仲間 | 記録者・バトンを渡す人 |
| **物語の入口** | 考える・理由を探す | 休む・身体を守る | 見通す・分かる形にする | 食べる・安全に関わる | 残す・次へつなぐ |
| **関心テーマ** | 行動の前後、感情、環境、習慣、理由、問題解決 | 体調、睡眠、呼吸、痛み、成長、安全、休息 | 視覚支援、予定、順番、選択、学び方、見通し | 摂食、嚥下、口の動き、食感、温度、姿勢、食事の安心 | 観察記録、変化、経過、家庭の気づき、引き継ぎ、連携 |
| **得意なスキル** | 時系列整理、比較、仮説づくり、作戦会議 | 普段との差の確認、休息、安全確認、適切な相談への接続 | 絵、カード、地図、予定表、手順と選択肢の見える化 | 拒否の受容、食べ方の観察、段階づけ、食具と環境の調整 | 事実と解釈の分離、短い記録、要約、必要な人への共有 |
| **最初に見るもの** | 行動の前後、相手、場所、結果 | 顔色、呼吸、痛み、普段との差 | 指示、順番、選択肢、見通し | 食感、温度、姿勢、拒否 | 小さな変化、事実、気づき |
| **見つけるもの** | 行動の理由と必要な支援 | いつもとの違い | 分かるための別の道 | 食べ物と関われる条件 | 消えそうな気づき |
| **信じていること** | 前後を見ると助け方が見える | 違いは身体からの知らせ | 伝え方が合っていないことがある | 「いらない」も意思表示 | 残して渡せば支援につながる |
| **強み** | 前後を整理し、仮説を比べる | 身体と安全を守る | 予定や選択を見える形にする | 拒否を尊重し、ゆっくり付き合う | 事実を記録して渡す |
| **愛嬌のある弱点** | **理屈っぽい**（考えすぎる） | **心配性**（止めすぎる） | **整理したがり**（見せすぎる） | **粘り屋**（付き合いすぎる） | **メモ魔**（残しすぎる） |
| **主な象徴** | 三枚カード、時計、作戦ボード | 聴診器、毛布、休憩場所 | 絵カード、予定ボード、太い鉛筆 | 小さなスプーン、カップ、試食皿 | ポーチ、記録帳、鉛筆、日付札 |
| **補う先生** | ことり、うさぎ | うさぎ、りす | ことり、ふくろう | くま、りす | ことり、ふくろう |

サブは格下ではない。場面に必要な別の視点を加え、特定テーマでは主役になる。ぽけっとさんは記録と引き継ぎを通して、複数の物語をつなぐ。

弱点は能力の不足ではなく、強みを使いすぎたときの偏りとして描く。まず強みが役立ち、その後に裏返しが現れる。別の先生は否定せず、異なる見方を重ねて補う。仕草、口調、具体的な台詞は [`character-expression-guide.md`](character-expression-guide.md) を参照する。

## 7. 同じ場面を見たときの違い

例: 子どもが電車のおもちゃを繰り返し押している。

| 先生 | 最初に気づくこと |
|---|---|
| ことり先生 | 電車を見たあと、一瞬相手の顔を見ている |
| りす先生 | 車輪の振動、押す力、音の違いを確かめている |
| うさぎ先生 | 同じ姿勢を保ち、押す力を調整している |
| ふくろう先生 | どんな前触れや反応のあとに繰り返すか |
| くま先生 | 疲れ、痛み、普段との違いがないか |
| ぞう先生 | 遊びの順番や次の展開を見える形にできるか |
| かば先生 | 口や呼吸の動き、感覚との関係がないか |
| ぽけっとさん | いつ、どこで、何が変わったかを事実として残す |

## 8. チーム内の連携

| 最初に見つけた先生 | 別の視点が必要なとき |
|---|---|
| ことり先生 | 身体と感覚はりす先生、行動整理はふくろう先生 |
| りす先生 | 動作と姿勢はうさぎ先生、安全と体調はくま先生 |
| うさぎ先生 | 感覚はりす先生、本人の意思確認はことり先生 |
| ふくろう先生 | 気持ちの受容はことり先生、小さな実行はうさぎ先生 |
| くま先生 | 安全な挑戦はうさぎ先生、環境調整はりす先生 |
| ぞう先生 | コミュニケーションはことり先生、情報整理はふくろう先生 |
| かば先生 | 感覚と道具はりす先生、健康と安全はくま先生 |
| ぽけっとさん | 残す情報の選択はふくろう先生、今の対話はことり先生 |

先生同士は互いを否定しない。「その見方は違う」ではなく、「今度はこちらの見方も重ねてみよう」と関わる。

## 9. シリーズ共通の物語エンジン

```text
1. 子どもの日常と、心が動いた瞬間
2. 大人には困りごとに見える出来事
3. 担当の先生が、その先生固有の手がかりを見つける
4. 環境、道具、距離、伝え方のどれかを小さく変える
5. 子どもの反応から見立てを確かめる
6. 保護者が、すでにあった育ちに気づく
7. 親子の日常へ戻り、次にも使える見方を残す
```

これは筋書きを固定する型ではなく、シリーズの価値観を確認するための物語エンジンである。空間を移動する展開は [`world-space-story-map.md`](world-space-story-map.md)、視点、三幕、EAT＋Eは [`story-narrative-guide.md`](story-narrative-guide.md) を正本とする。

## 10. 各作品を作り始める条件

```text
リアルな声
↓
中心となる一つの出来事
↓
子どもがすでにしていること
↓
保護者に起きてほしい気づき
↓
最初に見る手がかり
↓
担当する先生
```

テーマやフレームから先に決めず、実際の声と具体的な場面から始める。

## 11. 今後整備する資料

- 先生同士の距離感と、チーム内会話のガイド
