# シリーズの価値観を代表するストーリー候補

更新日: 2026-07-29

役割: [`story-backlog.md`](story-backlog.md)にある作品の種から、HugMap Storiesの共通の価値観と約束を表現しやすい候補を選ぶ。

このファイルは候補の進行状態を管理しない。作品の追加・優先順位・制作状態は`story-backlog.md`、シリーズ共通の価値観は[`world-and-character-guide.md`](world-and-character-guide.md)を正本とする。

## 1. 結論

シリーズ全体を代表する一冊の第一候補は、T-01である。

> **『いっしょにやるって、どこにいること？』**

各先生の専門性を紹介する候補と、シリーズの価値観を代表する候補は、目的が異なる。

| 目的 | 優先候補 |
|---|---|
| メイン3人の専門性を順に紹介する | K-06、R-01、U-01 |
| シリーズの価値観を一冊で見せる | **T-01、R-05、K-05** |
| 道具、連携、社会とのつながりを見せる | T-03、P-01 |
| 安全と専門支援への接続を見せる | F-01、B-01、H-04 |

## 2. 代表性の高い候補

| 優先 | ID | 仮題 | 主に表現できる価値観 |
|---:|---|---|---|
| **1** | **T-01** | **いっしょにやるって、どこにいること？** | 多様な参加、すでにある関わり、休む・見る選択、条件調整、先生同士の連携 |
| **2** | **R-05** | **もういっかいは実験中** | 行動には理由がある、楽しさは学び、子どもの好奇心、決めつけず観察する |
| **3** | **K-05** | **ぼくの「おしまい」見えた？** | 発語以外の表現、拒否の尊重、本人の反応を確かめる |
| 4 | T-02 | まだやってないのに、できないってわかるの？ | できないことを前提にしない、先回りしない、必要な助けを本人が選ぶ |
| 5 | T-03 | からだのそとにも、ぼくのなかまがいる？ | 道具によるアクセス、可能性は一人で支えない、参加方法を増やす |
| 6 | F-01 | ぼくは怒りたかったんじゃない | 行動を表面で決めつけない、前後、感覚、伝達、体調を一緒に考える |
| 7 | P-01 | 今日の小さな「できた」をしまって | 成長を周囲と祝う、家庭と支援者をつなぐ、小さな変化を残す |

## 3. 第一候補 T-01

### 子どもから始まる問い

> **いっしょにやるって、どこにいること？**

輪の中でみんなが踊っている。子どもは少し離れた場所にいる。

大人からは「参加していない」ように見える。しかし、よく見ると、子どもは別の形ですでに関わっている。

- 音楽が止まると指が動く。
- うさぎ先生が跳ぶと、足先が少し上がる。
- 道具をほかの子へ渡す。
- 離れた場所から動きを見ている。
- 途中で休み、好きな部分だけ戻ってくる。

### 先生たちの役割

| 先生 | この物語で行うこと |
|---|---|
| ことり先生 | 小さな声、視線、指の動きを、ことばになる前の応答として受け取る |
| りす先生 | 音、距離、道具、参加する場所を調整する |
| うさぎ先生 | 全部ではなく、一部分だけ一緒に動く |
| ぞう先生 | 「見る」「渡す」「一回だけ」などの参加方法を見える形にする |
| くま先生 | 疲れや身体の状態、安全を確認する |

先生が子どもの内面を代弁して終わらない。保護者は小さなサインへ気づき、問いを持ち帰る。

> あの指、音を待っていたのかな。
>
> こんど、きいてみよう。

### シリーズの価値観との対応

| シリーズが信じること | T-01での表現 |
|---|---|
| 子どもはすでに世界と関わっている | 離れた場所でも音や動きへ応答している |
| 行動には本人なりの理由がある | 輪から離れる前後と身体の反応を見る |
| 一つの正解より、合う条件を探す | 音、距離、場所、道具を変える |
| 全部頑張らなくてよい | 見るだけ、一部分だけ、休んで戻る |
| 楽しさは学びの入口になる | 好きな音や動きから参加が始まる |
| 強みは伸ばせる | 観察力、リズム、道具を渡す力に気づく |
| 成長は周囲と祝える | 保護者が小さな参加に気づく |
| 可能性は一人で支えない | 複数の先生が異なる見方を重ねる |

### 制作時の注意

- 「参加しなくてもよい」で閉じず、本人が参加したいときの方法を増やす。
- 輪の中へ入ることを最終的な成功にしない。
- 指が動いたことを「参加した証拠」と断定せず、次に確かめる手がかりとして扱う。
- 先生全員へ均等な出番を与えず、子どもの場面に必要な先生だけを前へ出す。
- 最後は先生の説明ではなく、保護者が次の日常でサインを見つける場面へ返す。

## 4. 小さく作りやすい代表候補 R-05

### 『もういっかいは実験中』

子どもがスプーンを何度も落とす。大人は「また落とした」と止めようとする。

りす先生は、高さ、素材、落とす場所を一つずつ変え、子どもの反応を見る。

- 高いところと低いところ。
- 木と金属。
- 布の上と床の上。
- 大きい音と小さい音。

「困った行動」に見えたものが、音、重さ、落ち方を確かめる実験だったかもしれないと気づく。

この候補は、一つの日常場面だけで次の価値観を表現できる。

- 行動には本人なりの理由がある。
- 楽しさは学びの入口になる。
- 子どもはすでに見て、感じて、試している。
- 大人は正解を教える前に観察する。

シリーズの短いサンプルや、画風を比較する試作にも向いている。

## 5. ことり先生の代表候補 K-05

### 『ぼくの「おしまい」見えた？』

子どもは、発語ではなく次の方法で「おしまい」を表す。

- 顔をそむける。
- 手を止める。
- 身体を後ろへ引く。
- 物を返す。
- 写真カードやAACで示す。

ことり先生は一つを正解と決めず、動きを小さく返し、意味を確かめる。

この候補は、ことり先生の信念を直接表現できる。

> **ことばの前から伝え合いは始まり、そのやりとりの中でことばも育つ。**

「ことばがなくてもよい」だけで終わらず、すでにある表現を受け取って往復を作り、ことばの育ちも支える。

## 6. 用途別の選び方

| 作りたいもの | 選ぶ候補 | 理由 |
|---|---|---|
| シリーズの理念を伝える代表作 | **T-01** | 八つの共通価値を最も広く含められる |
| 短く、分かりやすいサンプル | **R-05** | 一場面で観察前後の変化を描ける |
| ことり先生のキャラクター代表作 | **K-05** | 新しい信念と傾聴・確認の動きが一致する |
| 道具や支援機器への見方を伝える | T-03 | 身体、道具、参加を肯定的につなげられる |
| 行動の理由を多面的に考える | F-01 | 感覚、伝達、見通し、体調を比較できる |
| 保護者と支援者の連携を伝える | P-01 | 小さな変化を残し、別の場所へ渡せる |

## 7. 次の判断

T-01を企画化する場合、最初に次の三点を決める。

1. 子どもが参加している活動は、踊り、歌、外遊びのどれか。
2. 主担当をうさぎ先生、りす先生、ことり先生の誰にするか。
3. 一冊に登場させる先生を最大何人にするか。

この三点を決めた後、[`story-narrative-guide.md`](story-narrative-guide.md)に沿って子どもの問い、三幕、読後変化を作り、作品別の`script.md`へ移す。
