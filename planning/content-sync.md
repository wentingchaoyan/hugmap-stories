# withu参照・同期方針

## 基本方針

- `withu` はアプリ、データベース、キャラクター原本、専門情報の参照元。
- `hugmap-stories` は公開する静的絵本と、絵本用に承認された素材の保管先。
- 絵本の公開画面からアプリのソースファイルや本番データベースを直接参照しない。
- 同期は自動上書きではなく、内容と見た目を確認したうえで行う。

## キャラクター同期

1. `withu/design/personas/v2/personas.json` で役割と禁止事項を確認する。
2. 公式画像を `shared/characters/` へコピーする。
3. `shared/asset-manifest.json` の取得元コミットと日付を更新する。
4. 既存全作品を確認し、意図しない見た目の変化がないことを確認する。
5. キャラクター同期だけのコミットとして記録する。

## FAQ・Activity参照

FAQやActivityは、企画に必要な項目だけを `content/references/` へ静的JSONとして書き出します。

```json
{
  "sourceType": "faq",
  "sourceCode": "FAQ-C009",
  "title": "指さしをしない",
  "summary": "視線、手渡し、大人の手を取る行動も伝達になり得る",
  "sourceCommit": "withu commit hash",
  "reviewedAt": "YYYY-MM-DD"
}
```

公開用本文には必要な内容を再編集し、FAQの全文コピーや非公開情報を含めません。

## デザイン同期

- ブランド色は `shared/base.css` で固定する。
- アプリ側の色変更は自動反映しない。
- 絵本で採用する場合は、全作品のコントラストと表示を確認してから更新する。

## アプリへの導線

- 絵本からHugMapへは公開URLでリンクする。
- アプリ内部の画面パスやローカルファイルパスを公開HTMLへ含めない。
- 専門相談への誘導は、診断や効果を断定しない表現にする。
