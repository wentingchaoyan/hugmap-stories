# 3日間 キャラクター・ポーズ制作アサイン

役割: **キャラクター素材を作るための短期作業計画。設定の正本ではない**

対象: プロジェクトオーナー
期間: 3日間、1日5〜6時間を想定
目的: HugMap Storiesの「日常の近くにいる先生チーム」という世界観を、説明文なしでも伝えられる最小限のキャラクター素材を揃える。

## 完了条件

- 8キャラクターの姿と体格差が、一列に並べたときに見分けられる。
- 各キャラクターの専門性が、道具だけに頼らず姿勢・視線・距離で伝わる。
- 先生が子どもを「直す」のではなく、観察し、待ち、選択肢を差し出す関係になっている。
- チームが救助隊ではなく、普段から一緒に過ごす仲間として見える。
- ラフ段階でも、Web画面へ仮置きできる背景透過PNGまたはレイヤー付き原稿がある。

## 制作物

| 種類 | 点数 | 内容 |
|---|---:|---|
| 基本立ちポーズ | 8 | 全身、正面寄り、自然な待機姿勢 |
| 専門性ポーズ | 8 | 各キャラクターの「見つけ方」が分かる一動作 |
| チーム場面ラフ | 3 | 集う、相談する、親子を見守る |
| 比較シート | 1 | 8体の身長、体格、色、道具の比較 |

合計19点＋比較シート。清書の優先順位は「基本立ちポーズ → 専門性ポーズ → チーム場面」とする。

---

## Day 1 — 全員の存在感と統一感を決める

目安: 5〜6時間

### 1. 8体のシルエットを揃える（2時間）

- [ ] ことり先生
- [ ] りす先生
- [ ] うさぎ先生
- [ ] ふくろう先生
- [ ] くま先生
- [ ] ぞう先生
- [ ] かば先生
- [ ] ぽけっとさん

各キャラクターを「基本立ちポーズ」で描く。手足、耳、羽、尻尾などの形が重ならないようにし、黒いシルエットでも半数以上を識別できる状態を目指す。

### 2. 体格・色・象徴道具の比較シートを作る（1.5時間）

- [ ] 8体を同じ地面線に並べる。
- [ ] 身長差と頭身を決める。
- [ ] メイン色が隣同士で混同しないか確認する。
- [ ] 象徴道具は各1点だけ添える。

象徴道具:

- ことり: 二つの吹き出し、薄い歌集
- りす: 小さな道具箱
- うさぎ: 黄色いボール、足跡
- ふくろう: 前・行動・後の三枚カード
- くま: 聴診器
- ぞう: 絵の学習ボード
- かば: 小さなスプーン、持ち手つきカップ
- ぽけっと: ポーチ、記録ボード、鉛筆

### 3. 共通表情を確認する（1.5〜2時間）

清書ではなく、顔だけの小さなサムネイルでよい。

- [ ] 穏やかに見守る
- [ ] 小さな発見に気づく
- [ ] 心配を急いで消さず、隣にいる

全員を満面の笑顔にしない。「うれしい」「集中」「静かな心配」の出方を、耳・羽・尻尾・肩・視線で描き分ける。

### Day 1終了時のレビュー

- 8体を名前なしで見ても区別できるか。
- 全員が同じ性格、同じ笑顔に見えないか。
- 医療チームや戦隊ではなく、親しみのある先生チームに見えるか。

---

## Day 2 — 専門性が伝わる一動作を描く

目安: 5〜6時間

各キャラクター1点。子どもを大きく描き込まず、視線の先、小さな手、玩具などの部分表現でもよい。大切なのは先生の動作である。

### 午前: 観察と参加を支える4体（2.5〜3時間）

- [ ] **ことり先生** — 子どもの斜め横で同じ高さになり、首を傾け、羽を重ねて返事を待つ。
- [ ] **りす先生** — 道具を直接渡さず、二つの素材を選べる位置へ置き、尻尾を止めて反応を見る。
- [ ] **うさぎ先生** — 一歩先で引っ張らず、足元を示しながら隣で支えを差し出す。
- [ ] **ふくろう先生** — 三枚のカードを床に並べ、出来事の前後を静かに見比べる。

### 午後: 安心と次の道をつくる4体（2.5〜3時間）

- [ ] **くま先生** — 子どもと同じ高さで、記録と本人の様子を見比べ、「いつもとの違い」を確かめる。
- [ ] **ぞう先生** — 長い紙へ順番を描き、鼻先で二つの進み方を選べるよう示す。
- [ ] **かば先生** — 食べさせるのではなく、小さな一口と休憩の選択肢をテーブルへ置いて待つ。
- [ ] **ぽけっとさん** — 親子の小さな気づきをカードへ書き、ポーチへしまって次の人へ渡す。

### Day 2終了時のレビュー

- 道具を隠しても、その先生らしい姿勢や距離になっているか。
- 子どもの正面を塞いだり、腕を引いたり、強制したりしていないか。
- 観察 → 応答 → 待つ、のどこを描いたポーズか説明できるか。

---

## Day 3 — チームと世界の空気を描く

目安: 5〜6時間

### 1. チーム場面ラフを3点描く（3時間）

- [ ] **朝のひろば** — 8体が開放的な場所に集まる。全員を整列させず、準備、会話、休憩など別々の小さな動きを入れる。
- [ ] **二人で手がかりを渡す** — 主役の先生が気づき、別の先生またはぽけっとさんへ共有する。専門外なら仲間を呼ぶ関係を示す。
- [ ] **親子の日常へ返す** — 先生たちは前景で解決を宣言せず、少し離れた場所から、保護者が子どものサインを見つける瞬間を見守る。

背景へ最低限入れる場所:

- ゆっくり休める場所
- 身体や感覚を試せる場所
- みんなで集まれる開放的な場所
- 一人で安心して過ごせる小さな場所
- 気づきや記録を保管する場所

### 2. 優先素材を仕上げる（1.5〜2時間）

- [ ] Day 1の基本立ちポーズ8点を背景透過で書き出す。
- [ ] Day 2から特に伝わりやすい3点を選び、線と色を整える。
- [ ] ファイル名を統一する。

推奨ファイル名:

```text
<character>-stand-v1.png
<character>-observe-v1.png
team-plaza-rough-v1.png
team-handoff-rough-v1.png
team-family-distance-rough-v1.png
```

### 3. 最終確認（30分）

- [ ] 8体の縮小表示でも顔とポーズが潰れない。
- [ ] 背景透過PNGに不要な白縁がない。
- [ ] 光の方向、線幅、影の濃さが揃っている。
- [ ] 子どもの反応を待つ余白が画面内にある。
- [ ] 「困った行動の中にも、育っているものがある」という中心メッセージに反していない。

## 3日で終わらない場合の削減順

1. チーム場面の清書をやめ、ラフのまま残す。
2. 専門性ポーズは、ことり・りす・ふくろう・ぽけっとの4点を優先する。
3. 共通表情は個別ファイルにせず、比較シート内のサムネイルに留める。

基本立ちポーズ8点と比較シートは削らない。今後のすべての絵本で再利用する基準素材になるためである。
