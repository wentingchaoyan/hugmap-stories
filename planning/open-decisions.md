## 2. 国際展開を見据えた名前と即時認識

出典: 内田さん

### 2.1 今回決めること

- キャラクター名を「ことり先生」のような動物種＋先生だけにするか、固有名を付けるか。
- 日本語名と国際名を同じにするか、翻訳・ローカライズするか。
- 名前だけでIPとして展開するか、当初は動物種・役割の説明を添えるか。
- 絵本の信頼感と、グッズ・スタンプ・アニメーションでのキャラクター性をどう両立するか。
- 顔や持ち物が見えなくても、シルエット、色、動き、子どもとの距離で誰か分かる設計にするか。
- 出身地を設定するか。設定する場合、HugMapの家や日常世界とどうつなぐか。

### 2.2 現時点の推奨仮説

**C案: 説明できる入口から、固有名だけで成立するIPへ育てる二層構造**を第一候補とする。

```text
初登場・保護者向け
固有名＋動物種＋見つけ方
例: 小鳥のミモ先生｜ことばの前を聴く小鳥

認知後・表紙・グッズ
固有名のみ
例: Mimo
```

この案はまだ採用決定ではない。日本語では役割をすぐ理解でき、国際展開では短い固有名を育てられる可能性を比較する。

| 案 | 名前の構造 | 強み | 懸念 |
|---|---|---|---|
| A | 動物種＋先生を維持 | 日本では意味がすぐ分かり、現在の作品を変更しなくてよい | 国際的な発音、検索、グッズ上の固有性が弱い |
| B | 固有名だけへ変更 | キャラクターIPとして独立しやすい | 初見で動物、役割、専門性が分からない |
| **C** | **固有名＋動物種・役割から始め、後に固有名へ移行** | **理解しやすさとIP展開を段階的に両立できる** | 表記ルールと移行時期を決める必要がある |

参考にする考え方:

- Miffyのように、複数言語で発音しやすく、意味を背負わせすぎない短い国際名。
- POP MART型の固有名は、名前だけで役割を説明せず、強い造形と反復露出によって育てる。
- Sanrio型は、固有名に加え、一つの不変な形、服飾、性格、好きなことを結びつける。
- HugMapでは、上記をそのまま模倣せず、**見つけ方と子どもとの関係**を識別記号へ加える。

### 2.4 名前を判断する軸

| 軸 | 確認内容 |
|---|---|
| 発音 | 日本語・英語でおおむね2〜3音節、初見でも言いやすいか |
| 聞き分け | メイン同士で頭文字、母音、リズムが十分に違うか |
| 綴り | 聞いたあとに綴りを推測しやすいか |
| 記憶 | 3人を一度紹介したあと、名前を思い出せるか |
| 人物像 | 音から受ける温度が、傾聴者・探偵・応援者に合うか |
| 年齢耐性 | 幼児向けでも、保護者・成人向け情報でも幼すぎないか |
| 展開性 | 絵本タイトル、音声、スタンプ、ぬいぐるみで呼びやすいか |
| 文化・言語 | 主要展開言語で不快、誤解、発音困難な意味がないか |
| 所有可能性 | 商標、キャラクター、商品、ドメイン、SNSとの衝突がないか |

商標調査は候補を2案程度へ絞ってから専門的に行う。検索結果が少ないことだけを、使用可能の根拠にしない。

### 2.5 ひと目で認識させる設計

識別は顔や職業道具だけに頼らず、次の5層で作る。

| 層 | 決めること | メイン3人の現在の仮説 |
|---|---|---|
| シルエット | 黒一色、後ろ姿、部分表示でも分かる固有形 | ことり＝頭頂の羽と重なる翼、りす＝大きな渦巻き尻尾、うさぎ＝長い非対称の耳と前へ出る足 |
| 固有色 | 小さく表示しても追える主色と合図色 | ことり＝黄＋橙、りす＝橙＋紫、うさぎ＝白・赤紫＋黄 |
| 身体に残る記号 | 道具を置いても消えない服・身体の印 | ことり＝二つの点、りす＝渦形ポケット、うさぎ＝片耳または足元の印を検討 |
| 基本動作 | 静止画3枚でも性格が分かる動き | ことり＝気づく・まねる・待つ、りす＝観察・出しすぎる・選んで戻す、うさぎ＝張り切る・気づく・合わせる |
| 関係の距離 | 子どもとの位置だけでも役割が分かる | ことり＝斜め横、りす＝手元と同じ高さ、うさぎ＝一歩前から隣へ移る |

避けること:

- 全員へ同じ白衣や同じ形のベストを着せ、シルエットを似せる。
- 虫眼鏡、ボール、歌などの持ち物がないと誰か分からない。
- 色だけで区別し、白黒印刷や色覚の違いで識別できなくなる。
- 表情を大きく変えすぎ、同じキャラクターに見えなくなる。
- 専門職の記号を増やし、子どもとの関わり方が見えなくなる。

### 2.6 認識テスト

正式決定前に、メイン3人だけで次を行う。

1. 黒いシルエットだけを見せる。
2. 32px程度の小さなアイコンを見せる。
3. 顔を隠し、身体と姿勢だけを見せる。
4. 象徴道具を持たせずに見せる。
5. 後ろ姿または一部分だけを見せる。
6. 3秒見せ、名前と「どんな子か」を一語で答えてもらう。

仮の判定基準:

- 3人の識別: 80%以上
- 固有名の想起: 60%以上
- 性格・役割の方向性: 70%以上

種族名を答えられるだけでは、キャラクターを認識したとは判定しない。「ミモ」「聴く子」のように、名前または人物像へ結びつくかを見る。

### 2.7 決定する順番

```text
1. 絵本中心か、キャラクターIP中心か、段階的に両立するか
2. 固有名を付けるか、二層表記にするか
3. メイン3人の命名規則と音の温度
4. メイン3人のシルエット・色・身体記号
5. 名前＋絵の認識テスト
6. 候補を絞って言語・商標・権利調査
7. 正式名と表記ルールを決定
8. サブキャラクターへ同じ規則を展開
```

判断するときの問い:

- 名前や造形が、キャラクターの見つけ方を豊かにするか。
- 絵本の先生としての信頼感と、物として欲しくなる愛着のどちらを優先するか。
- 固有名を聞いたとき、幼すぎる、玩具的すぎる、専門的すぎる印象がないか。
- 名前を知らなくても絵で役割が分かり、絵を見なくても音で名前を区別できるか。
- 出身地が物語を豊かにするか、設定量を増やすだけになっていないか。
- 文化的な固定観念や不要な地域性を持ち込まないか。

決定後の反映先:

- 正式名、呼び方、命名規則: `world-and-character-guide.md`
- シルエット、色、身体記号、基本動作: `character-expression-guide.md`
- 顔・耳・羽・尻尾の描画仕様: `character-facial-expression-reference.md`

## ⭐️⭐️⭐️5. メンタリングで相談する制作軸

### 5.1 キャラクター作り

参照する作品:

- 『アンパンマン』

相談したいこと:

- キャラクターをひと目で理解できる、簡潔な3つのキーワードをどう定めるか。
- 性格だけでなく、親子がそのキャラクターから受け取る感触を言葉にできているか。
- 役割、形、色、動き、口調が一つの印象へまとまっているか。
- 専門性を持ちながら、説明的で堅いキャラクターにならないために何が必要か。
- 現在の3語とメイン・サブの分け方が、シリーズ展開に耐えられるか。

現在の仮説:

- シリーズ全体: **気づく・つながる・育つ**
- 各キャラクターの仮の3語は `world-and-character-guide.md` の「ひと目で感じる3語」を参照する。

### 5.2 ストーリーの組み立て

現在の仮説:

どちらか一方を選ぶのではなく、物語の異なる部分で役割を分けて参照する。

> **身近な「どうして？」から想像を広げ、短い言葉と絵の余白の中で、親子に気づきを返す。**

固有の絵柄や文体を再現するのではなく、次の制作思想をHugMap独自の表現へ置き換える。

| 参照先 | 担当する役割 | HugMapで取り入れたいこと |
|---|---|---|
| ヨシタケシンスケ | 物語を動かす入口とエンジン | 子どもの視点、身近な生活場面、当たり前を疑う問い、思いがけない発想、先生が正解へ戻さず一緒に想像する展開 |
| 谷川俊太郎 | 表現の土台と読後感 | 説明し切らない余白、短い言葉、音と反復、ページの間、理解させるより先に感じさせる結末 |

物語の中での役割分担:

| 物語の部分 | 主に参照する考え方 | HugMapでの表現 |
|---|---|---|
| 日常の小さな違和感 | ヨシタケシンスケ | 靴を履かない、同じ音を繰り返す、食べ物を触るなど、身近な生活から始める |
| 子どもの問い | ヨシタケシンスケ | 「声って、口から出ないと声じゃないの？」のように、当たり前を問い直す |
| 想像の広がり | ヨシタケシンスケ | 視線、指、足音も「ことば」かもしれない、と発想を広げる |
| 先生の関わり | 両方 | 答えを説明せず、一緒に見て、短く問い返し、子どもの発想を受け取る |
| 子どもの発見 | 谷川俊太郎 | 短い言葉、音、反復、絵の変化で感じさせる |
| 保護者の気づき | 谷川俊太郎 | 「分かった」と説明せず、視線、姿勢、距離の変化で見せる |
| 結末 | 谷川俊太郎 | 完全な解決ではなく、余韻と次の小さな気づきを残す |

現時点では、**谷川俊太郎的な余白を表現の土台に6、ヨシタケシンスケ的な問いと発想を物語の推進力に4**ほど置く案を検討する。

本文では専門知識を説明し切らない。物語は子どもの経験と親子の気づきで閉じ、必要な解説は巻末の保護者向けページへ分ける。

メンタリングで相談したいこと:

- 専門的なテーマを、教訓や支援解説ではなく、子どもの問いから始まる物語にできるか。
- ヨシタケシンスケ的な問いを入口にし、谷川俊太郎的な余白で閉じる役割分担は自然か。
- 「余白6：問いと発想4」という重心はHugMapの世界観に合っているか。
- 子どもの思いがけない発想を、先生が正解へ戻さずに広げられるか。
- 生活上の小さな違和感から、当たり前を問い直す構造をどう作るか。
- 保護者向けの気づきを伝えながら、本文にどこまで説明を書かずに済むか。
- 絵、言葉、見開き、ページをめくる間のどこに余白を置くか。
- EAT＋Eなど現在の構造を、作品の自由さを損なわずにどう使うか。
- 作家固有の文体模倣にならず、HugMapらしい言葉のリズムをどう確立するか。

### 5.3 画風と、人間・動物の描き分け

現在迷っている方向:

1. ミッフィーのような**記号タイプ**
2. 表情やポーズを豊かに描く**キャラクター・アニメーション型**
3. 紙、布、絵の具などの質感を使う**コラージュ・素材型**
4. 水彩などで日常の空気を描く**生活描写型**

特に比較したい組み合わせ:

| 案 | 動物の先生 | 人間の親子 | 期待する効果 | 懸念 |
|---|---|---|---|---|
| A | 記号タイプ | キャラクター・アニメーション型 | 先生は役割が分かりやすく、親子は感情を豊かに描ける | 両者が別の作品世界に見えないか |
| B | 記号タイプ | 水彩・生活描写型 | 動物は普遍的な案内役、人間は現実の生活として描き分けられる | 記号と写実の差が強すぎないか |
| C | キャラクター・アニメーション型 | 水彩・生活描写型 | 先生に強い個性を持たせながら、親子の生活感を保てる | 先生が主役を奪わないか |
| D | 同じ基本画風＋素材差 | 同じ基本画風＋生活背景 | 一つの世界として統一しやすい | 動物と人間の役割差が弱くならないか |

相談したいこと:

- 動物と人間を別の描画方式にしても、同じ世界にいるように見せられるか。
- 子どもの視点と感情を中心にするには、どの組み合わせが適切か。
- キャラクターの再現性、絵本としての情緒、シリーズ量産性をどう両立するか。
- 白背景と境界線のない既存方針を残すか、素材や生活背景をどの程度加えるか。
- まず比較試作するなら、どの一場面・どの2案が判断しやすいか。
