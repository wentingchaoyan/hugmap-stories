# 動物キャラクターを設計するときに考える順番

作成日: 2026-08-09  
対象: 子ども向けの動物デフォルメキャラクター  
目的: 性格、印象、世界観、造形、展開性を一貫した順番で設計する

## 基本の順番

```text
1. 読者と役割
↓
2. 最初に与えたい印象
↓
3. 性格、欲求、弱点
↓
4. 世界観と暮らし
↓
5. 動物を選ぶ理由
↓
6. 性格を形へ翻訳
↓
7. 識別記号を絞る
↓
8. 仲間との違いを確認
↓
9. 物語の中で動かす
↓
10. 媒体と商品への展開を確認
↓
11. トレンドとの距離を決める
↓
12. 小さく試作して検証
```

## 1. 読者と役割を決める

最初に、誰がどの場面で出会うキャラクターなのかを決める。

- 主な読者の年齢は何歳か。
- 子ども、保護者、支援者の誰を主な読者にするか。
- 主人公、先生、友達、案内役、敵役のどれか。
- 読者に安心、共感、憧れ、笑いのどれを届けるか。
- 一度だけ登場するのか、シリーズを通して登場するのか。

HugMap Storiesでは、動物の先生が子どもの主役性を奪わないことを最初の条件にする。

## 2. 最初に与えたい印象を一語で決める

性格を細かく書く前に、見た瞬間の印象を一語または短い句にする。

例:

- 安心できる。
- 話しかけやすい。
- 好奇心がありそう。
- 少しいたずらっぽい。
- 不器用だけれど応援したくなる。
- 静かに見守ってくれそう。

複数の印象を並べすぎない。最初の印象を一つ、近づいた後に分かる印象を一つまでに絞る。

## 3. 性格、欲求、弱点を決める

性格は形容詞の一覧ではなく、行動を生む構造として考える。

| 項目 | 問い |
|---|---|
| 性格の核 | どのように他者や世界へ関わるか。 |
| 欲求 | 何をしたい、知りたい、守りたいのか。 |
| 弱点 | 何が苦手で、どのような失敗をするか。 |
| 安心する条件 | どの場所、相手、物、距離で落ち着くか。 |
| ギャップ | 見た目と内面の間にどんな意外性があるか。 |

弱点は欠陥として罰するためではなく、読者が感情移入する入口として使う。

## 4. 世界観と暮らしを決める

キャラクター単体ではなく、そのキャラクターがどのように暮らすかを考える。

- どこに住んでいるか。
- 誰と暮らしているか。
- 日常的に何をしているか。
- 何を食べ、何を持ち、どのくらいの大きさか。
- 人間と同じ道具を使うのか。
- 現実の動物に近いのか、完全に人間のように振る舞うのか。
- 世界の安全、危険、失敗はどの程度か。

世界観が日常型なら身近な衣服や道具、冒険型なら移動や能力を感じる身体、生活型なら家具や他者と並べられる寸法が必要になる。

## 5. 動物を選ぶ理由を確認する

「かわいいから」だけでなく、動物が持つ印象や身体的特徴を役割へ結びつける。

| 動物 | 利用できる印象・特徴 |
|---|---|
| 犬 | 親しみ、忠実さ、活発さ、垂れ耳や立ち耳 |
| 猫 | 自由さ、敏感さ、静かな観察、尻尾 |
| ウサギ | 聴く、跳ぶ、警戒、長い耳 |
| 熊 | 安心感、包容力、大きな身体 |
| リス | 好奇心、手先の器用さ、蓄える、大きな尻尾 |
| 鳥 | 聴く、話す、歌う、移動する、羽根 |
| アザラシ | 丸さ、柔らかさ、おっとりした動き |
| キツネ | 賢さ、機敏さ、少し不思議な印象 |

既存のイメージをそのまま使わず、一つだけ意外性を加える。

## 6. 性格を形へ翻訳する

文章で決めた印象や性格を、造形要素へ変換する。

| 与えたい印象 | 造形への翻訳例 |
|---|---|
| 安心 | 円、楕円、太い輪郭、低い重心 |
| 幼さ | 大きな頭、小さな鼻口、短い手足 |
| 活発 | 上向きの耳、開いた姿勢、斜めの線 |
| 穏やか | 垂れた耳、曲線、ゆっくりした姿勢 |
| 臆病 | 小さな身体、内向きの手足、狭い姿勢 |
| 頼もしさ | 大きな胴、太い脚、安定した立ち方 |
| いたずら | 尖った形、左右非対称、斜めの目線 |
| 好奇心 | 前傾姿勢、大きな目、動く耳や尻尾 |

形と性格を完全に一致させず、「見た目は大きいが慎重」などのギャップを一つ残してもよい。

## 7. 識別記号を一つか二つに絞る

黒いシルエット、小さなアイコン、顔だけの状態でも判別できる特徴を選ぶ。

候補:

- 耳の長さ、向き、形。
- 尻尾の輪郭。
- 頭の羽根や毛。
- リボン、帽子、眼鏡。
- 身体の比率。
- 一つの代表色。
- いつも持つ道具。

特徴を追加するたびに、「これがなくても同じキャラクターに見えるか」を確認する。識別に不要な装飾は減らす。

## 8. 仲間との違いを並べて確認する

キャラクターは必ず主要な仲間と同じ縮尺で並べる。

- シルエットが重複していないか。
- 代表色だけに差を頼っていないか。
- 身長、頭身、耳、尻尾、姿勢に違いがあるか。
- 性格や役割の違いが身体に表れているか。
- 一人だけ情報量や彩度が高すぎないか。
- 世界の住人として共通する造形文法があるか。

HugMap Storiesでは、先生ごとの違いを大きな表情だけでなく、耳、羽、尻尾、姿勢、距離、反復する道具で表す。

## 9. 物語の中で動かす

正面立ち絵だけで判断せず、最低限次の場面を描く。

1. 何もしていない通常姿勢。
2. 興味を持って近づく姿勢。
3. 相手の反応を受けて止まる、待つ姿勢。
4. 喜ぶ、困る、失敗する姿勢。
5. 他のキャラクターと並ぶ場面。

性格が顔だけでなく、身体の使い方と他者との距離に現れているかを見る。

## 10. 媒体と商品への展開を確認する

最初から商品化を目的にしなくても、媒体を変えたときに核が残るか確認する。

- 絵本の見開きで動かせるか。
- スマートフォン幅でも識別できるか。
- 32px程度のアイコンで特徴が残るか。
- 白黒印刷でも判別できるか。
- ぬいぐるみや立体にしたとき無理がないか。
- 刺繍やシールにしたとき線が潰れないか。
- 顔だけ、全身、後ろ姿のすべてで成立するか。
- 季節の服や持ち物を追加しても核が消えないか。

## 11. トレンドとの距離を決める

トレンドは出発点ではなく、基本設計を作った後に確認する。

確認する傾向:

- 弱さ、失敗、不完全さへの共感。
- かわいさと不穏さ、意外性の組み合わせ。
- 性別を限定しすぎない色と衣装。
- SNSの小さな画像やスタンプでの読みやすさ。
- 日常の感情を代弁できる表情や短い言葉。
- 大人も持ちやすい色数と情報量。

流行の形をそのまま足すのではなく、作品の価値観と矛盾しない要素だけを採用する。

## 12. 小さく試作して検証する

完成画を一枚作り込む前に、同じ条件で複数案を比較する。

### 最低限の試作

- 白黒シルエット3案。
- 顔と全身の小サイズ表示。
- 通常、接近、待機の3ポーズ。
- 主要キャラクターとの並び。
- 絵本の一場面への配置。

### 検証する問い

1. 最初に意図した印象が伝わるか。
2. 性格が説明文なしでも行動から分かるか。
3. その動物を選んだ意味があるか。
4. 世界観の中で浮いていないか。
5. 他のキャラクターと一目で区別できるか。
6. 小さくしても識別記号が残るか。
7. 子どもの主役性や解釈の余白を奪っていないか。
8. 別の物語でも動かし続けたいと思えるか。

- [ ] 性格の核、欲求、弱点、ギャップを決めた。
- [ ] 暮らす場所と日常の行動を決めた。
- [ ] その動物を選ぶ理由を説明できる。
- [ ] 性格を輪郭、比率、姿勢へ翻訳した。
- [ ] 識別記号を一つか二つに絞った。
- [ ] 仲間と同じ縮尺で並べた。
- [ ] 通常、接近、待機、失敗の姿勢を描いた。
- [ ] 小画面、白黒、立体での成立を確認した。
- [ ] トレンドを模倣せず、必要な要素だけ選んだ。
- [ ] 説明文なしで第三者に印象を確認した。
