# 成人マスコットの年齢表現と識別方針

作成日: 2026-08-09  
状態: **推奨方針。メイン3人の比較試作と第三者確認を経て正式固定する**  
対象: HugMap Storiesの動物の先生たち

## 1. この方針の目的

動物の先生たちを、子どもに親しまれる小さなマスコットとして保ちながら、子ども本人ではなく、経験と責任を持つ大人の先生として表現する。

現在のメイン3人は、頭部の形によって識別しやすくしている。

- ことり先生: 楕円を基礎にした頭。
- うさぎ先生: 正方形を基礎にした頭。
- りす先生: やや長方形を基礎にした頭。

この識別力は、小さなマスコット、アイコン、スタンプ、ぬいぐるみで有効である。一方、頭部へ人間的な成人体型をそのまま組み合わせると、頭と身体が別の画風に見え、かわいさを失う可能性がある。

この問題は、特徴的な頭部を捨てるのではなく、**識別と成人性を別の要素へ分担する**ことで解決する。

## 2. 基本方針

```text
識別
＝頭の形

かわいさ
＝頭身、丸み、目鼻の配置

大人らしさ
＝姿勢、間、行動、関係性

専門性
＝観察方法、判断の順序、道具の扱い方

個性
＝反復する動作＋一つの固定記号
```

頭の形へ、識別、性格、年齢、職業のすべてを背負わせない。

## 3. 公開年齢と内部設定を分ける

動物の先生は、公開上は**年齢不詳の成人マスコット**として扱うことを第一候補とする。

- 子どものキャラクターとしては描かない。
- 人間の成人に近い頭身へ伸ばさない。
- しわ、白髪、ひげ、老眼鏡などを、成人性の必須記号にしない。
- 具体的な年齢は、物語上必要な場合を除き前面に出さない。
- 制作内部では、経験、テンポ、判断、弱点を揃えるために年齢感を持つ。

| 先生 | 公開上の扱い | 内部で持つ年齢感・経験 |
|---|---|---|
| ことり先生 | 年齢不詳の成人マスコット | 若々しく柔らかな聞き手。急いで答えず、ときどき待ちすぎる |
| りす先生 | 年齢不詳の成人マスコット | 経験を積んだ探偵兼発明家。観察して選び、ひらめくと試しすぎる |
| うさぎ先生 | 年齢不詳の成人マスコット | 若々しく活動的な伴走者。先へ出るが、相手に気づいて速度を合わせる |

性別は、役割や物語上必要な場合を除き、造形上のかわいさや成人性を説明する記号として使わない。

## 4. 頭部は「固定図形」ではなく「形の家族」とする

楕円、正方形、長方形を完全な幾何学図形として固定しない。角度、姿勢、表情に対応できる範囲を持たせながら、黒いシルエットで識別できる核を維持する。

### ことり先生

- 楕円を基本にする。
- 真円にはしない。
- 聞く方向へ傾いたときも、楕円の流れが残る。
- 顎を尖らせず、下部だけをわずかに細くできる。
- 頭頂の羽と頭の傾きで、楕円の方向を強調する。

### うさぎ先生

- 正方形を基本にする。
- 完全な直線や鋭い角ではなく、大きな丸角を持つ四角形とする。
- 正面では四角い印象を保ち、横顔では自然な前後差を許容する。
- 頬を人間の大人の顎のように角張らせない。
- 長い耳を含めた全身シルエットで、縦方向の動きも作る。

### りす先生

- やや長方形の頭を基本にする。
- 完全な箱形にはせず、頬から顎へわずかに細くする。
- ことり先生より底面を安定させる。
- 頭部の縦方向と、尻尾やポケットの渦形を対比させる。
- 現行の造形固定ガイドと矛盾しない範囲で調整する。

## 5. 成人性を表す優先順位

成人性は、次の順番で表す。

### 5.1 行動の順序

最優先とする。単独の大人記号より、相手の反応を受けて行動を変えられることを大人らしさとして描く。

| 先生 | 成人性が見える行動の順序 |
|---|---|
| ことり先生 | 気づく → まねる → 急がず待つ |
| りす先生 | 観察する → 試す → 選び直して戻す |
| うさぎ先生 | 一歩前へ出る → 相手に気づく → 隣へ戻って合わせる |

### 5.2 身体の重心と間

- 頼もしさを身体の大きさだけで表さない。
- 経験は、足元の安定、動く前の観察、動作の選択として表す。
- 若々しさは、前傾、軽い足取り、反応の速さとして表せる。
- 落ち着きは、動きを減らすだけでなく、必要なときに待てることとして表す。

### 5.3 子どもとの距離

- 子どもの正面を塞がない。
- 斜め横、同じ高さ、または少し後ろへ位置する。
- 必要に応じてしゃがみ、身体を小さくする。
- 道具を一方的に手渡さず、選べる位置へ置く。
- 役割を終えたら一歩下がる。

単独立ち絵より、子どもや保護者と一緒にいる場面で成人性と専門性を伝える。

### 5.4 固定された身体記号

動作が使えないアイコン、顔表示、ぬいぐるみのため、一人につき一つの弱い固定記号を検証する。

| 先生 | 第一候補 |
|---|---|
| Mimo（ことり先生） | 頭頂の一枚羽と、聴く方向へ傾く縦長の卵形頭部 |
| Luke（りす先生） | 小さな三本の額毛と、片側へ大きく張り出す渦巻き尻尾 |
| Gen（うさぎ先生） | 左右非対称の耳と、目より下で最も広くなる低い頬 |

固定記号は、年齢、性別、障害、能力不足を示すものにしない。

### 5.5 付け物

眼鏡、帽子、白衣、ひげ、専門道具などは最後の補助とする。

- 付け物だけで成人性や専門職を説明しない。
- 外したときも同じキャラクターに見えるようにする。
- 職業のステレオタイプを優先しない。
- 付け物より先に、身体、距離、行動を設計する。

## 6. 避ける設計

- 特徴的な頭へ、人間に近い長い成人体型をそのまま接続する。
- 大人らしさを、しわ、白髪、ひげ、眼鏡だけで表す。
- 頼もしさを、大きな身体、中央配置、腕組みだけで表す。
- 専門性を、白衣や道具だけで表す。
- かわいさを守るため、全員を同年代の子どもの友達に見せる。
- 画風だけに個体識別を任せる。
- 色だけで三人を区別する。
- 頭の形を優先しすぎて、横顔、感情、動作が成立しなくなる。

## 7. 頭部の識別設計を捨てる条件

頭部の形は、次の問題が比較試作と第三者確認で再現された場合にだけ再設計する。

- 子どもが四角形や長方形の頭を怖い、硬いと感じる。
- 表情や視線が読み取りにくい。
- 横顔、後ろ姿、動いている場面が成立しない。
- メイン3人が同じ世界の住人に見えない。
- 身体を動かすと、頭だけ別部品のように浮く。
- 絵本の繊細な感情場面で幾何学性が妨げになる。
- ぬいぐるみで抱きやすさや触りやすさを損なう。

単に「大人に見えない」ことは、頭の形を捨てる理由にしない。成人性は、頭部以外の要素で表す。

## 8. 比較試作

各先生について、次の3案を同じ条件で比較する。

| 案 | 頭 | 身体 | 成人性の表現 |
|---|---|---|---|
| A | 現在の幾何学形 | 小型マスコット | 成人記号なし |
| **B** | **現在の形を少し柔らかくする** | **小型成人マスコット** | **重心、行動、間、距離** |
| C | 現在の形を維持 | 人間に近い成人体型 | 衣服、付け物 |

第一候補はBとする。

### 同じ条件で作る5点

1. 単独の通常姿勢。
2. 子どもへ近づく姿勢。
3. 子どもの反応を受けて止まる、選び直す姿勢。
4. 子どもと保護者の横に並ぶ場面。
5. 32px相当のアイコン。

### 確認項目

- [ ] 名前と色がなくても三人を識別できる。
- [ ] 子ども本人ではなく、年齢不詳の成人マスコットに見える。
- [ ] 子どもが近づきたいかわいさがある。
- [ ] 保護者が相談できそうな落ち着きがある。
- [ ] セラピストが見ても、専門職を幼稚化していない。
- [ ] 道具を外しても、役割と性格の違いが残る。
- [ ] 横顔と後ろ姿でも、頭部の形の家族が維持される。
- [ ] 小さな表示でも、固定記号が潰れない。
- [ ] 先生が子どもより大きく、中央に居続けていない。
- [ ] 作者が別の物語でも描き続けたいと思える。

## 9. プロンプトへ入れる固定ブロック

キャラクター画像を生成・編集するときは、必要に応じて次をプロンプトへ入れる。

```text
The character is an ageless adult animal mascot, not a child character and not a realistically proportioned adult human.
Keep the established head-shape family as the primary recognition anchor.
Preserve a compact mascot body, rounded forms, short limbs, and child-friendly visual softness.
Show adulthood through posture, timing, behavioral sequence, professional judgment, and respectful distance from the child—not through wrinkles, gray hair, facial hair, mature anatomy, or occupational stereotypes.
The character notices the child's response and changes their own action accordingly.
Accessories are secondary; the character must remain recognizable and adult-coded without tools.
```

キャラクター別に、頭部の形、代表動作、固定記号、変更禁止項目を追加する。

## 10. 正式固定の条件

次の確認が終わるまでは、年齢表現と成人マスコット比率を正式固定しない。

1. メイン3人のA・B・C比較を作る。
2. B案で子どもとの関係場面を作る。
3. 子ども、保護者、セラピストへ印象確認を行う。
4. 32px、白黒、横顔、後ろ姿を確認する。
5. 結果を、メイン3人のモデルロックと正本へ反映する。

### 現在の残作業

1. Mimo、Luke、Genの相談アイコンを同じフラット塗り、影量、外周線、表示占有率へ統一する。
2. 64px／48px、白・淡色・濃色背景、白黒、道具なしで識別性を確認する。
3. 横顔と後ろ姿で頭部記号が維持されるか確認する。
4. 子ども、保護者、セラピストへ、かわいさ、相談しやすさ、成人性、名前の想起を確認する。
5. 結果をモデルロックとアプリ用書き出し仕様へ反映する。
