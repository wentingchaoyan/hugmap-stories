# HugMap Stories シリーズ予告・5案比較

作成日: 2026-08-13

位置づけ: 8/12 feedback の白黒 SMALL MASCOT を参照した比較用ネーム。正式なキャラクター素材ではない。

共通条件:

- 子ども・保護者の姿を直接描かない
- 白黒漫画、6コマ
- 3人の違いを行動で見せる
- Mimo＝聴く、Luke＝探す、Gen＝合わせる
- 5つの信条は説明せず、行動の背景へ置く
- STEP 4までの頭身・衣装・Uマーク・丸い手を形状基準とする

## 01 保護者の悩みから始まる

中心感情: 共感 → 好奇心 → 安心

1. 「どうしてだろう」を表す、絡まった線と未完成の道
2. 一見同じに見える反復の中に、小さな違いが現れる
3. Mimoが小さなサインを聴く
4. Lukeが反復と条件を調べる
5. Genが歩幅と進み方を合わせる
6. 3人が困惑を一つの道へ変える

締めコピー案: **困りごとの向こうにある、小さなサインを見つけにいこう。**

## 02 映画のキャラクター登場編

中心感情: 期待 → 親しみ → 記憶

1. 3つのスポットライト
2. Mimo――小さな音を追い、立ち止まって聴く
3. Luke――道具を出しすぎ、必要なものを選び直す
4. Gen――勢いよく進みすぎ、戻って速度を合わせる
5. 3人の異なるシルエット
6. 3人が読者を世界へ招く

締めコピー案: **聴く。探す。合わせる。見つけ方の違う、3人の先生。**

## 03 HugMapの家の朝

中心感情: 親しみ → 笑い → 一緒に進む安心

1. 3人が出発の準備をする
2. Mimoが小さな音に気づき、支度の手を止める
3. Lukeの鞄は道具でいっぱいになり、閉まらない
4. Genが一人で先に飛び出す
5. Genが戻り、Lukeが道具を減らし、Mimoが聴き終える
6. 3人が同じ速さで出発する

締めコピー案: **見つけ方も、歩く速さも違う3人が、今日も一緒に向かいます。**

## 04 一通の手紙

中心感情: 共感 → 好奇心 → 信頼

1. 差出人を描かない、文字のない封筒
2. 3人が近づきすぎず、一緒に見る
3. Mimoが、まだ言葉になっていない気配を聴く
4. Lukeが、複数の可能性を比べる
5. Genが、近づく・離れる・休む・少し進む道を並べる
6. 一つの答えに閉じず、3人の手がかりを持ち寄る

締めコピー案: **一つの悩みに、一つだけの答えを置かない先生たち。**

## 05 白いページから地図が生まれる

中心感情: 不思議 → 発見 → 静かな希望

1. 白いページに一つの点
2. Mimoが、点と点の間を聴く
3. Lukeが、似た線の小さな違いを比べる
4. Genが、足跡に自分の歩幅を合わせる
5. 点・線・足跡が一枚の地図になる
6. 3人は地図の中心ではなく入口に立つ

締めコピー案: **小さなサインをつないで、その人の世界へ近づいていく。**

## 比較時の質問

1. 続きを見たいと思うか。
2. Mimo・Luke・Genの違いを一言で説明できるか。
3. 評価される感じより、一緒に見つける感じがあるか。
4. 子どもや保護者を描かなくても、自分との関係を想像できるか。
5. HugMapらしいと思うのはどれか。
