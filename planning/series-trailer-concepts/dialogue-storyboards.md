# HugMap Stories シリーズ予告・文字ネーム5案

作成日: 2026-08-13

## 共通ルール

- 全6コマ
- 主役はMimo・Luke・Genの3人
- 子ども、保護者、人間は直接描かない
- 読者へ説明しすぎず、3人の動詞を覚えてもらう
- Mimo＝聴く、Luke＝探す、Gen＝合わせる
- 1吹き出しは原則20文字前後
- 信条は番号や標語として説明せず、行動に埋め込む
- 最終コマにだけシリーズ名を置く

---

## 案1｜保護者の悩みから始まる

中心感情: 共感 → 好奇心 → 安心

### 1コマ目｜迷い

- **絵:** 絡まった線、疑問符、途中で途切れた道。人物は描かない。
- **声・モノローグ:** 「どうして、何度も同じことをするんだろう。」
- **ナレーション:** なし
- **感情:** 自分にも覚えがあるという共感
- **次への引き:** 答えではなく、もう一つの問いが現れる

### 2コマ目｜見方が変わる問い

- **絵:** 一見同じ円が並ぶが、間隔や大きさが少しずつ違う。
- **声・モノローグ:** 「同じに見えて、少しずつ違う？」
- **ナレーション:** なし
- **感情:** 困惑から好奇心へ
- **次への引き:** 小さな違いにMimoが気づく

### 3コマ目｜Mimo

- **絵:** Mimoが音の波や小さな点から少し離れ、羽を閉じて聴く。
- **Mimo:** 「……いま、なにか届いた？」
- **肩書き:** `MIMO／ミモ　小さなサインを聴く`
- **感情:** 静かな集中
- **次への引き:** Lukeが痕跡を追う

### 4コマ目｜Luke

- **絵:** Lukeが反復する跡を比べる。道具を一度出しすぎ、二つだけ残す。
- **Luke:** 「決める前に、比べてみよう。」
- **小声:** 「これは多すぎたね。」
- **肩書き:** `LUKE／ルーク　手がかりを探す`
- **感情:** 発見の楽しさと愛嬌
- **次への引き:** 道が複数に分かれる

### 5コマ目｜Gen

- **絵:** Genが大股で進みかけ、短い足跡に気づいて歩幅を小さくする。
- **Gen:** 「この速さなら、どうかな？」
- **肩書き:** `GEN／ゲン　合う進み方へ合わせる`
- **感情:** 安心と選択可能性
- **次への引き:** 3人の発見がつながる

### 6コマ目｜結び

- **絵:** 絡まった線、比較した跡、足跡が一つの開いた道になる。3人は道の入口に立つ。
- **ナレーション:** 「困りごとの向こうにある、小さなサインを見つけにいこう。」
- **タイトル:** `HugMap Stories`
- **感情:** 小さな希望

## 案2｜映画のキャラクター登場編

中心感情: 期待 → 親しみ → 記憶

### 1コマ目｜開幕

- **絵:** 白い舞台に3本のスポットライト。まだ誰もいない。
- **ナレーション:** 「小さなサインに出会ったとき——」
- **感情:** 期待
- **次への引き:** 一つ目の光に小さな点が入る

### 2コマ目｜Mimo登場

- **絵:** 音の点を追ってMimoが現れ、途中で立ち止まって聴く。
- **Mimo:** 「……返事を、待っているの。」
- **肩書き:** `MIMO／ミモ　聴く`
- **小さな補足:** 「ときどき、待ちすぎる。」
- **感情:** 静かな親しみ
- **次への引き:** 道具の落ちる小さな音

### 3コマ目｜Luke登場

- **絵:** Lukeが道具箱と登場。一つ落とし、考えて二つだけ選ぶ。
- **Luke:** 「答えより先に、試してみよう。」
- **肩書き:** `LUKE／ルーク　探す`
- **小さな補足:** 「ときどき、試しすぎる。」
- **感情:** 好奇心と愛嬌
- **次への引き:** ボールが画面を横切る

### 4コマ目｜Gen登場

- **絵:** Genがボールを追って勢いよく登場。通り過ぎ、少し戻る。
- **Gen:** 「あっ。ちょっと速かった？」
- **肩書き:** `GEN／ゲン　合わせる`
- **小さな補足:** 「ときどき、張り切りすぎる。」
- **感情:** 笑いと好感
- **次への引き:** 3人の視線が同じ方向へ

### 5コマ目｜チーム

- **絵:** Mimoは耳を澄まし、Lukeは二つを比較し、Genは低くしゃがむ。
- **Mimo:** 「まず、聴く。」
- **Luke:** 「それから、探す。」
- **Gen:** 「いっしょに、合わせる！」
- **感情:** 役割の理解
- **次への引き:** 3人が読者側へ振り向く

### 6コマ目｜タイトル

- **絵:** 3人が並び、白い余白の先を示す。
- **ナレーション:** 「見つけ方の違う、3人の先生。」
- **タイトル:** `HugMap Stories`
- **サブコピー:** 「小さなサインから、世界をひらく。」
- **感情:** 覚えやすさと期待

## 案3｜HugMapの家の朝

中心感情: 親しみ → 笑い → 一緒に進む安心

### 1コマ目｜出発準備

- **絵:** 3人が鞄を準備している。
- **Gen:** 「みんな、準備できた？」
- **Mimo:** 「もう少しだけ。」
- **Luke:** 「ほとんどね。」
- **感情:** 日常への親しみ
- **次への引き:** Mimoの耳元に小さな音

### 2コマ目｜Mimoらしさ

- **絵:** Mimoが鞄を持ったまま動きを止め、遠くの小さな音を聴く。
- **Mimo:** 「しーっ。いま、なにか聞こえた？」
- **小さな補足:** `Mimoは、小さなサインを聴く。`
- **感情:** 静かな好奇心
- **次への引き:** Lukeの鞄から道具がはみ出す

### 3コマ目｜Lukeらしさ

- **絵:** Lukeが膨らんだ鞄を閉じようとしている。
- **Luke:** 「念のため、これも……」
- **効果音:** 「むぎゅ」
- **小さな補足:** `Lukeは、いくつも試して探す。`
- **感情:** 笑い
- **次への引き:** 玄関が開く

### 4コマ目｜Genらしさ

- **絵:** Genが元気よく一人で外へ飛び出す。
- **Gen:** 「じゃあ、しゅっぱーつ！」
- **感情:** 勢いと楽しさ
- **次への引き:** 後ろに誰もいない

### 5コマ目｜気づいて変わる

- **絵:** Genが戻って歩幅を小さくする。Lukeは道具を減らす。Mimoは聴き終えて顔を上げる。
- **Gen:** 「……一緒に行ける速さにしよう。」
- **Luke:** 「持つのは、これだけ。」
- **Mimo:** 「うん。届いたよ。」
- **感情:** 安心と関係性
- **次への引き:** 3人が横に並ぶ

### 6コマ目｜出発

- **絵:** 3人が同じ速さで歩き出す。
- **ナレーション:** 「見つけ方も、歩く速さも違う3人が、今日も一緒に向かいます。」
- **タイトル:** `HugMap Stories`
- **感情:** 仲間になりたい気持ち

## 案4｜一通の手紙

中心感情: 共感 → 好奇心 → 信頼

### 1コマ目｜届く

- **絵:** 文字のない封筒が机に置かれる。送り主は描かない。
- **手紙の声:** 「どうしたらいいのか、わからなくなる日があります。」
- **感情:** 静かな共感
- **次への引き:** 3人が封筒に気づく

### 2コマ目｜一緒に見る

- **絵:** 3人が封筒を囲まず、同じ側から見る。
- **Gen:** 「すぐ、助けに行こう！」
- **Luke:** 「その前に、もう少し知りたいな。」
- **Mimo:** 「まだ、続きがあるかも。」
- **感情:** 3人への関心
- **次への引き:** 封筒から小さな点線

### 3コマ目｜Mimoの問い

- **絵:** Mimoが点線の間に耳を澄ます。
- **Mimo:** 「どんなふうに、伝えようとしていたのかな。」
- **肩書き:** `MIMO／ミモ　聴く`
- **感情:** 相手を決めつけない安心
- **次への引き:** Lukeが二枚の可能性を並べる

### 4コマ目｜Lukeの問い

- **絵:** Lukeが二つの絵札や痕跡を比較する。
- **Luke:** 「その前と後に、なにがあったんだろう。」
- **肩書き:** `LUKE／ルーク　探す`
- **感情:** 観察したくなる好奇心
- **次への引き:** Genが複数の道を作る

### 5コマ目｜Genの問い

- **絵:** Genが、近い道、遠い道、休む場所、小さな一歩を並べる。
- **Gen:** 「どの参加なら、いま合いそう？」
- **肩書き:** `GEN／ゲン　合わせる`
- **感情:** 選べる安心
- **次への引き:** 3つの手がかりが机にそろう

### 6コマ目｜答えを閉じない

- **絵:** 封筒は開いたまま。3人が見つけた点、比較、道を横に並べる。
- **ナレーション:** 「一つの悩みに、一つだけの答えを置かない先生たち。」
- **タイトル:** `HugMap Stories`
- **感情:** 信頼と次を話したくなる気持ち

## 案5｜白いページから地図が生まれる

中心感情: 不思議 → 発見 → 静かな希望

### 1コマ目｜一つの点

- **絵:** 大きな白い余白に、小さな点が一つ。
- **ナレーション:** 「まだ、なにもない？」
- **感情:** 不思議
- **次への引き:** もう一つの点が現れる

### 2コマ目｜Mimoが間を聴く

- **絵:** Mimoが二つの点の間に立ち、静かに待つ。
- **Mimo:** 「この間にも、なにかあるかも。」
- **肩書き:** `MIMO／ミモ　聴く`
- **感情:** 静かな発見
- **次への引き:** 点から複数の線が伸びる

### 3コマ目｜Lukeが違いを探す

- **絵:** Lukeが似ている曲線を並べて比較する。
- **Luke:** 「同じようで、ここが違うね。」
- **肩書き:** `LUKE／ルーク　探す`
- **感情:** 好奇心
- **次への引き:** 線の先に足跡が現れる

### 4コマ目｜Genが歩幅を合わせる

- **絵:** Genが大きな一歩を止め、小さな足跡へ歩幅を合わせる。
- **Gen:** 「この歩幅で、行ってみよう。」
- **肩書き:** `GEN／ゲン　合わせる`
- **感情:** 安心
- **次への引き:** 点、線、足跡が一つにつながる

### 5コマ目｜地図になる

- **絵:** 点、曲線、足跡が抽象的な地図になる。3人はまだ描かない。
- **ナレーション:** 「小さなサインをつなぐと、見えてくる世界がある。」
- **感情:** 発見と希望
- **次への引き:** 地図の先が白い余白へ続く

### 6コマ目｜入口に立つ3人

- **絵:** 3人が地図の中心ではなく入口に立ち、続きを指す。
- **ナレーション:** 「その人の世界へ、少しずつ近づいていく。」
- **タイトル:** `HugMap Stories`
- **サブコピー:** 「小さなサインから、世界をひらく。」
- **感情:** 静かな期待

## 初回比較で見ること

5案を保護者へ見せる際は、内容を説明する前に次を尋ねる。

1. 最初にどんな気持ちになったか。
2. 続きを読みたいと思ったか。
3. 3人の違いをどのように受け取ったか。
4. 責められている、評価されている感じがなかったか。
5. 一番HugMapらしいと思った案はどれか。

キャラクター名の記憶だけを比べる場合は案2、シリーズへの信頼まで比べる場合は案4、世界観の独自性を比べる場合は案5を基準候補とする。
