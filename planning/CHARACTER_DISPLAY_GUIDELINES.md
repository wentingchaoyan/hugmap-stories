# HugMap キャラクター表示ガイドライン

最終更新: 2026-09-07

## 1. 目的

本書は、HugMapのキャラクターをアプリ、公開FAQ、Webサイト、SNSなどへ表示するときの共通ルールを定める。

キャラクターの役割・登場可否は、アプリ側の
[`withu/docs/characters.md`](../../withu/docs/characters.md) を正とし、本書では次を扱う。

- 表示サイズとアセットの使い分け
- クロップ、余白、見かけ上の大きさ
- 配色と背景の組み合わせ
- 同一画面での登場回数
- 画面別の推奨表現
- 制作・実装時の確認方法

目標は、どの画面でも同じキャラクターとして認識でき、情報を邪魔せず、28pxから大型イラストまで一貫して機能することである。

## 2. 基本原則

1. **1枚の全身画像をすべてのサイズへ縮小しない。** Face、Avatar、Full、Sceneを用途別に用意する。
2. **小さいほど造形を単純にする。** 細部を残すために線を細くするのではなく、細部そのものを省略する。
3. **全高ではなく、頭部の見かけサイズを揃える。** 耳、冠羽、尻尾などの突出部は光学サイズの基準にしない。
4. **色は識別に使い、装飾として増やさない。** 1キャラクターにつき体色1色、ニュートラル色、アクセント1色を基本とする。
5. **キャラクターは案内・共感・応援を担う。** 判定、診断、評価の正誤を表す用途には使わない。
6. **同一画面で反復させすぎない。** 常設ナビゲーションを除き、同じキャラクターの主要表示は原則2か所以内とする。
7. **大型イラストの画風が変わっても、固定造形は変えない。** 頭部形状、顔パーツ、固有記号、頭身、服の基本形を維持する。

## 3. レスポンシブ・キャラクター規格

### 3.1 アセットの4段階

| 規格 | 推奨表示サイズ | 表現 | 主な用途 |
|---|---:|---|---|
| Face | 24–32px | 頭部のみ | Chat回答者、FAQ回答者、カード内の担当表示 |
| Avatar | 40–64px | 頭＋上半身 | 先生タブ、先生選択、プロフィール導線 |
| Full | 72–128px | コンパクトな全身 | 先生カード、空状態、CTA |
| Scene | 160px以上 | 全身＋相手・背景・動作 | Discover本文、プロフィールヒーロー、記事、SNS |

Face、Avatar、Fullは単なるリサイズではなく、同じ固定造形から作る個別アセットとする。

### 3.2 実装トークン

新規実装では、原則として次のサイズへ寄せる。

```ts
export const personaSizes = {
  xs: 28,  // Face
  sm: 40,  // Face / Avatar
  md: 56,  // Avatar
  lg: 80,  // Full
  xl: 128, // Full / Scene preview
} as const;
```

既存の26、30、34、48、58、72pxは直ちにすべて変更する必要はない。ただし、同じ役割の表示へ新しいサイズを追加せず、最も近いトークンへ段階的に統合する。

キャラクター画像が小さくても、操作可能な領域は44×44px以上を確保する。画像サイズとタップ領域は分離して考える。

## 4. サイズ別の造形ルール

### 4.1 Face — 24–32px

- 頭部がアセット領域の78–84%を占める。
- 外周余白は上下左右8–10%を基準とする。
- 服、足、尻尾、手持ち小物は表示しない。
- 耳、冠羽、くちばし、マズル、眼鏡など、頭部の固有記号を優先する。
- 実表示で1px未満になる内部線は使用しない。
- 目、口、くちばしを背景色に近づけない。
- 基本表情は通常、聞く、喜ぶの最大3種を目安とする。
- 円形クロップと角丸正方形クロップの両方で欠けないことを確認する。

### 4.2 Avatar — 40–64px

- 頭部60–68%、上半身32–40%を目安とする。
- 胸元より下を原則として表示しない。
- 片腕・片翼による単純な関わりのジェスチャーを1つまで使える。
- 小物は原則なし。役割を示すため不可欠な場合のみ1種類とする。
- 外周線は実表示で1.5–2px相当を目安とする。
- 全キャラクターの頭部面積を光学的に揃える。

### 4.3 Full — 72–128px

- 全身が領域高の82–88%を占める。
- 耳、冠羽、尻尾を含む外周余白を8%以上確保する。
- 1ポーズ1動詞とし、複数の感情や動作を同時に説明しない。
- 小物は1系統までとし、顔より強く見せない。
- 接地線と見かけ上の頭部サイズをキャラクター間で揃える。
- 高さだけを揃えて、幅広いキャラクターを過度に小さくしない。

### 4.4 Scene — 160px以上

- キャラクター単体ではなく、相手、視線、距離、環境によって関係を描ける。
- 水彩、線画、紙の質感など、コンテンツに合った表現を選べる。
- UI用正本の頭部形状、顔パーツ、固有記号、服の基本形は変更しない。
- キャラクターが主役でない場面では、画面高の25–45%程度を目安とする。
- 背景の情報量が顔の可読性を上回らないようにする。

## 5. 固定造形と変更可能な表現

### 固定するもの

- 頭部の縦横比
- 目の位置、大きさ、間隔
- くちばし、鼻、マズル、顔盤
- 冠羽、耳、額毛、眼鏡、尻尾
- 基本頭身と胴体比率
- 服の基本形
- キャラクター固有色
- 輪郭色

### 用途に応じて変更できるもの

- ポーズと視線
- 背景と小物
- 塗りの密度
- 陰影の量
- 紙、水彩、鉛筆などの質感
- 線の揺れ。ただしFaceでは省略する

## 6. 配色

### 6.1 ブランド色とキャラクター色の関係

ブランドの基準色は維持する。

```text
Orange     #FF511B
Yellow     #D7C862
Light Grey #DCD5D2
Purple     #7D2741
Off White  #F4F1F0
Dark Brown #291712
```

UIでは基準色を使用し、キャラクターの大面積には彩度を抑えた派生色を使用する。基準色は小物、くちばし、胸元などの小面積アクセントへ残す。

```text
Character Orange #E96A42
Character Yellow #D5C675
Character Purple #88475A
Warm White       #F8F5F3
Soft Purple Grey #D8D2D3
Outline          #291712
```

### 6.2 面積ルール

- 体色：1色
- 服：Warm White、Light Grey、グレージュを中心にする
- ブランド原色：キャラクター面積の10–20%以内を目安とする
- 輪郭・目：Dark Brown。純黒は使用しない
- 強いグラデーション、光沢、複雑な影は使用しない
- 80px未満では紙の質感を識別情報として扱わない

### 6.3 キャラクター別

| キャラクター | 基本体色 | アクセント | 注意点 |
|---|---|---|---|
| ミモ | Character Yellow | Orangeのくちばし | 黄色背景へ直接置かない |
| ゲン | Warm White | Purpleの衣装要素 | 白背景では輪郭または淡い背景面を必須とする |
| ルク | Character Orange | 原色Orangeは小面積 | CTAと同じOrangeを体全体へ使わない |
| ルミ | Soft Purple Grey | Purpleのくちばし・足・胸元 | 体全体を濃いPurpleにしない |

ほかの先生にも、同じ「体色＋ニュートラル＋小面積アクセント」の構成を適用する。

## 7. 背景との組み合わせ

| キャラクター色 | 推奨背景 | 避ける組み合わせ |
|---|---|---|
| Yellow | White、Off White、淡いPurple | 同程度のYellow背景 |
| Orange | White、Off White、Light Grey | OrangeのCTA・カード背景 |
| Warm White | Light Grey、淡いYellow | 境界処理のないWhite背景 |
| Purple Grey | White、Off White、淡いYellow | 同明度のGrey背景 |

白・淡色キャラクターには、次のいずれかを必ず使用する。

- Dark Brownの外周線
- 淡い背景ディスク
- 控えめなキーライン

輪郭線なし版は大型のWeb・SNSイラスト専用とし、64px以下のUIには使用しない。

## 8. 画面別ルール

### 8.0 選択肢・トピックタグ

- 未選択のトピックタグはニュートラル色を使用する。
- 推奨背景はアプリテーマの`componentDisableBackground`、文字は
  `componentInactiveTintColor`または`mainTextColor`とする。画面側へHEX値を直書きしない。
- Orangeは選択中、押下フィードバック、主要CTA、質問種別を示す小さな記号へ限定する。
- 同じ画面にタグが4つ以上並ぶ場合、全タグへOrange文字とOrange背景を同時に使用しない。
- 質問候補とトピックタグを区別する。質問候補はWhite＋小さなOrangeのQ、トピックはGrey＋ニュートラル文字を基本とする。
- 色だけで選択状態を伝えず、背景、境界線、チェック、文字ウェイトのいずれかを併用する。

### 8.1 Chat・FAQ回答カード

- Faceを使用する。
- 推奨画像サイズは28–32px、コンテナは36–40px。
- 全身画像を円形コンテナへ縮小して入れない。
- 名前と専門領域が隣接する場合、小物を追加しない。
- 回答本文よりキャラクターが強く見えないようにする。

### 8.2 先生選択・Discover上部タブ

- Avatarを使用する。
- 推奨サイズは56px。円または角丸コンテナ内の85–90%を使用する。
- 全キャラクターの頭部面積を揃える。
- 選択状態はリング、背景、文字色のうち最大2つで示す。
- OrangeのリングとOrange文字を重ねる場合、キャラクター周辺のほかのOrangeを減らす。

### 8.3 先生カード一覧

- Fullを80–96pxで使用する。
- カード内の全高ではなく、頭部の見かけサイズを揃える。
- キャラクター、名前、専門領域、紹介文の順序を維持する。
- キャラクターがカード上部で小さく浮かないようにする。
- 小物は原則として表示しない。

### 8.4 キャラクター情報画面

- Sceneを使用できる。
- 水彩・絵本調の背景表現を使用してよい。
- UI正本の固定造形を維持する。
- キャラクターの足元や突出部へ3–5%以上の余白を確保する。
- テキストを重ねる場合は、背景コントラストまたはオーバーレイを確認する。

### 8.5 Discover本文

- Sceneまたは大型線画を使用する。
- 顔より、視線、姿勢、相手との距離で動作を説明する。
- タブ、カード、本文に同じキャラクターを3回以上反復させない。
- タブにAvatar、本文にSceneがある場合、中間カードの小型キャラクターは省略できる。
- 評価や正誤を示す位置へキャラクターを置かない。

## 9. 同一画面での登場密度

同じキャラクターを複数箇所へ置く場合、それぞれに異なる機能が必要である。

許容例：

- タブ：現在の担当を示す
- 本文イラスト：場面の関係を説明する

避ける例：

- タブ、カード見出し、本文、CTAへ同じ全身画像を反復する
- 同じポーズをサイズだけ変えて複数表示する
- 情報のない装飾として常設表示する

原則として、常設ナビゲーションを除く主要表示は同一画面で2か所以内とする。

## 10. アセット仕様

### 10.1 マスター

- 透過PNGまたは編集可能な正本から生成する
- 正方形マスターは2048×2048px以上を推奨する
- RGB／sRGBで管理する
- 背景はアセットへ焼き込まず、UIコンテナ側で管理する
- 外周の透明余白をキャラクター間で統一する

### 10.2 命名

```text
persona_{id}_face_{expression}.png
persona_{id}_avatar_{gesture}.png
persona_{id}_full_{pose}.png
persona_{id}_scene_{scene-name}.png
```

例：

```text
persona_mimo_face_neutral.png
persona_mimo_avatar_listening.png
persona_mimo_full_listening.png
persona_mimo_scene_joint-attention.png
```

サイズをファイル名の主分類にしない。表示密度ごとの書き出しが必要な場合は、プラットフォーム標準の`@2x`、`@3x`を使用する。

## 11. 実寸QA

キャラクター正本を承認する前に、必ず次の実表示サイズで確認する。

```text
28px / 40px / 56px / 80px / 128px
```

### 合格条件

#### 28px

- 名前なしでも動物種またはキャラクターを判別できる
- 目、くちばし、鼻、眼鏡が潰れない
- 背景へ溶けない

#### 40px

- 主要キャラクターを相互に取り違えない
- 通常と傾聴など、基本表情の差が読める

#### 56px

- 表情と単純なジェスチャーが読める
- キャラクター間の見かけサイズが揃っている

#### 80px

- 代表ポーズの動詞が顔を隠しても推測できる
- 服と小物が顔を邪魔しない

#### 128px

- 手描き線や素材感が魅力として機能する
- 細部が別の画風に見えない

### 確認背景

- White
- Off White `#F4F1F0`
- ブランドPurple
- ブランドYellow
- 写真
- 円形クロップ
- 角丸正方形クロップ

## 13. 現行画面の移行優先順位

1. Chatの小型全身アバターをFaceへ変更する
2. Discover上部タブをAvatarへ変更する
3. 先生選択カードのFullを80–96pxへ拡大する
4. すべての先生カードで頭部の光学サイズを揃える
5. ルミをPurple主体からPurple Grey主体へ変更する
6. Discover内で同じ先生が3回以上登場する構成を整理する
7. 大型水彩版の固定造形をUI正本へ合わせる
