# HugMap Stories 感情・価値観・物語言語ガイド

作成日: 2026-08-03  
対象: 障害、発達、子育てを扱うHugMap Storiesの物語・アプリ・キャラクター表現  
役割: **難しい感情を消さず、希望や発見と共存させるための補助資料**

世界観とシリーズの約束は [`world-and-character-guide.md`](world-and-character-guide.md)、物語構造は [`story-narrative-guide.md`](story-narrative-guide.md)、キャラクターの具体的な行動と言葉は [`character-expression-guide.md`](character-expression-guide.md) を参照する。

## 1. 基本姿勢

HugMap Storiesでは、ポジティブとネガティブを単純な対立として扱わない。

難しい感情を前向きな言葉で消すのではなく、どちらも親子の生活に存在してよいものとして描く。

```text
不安が希望に変わって消える
```

ではなく、次の共存を基本とする。

```text
不安はまだある。
でも、今日は一つ気づけた。
```

感情の変化は、次の順序で描く。

```text
感情が生まれる
↓
急いで消さずに受け止める
↓
小さく行動する、または今日は行動しない
↓
新しい感情が隣に生まれる
```

## 2. 中心となる英語表現の整理

### 2.1 価値観

| English | 日本語 | HugMapでの意味 |
|---|---|---|
| patience | 忍耐、待つこと | 答えや反応を急がず、本人の時間を尊重する |
| trust | 信頼 | 子どもの反応と、保護者が持つ専門性を信じる |
| respect | 尊重 | 本人の選択、拒否、距離、方法を尊重する |
| generosity | 寛容さ、惜しまず与えること | 正解を押しつけず、時間と選択肢を渡す |
| resilience | 回復する力、しなやかさ | 元に戻ることだけでなく、別の形を見つける |
| hope | 希望 | 難しさを否定せず、その隣に可能性を置く |

概念を表す場合、`patient`ではなく名詞の`patience`を用いる。

### 2.2 行動する力

| English | 日本語 | HugMapでの扱い |
|---|---|---|
| courage | 勇気 | 怖さがないことではなく、怖さと一緒に小さく動くこと |
| challenge | 挑戦 | 成功まで続けることではなく、見る・近づく・一部分だけ試すことも含む |
| courage to make mistakes and try | 間違えても試す勇気 | 失敗しても戻れる、別の方法を選べるという安心 |
| enjoy | 楽しむ | 学びや参加の入口になる遊び心 |
| celebrate | 祝う | 結果だけでなく、選択、拒否、試したこと、休んだことを周囲と受け取る |

### 2.3 今を受け取る姿勢

| 元の表現 | 推奨表現 | 理由 |
|---|---|---|
| at the moment | this moment / in this moment | 「今この瞬間」にある反応を見る |
| positive sign | small sign / already-there sign | 医療的な判定ではなく、すでに存在する小さなサインを表す |
| beyond expectations | a possibility unfolding / discovering their own way | 低い期待を超えたという含みを避け、その子の方法と可能性に焦点を当てる |
| heart bloom | a heart opening / the heart begins to bloom | 心がひらく、気づきやつながりが生まれる詩的な表現として使う |

`beyond expectations`を使う場合は、「障害のある子に期待していなかった」という含みが生じないか確認する。

### 3.3 自分で決める力

| English | 日本語 | 物語での表し方 |
|---|---|---|
| agency | 自分で選び、働きかける力 | やる、やらない、方法、相手、量を本人が選ぶ |
| choice | 選択 | 二つ程度の選択肢から本人が決める |
| autonomy | 自分らしく決めること | 全部を一人で行うことと同一視しない |
| dignity | 尊厳 | 本人の身体、意思、プライバシーを守る |
| self-trust | 自分を信じる | 自分の感覚や限界を受け取る |
| self-advocacy | 自分の希望や必要を伝える | 助け、拒否、休憩、配慮を求める |
| interdependence | 支え合いながら生きる | 道具や人の力を使うことも本人の力として描く |

HugMapでは「一人でできる」だけを成長としない。

- 自分で選ぶ。
- 助けを求める。
- 誰かと一緒に行う。
- 必要な支援や道具を使う。
- 今日はしないと決める。

これらも本人の力として扱う。

## 4. 入れるべき難しい感情

### 4.1 保護者が感じること

| English | 日本語 |
|---|---|
| uncertainty | 先が分からない不安 |
| fear | 怖さ |
| worry | 心配 |
| grief | 悲しみ、思い描いていた未来との別れ |
| disappointment | がっかりする気持ち |
| guilt | 罪悪感 |
| self-doubt | 自分の関わり方への迷い |
| helplessness | どうすればよいか分からない感覚 |
| exhaustion | 疲れ |
| overwhelm | 抱えきれなさ |
| loneliness | 孤独 |
| frustration | もどかしさ |
| anger | 怒り |
| envy | 他の家庭をうらやましく思う気持ち |
| comparison | 比べてしまうこと |
| advocacy fatigue | 説明し、求め続ける疲れ |
| waiting fatigue | 待ち続ける疲れ |

これらの感情を、親としての失敗や愛情不足として扱わない。

### 4.2 子どもが感じているかもしれないこと

子どもの内面は断定しない。「そうかもしれない」「身体が探しているのかもしれない」と仮説を残す。

| English | 日本語 |
|---|---|
| confusion | 分からなさ |
| frustration | うまく伝わらないもどかしさ |
| fear | 怖さ |
| sensory overwhelm | 刺激の多さ、感覚的な抱えきれなさ |
| tiredness | 疲れ |
| hesitation | ためらい |
| disappointment | 思うようにならない悲しさ |
| loneliness | 仲間に入れない寂しさ |
| embarrassment | 恥ずかしさ |
| anger | 境界を越えられた怒り |
| resistance | 拒否、抵抗 |
| need for space | 離れたい、距離が必要という感覚 |

拒否や怒りを「ネガティブな行動」として処理せず、次の可能性を検討する。

- もう無理。
- これは嫌。
- 距離が必要。
- 分からない。
- 自分で決めたい。
- 痛い、疲れた、刺激が多い。

## 5. 障害をめぐる社会的な感情と経験

難しさの原因を本人や家庭の中だけに置かず、環境や社会との関係も描く。

| English | 日本語 | 描写上の注意 |
|---|---|---|
| exclusion | 仲間に入れない、排除される | 本人の能力不足だけを原因にしない |
| being underestimated | 低く見積もられる | 本人の可能性や意思が見落とされる場面として描く |
| being stared at | 見られる苦しさ | 周囲の視線が本人や家族に与える負担を扱う |
| not being heard | 本人の声が聞かれない | 代弁だけで終わらず、本人へ確かめる |
| lack of access | 参加できる環境がない | 環境、道具、伝え方を変えられる可能性を示す |
| pressure to prove | できることを証明し続ける負担 | 成功や能力を尊厳の条件にしない |
| medical anxiety | 診察や検査への不安 | 安全を守りつつ、予告、選択、休憩を描く |
| system fatigue | 医療・教育・福祉制度を渡り歩く疲れ | 家族の努力不足として扱わない |
| advocacy | 必要な環境や配慮を求めること | 対立だけでなく権利と参加のための行動として描く |
| solidarity | 同じ経験を持つ人との連帯 | 一つの経験を全員へ一般化しない |
| disability pride | 障害を含む自分への誇り | 障害を克服・否定する物語にしない |

## 6. 感情をつなぐ物語上のペア

難しい感情を肯定的な感情で上書きせず、その間に受容と小さな行動を置く。

| 難しい感情・状態 | 間にある行動 | 隣に生まれる感情・状態 |
|---|---|---|
| 不安 | 立ち止まって見る | 好奇心 |
| 怖さ | 小さく試す | 勇気 |
| もどかしさ | 方法を変える | 手応え |
| 疲れ | 休む | 安心 |
| 孤独 | 経験を分かち合う | つながり |
| 罪悪感 | 自分にも優しくする | 自己受容 |
| 比べてしまう | 本人自身の過去を見る | その子らしさへの信頼 |
| がっかり | 悲しさをそのまま認める | 静かな希望 |
| 怒り | 境界や必要を伝える | 尊厳 |
| 分からなさ | 複数の見方を重ねる | 発見 |
| 失敗への怖さ | 間違えても戻れる条件を作る | 遊び心 |
| 排除 | 環境や参加方法を変える | 参加、所属 |
| 抱えきれなさ | 誰かに渡す、頼る | 支えられている安心 |

この表は「必ず左から右へ解決する」という意味ではない。左側の感情が残ったまま、新しい感情が隣に生まれてよい。

## 7. 物語構造

### 7.1 避けたい構造

```text
できない
↓
保護者が悲しむ
↓
先生が正しい方法を教える
↓
子どもが成功する
↓
全員が前向きになる
```

この構造は、難しい感情を急いで消し、子どもの成功を家族が希望を持つ条件にしてしまう。

### 7.2 HugMapらしい構造

```text
親子が楽しみにしていた
↓
思うようにならず、親子ともに困る
↓
悲しさやもどかしさを急いで消さない
↓
先生が、すでにあった小さなサインに気づく
↓
本人に合う距離、方法、量を一つだけ試す
↓
成功ではなく、本人から何らかの反応が返る
↓
不安は残るが、新しい見方も生まれる
↓
その小さな発見を一緒に受け取り、祝う
```

### 7.3 例

> ママは、少し悲しかった。  
> みんなと一緒に遊んでほしかったから。
>
> うさぎ先生も、すぐには励まさなかった。  
> ふたりで、少し離れた場所から見ていた。
>
> すると、ぼくの足が、ボールの方を向いた。
>
> 「遊ばない」だけではなかった。  
> ぼくは、ここから参加する方法を探していたのかもしれない。

最後を完全な解決にしない。

> まだ入らない日もある。  
> でもママは、見るだけの一歩にも気づけるようになった。

## 9. HugMapの感情循環

シリーズの基本的な感情循環は、次の形とする。

```text
不安
↓
立ち止まる
↓
気づく
↓
小さく試す、または今日は試さない
↓
つながる
↓
小さく祝う
```

この循環の途中には、常に次の余白を残す。

- 悲しんでよい。
- 疲れてよい。
- 怒ってよい。
- 比べてしまう日があってよい。
- 今日は試さなくてよい。
- 一人で抱えなくてよい。

## 10. 制作チェック

物語、アプリ文言、キャラクターの台詞を作るときは、次を確認する。

- 難しい感情を、励ましや希望で急いで消していないか。
- 保護者の悲しさ、怒り、疲れを、愛情不足として描いていないか。
- 子どもの内面を断定していないか。
- 拒否、休憩、距離を取ることを失敗として扱っていないか。
- 成功や自立だけを、祝う条件にしていないか。
- 障害を克服すべき悲劇、または周囲を感動させる道具として扱っていないか。
- 難しさの原因を、本人の中だけに置いていないか。
- 環境、道具、距離、速さ、伝え方を変える余地があるか。
- 本人が選ぶ、断る、頼る場面があるか。
- 希望が、現在の本人を否定する未来志向になっていないか。
- 最後に完全な解決ではなく、親子の日常へ持ち帰れる見方が残っているか。
