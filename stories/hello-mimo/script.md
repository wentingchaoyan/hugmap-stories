# こんにちは、ミモです。

ミモが読者に語りかける自己紹介絵本。声・動作・指さし・選択・絵本・思い出のやりとりと、待ちすぎる一面を描く。

## 素材管理

使用する画像のみを assets/ に配置。ファイル名は固定し、変更履歴はGitで管理する。配色は黄色い体・薄いグレーの服・オレンジのスカーフ。
