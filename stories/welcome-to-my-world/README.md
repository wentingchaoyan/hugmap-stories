# 『ぼくの世界へ、ようこそ。』

学校見学インタビューから抽出した「こちらの課題へ連れていく前に、まず大人が子どもの世界へ入る」を中心にした EAT＋E 絵本です。

## EAT設計

- **Experience（1〜5）**: 僕はカーペットの線に心を向けている。課題へ注意を移されると、動きも声も止まる。
- **Awareness（6〜8）**: ふくろう先生が「何を見ている？」と問い、りす先生が感覚的な興味へ加わり、ことり先生が視線の往復をコミュニケーションとして見つける。
- **Theory（9）**: 「こちらへ呼ぶ前に、まず僕たちが君の世界へ入る」。共同の注意・意図・楽しさは関係から育つ。
- **Experience again（10〜12）**: 家でママが中断せず隣へ座る。カーペットの線が二人の遊びになり、僕の世界が共有される。

## 先生の役割

- ふくろう先生：行動の「何」ではなく「なぜ」を探す。
- りす先生：身体と感覚の興味へ、安全に加わる。
- ことり先生：目・手・身体に現れたコミュニケーションを見つける。
