# 台本：いっしょのリズムは、どこにある？

- 型：共感・没入型＋発達・支援型
- 主役：子ども、りす先生
- 連携：ことり先生、くま先生、保護者
- 物語の核：身体は、周りの感覚と人との関わりの中で、自分に合うリズムを探している。
- 子どもの問い：「ぼくの からだだけ、はしっているの？」
- 読後の核：親子のリズムは同じでなくてよい。刺激を減らす、加える、変える、休む、終える選択を本人と探すと、異なるリズムの間に小さな出会いが生まれる。
- 文章方針：迷走神経、感覚統合、感覚ダイエットは本文で説明しない。子どもの呼吸、肩、指、まばたき、距離として描き、専門情報は巻末へ分ける。
- 絵の方針：白い余白を保ち、感覚負荷は周縁の線と物の重なりで表す。子どもの周囲を暗く囲まない。

## 用語と安全の境界

- Sensory Seekerは診断名として扱わない。同じ子でも感覚の種類や日によって「もっと欲しい」と「多すぎる」が併存する。
- Sensory DietはSensory Seekerへ刺激を大量に与える方法ではない。生活への参加目標、本人の選択と反応を中心にした個別の感覚方略・環境調整として扱う。
- 感覚は増やすだけでなく、減らす・変える・休む・終えるを同じ選択肢として描く。
