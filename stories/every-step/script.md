# 台本：うさぎせんせい、「かんたん」ってだれがきめたの？

- 型：発達・支援型
- 読後の核：一つの動きには複数の身体の仕事があり、道具・環境・時間で力を使いやすくできる。
- 演出方針：没入感より身体と支援の正確さを優先する。支援前後は同じ画角・同じ大きさで比較する。
