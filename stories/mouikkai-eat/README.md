# 『もういっかい』EAT＋E試作版

完成済みの『ことりせんせい、ぼくの「もういっかい」きこえた？』を、`planning/story-narrative-guide.md` の EAT＋E に沿って再構成した比較用プロトタイプです。元作品は変更していません。

## EAT設計

- **Experience（1〜6）**: 音楽が止まり、子どもが袖・移動・指・視線で要求を伝えるが、母親とすれ違う。
- **Awareness（7〜8）**: 一つの仕草ではなく、観察できる行動の連鎖と視線の先に気づく。
- **Theory（9）**: ことばになる前の伝達は、目・手・身体・出来事のつながりに現れることがある、と一つだけ説明する。
- **Experience again（10〜12）**: 翌日の別の場面で、母親が自分で見て、待ち、確かめ、親子の新しい遊びが始まる。

本文12場面の配分は Experience 50%、Awareness 17%、Theory 8%、Experience again 25%。Awareness は最初の6場面にあらかじめ描いたサインだけを再発見する構成です。
